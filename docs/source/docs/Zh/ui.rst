如何使用
--------

.. image:: ../image/main/FrontEngine.png

FrontEngine 把東西放在你的畫面最上層——影片、圖片、網頁、文字、桌面寵物——
並且在你繼續工作的時候一直留在那裡。每一個這樣的東西叫做「覆蓋層」。你可以
同時開很多個，來自不同分頁、放在不同螢幕上。

開出第一個覆蓋層
================

1. 挑一個分頁，看你想放什麼：影片、圖片、網頁、文字等等。
2. 選好檔案，或輸入網址。
3. 按那一頁的開始按鈕。

它會出現在所有東西之上，直到你把它關掉為止。你做其他事情不會不小心把它收走。

每個分頁共通的設定
==================

大部分分頁都有同樣的幾個控制項，而且在哪一頁意思都一樣：

* **不透明度** - 桌面透出來多少。覆蓋層預設偏透明，是為了疊在你的工作上而不是
  把它蓋掉。
* **目標螢幕** - 要用哪個螢幕。設成「每次詢問」就會每次問你。
* **顯示在所有螢幕** - 每個螢幕各放一份，而不是只有一個。
* **顯示在所有視窗底下** - 把覆蓋層壓到視窗之下，像背景而不是擋在前面的東西。
* **最近使用** - 之前用過的檔案，不用再找一次。

覆蓋層不會擋路
==============

點擊會直接穿透覆蓋層落到底下的東西上，所以下面的視窗照常可以操作。有兩個東西
本來就需要滑鼠，因此是例外：寵物，以及簡報頁在塗鴉開啟時的塗鴉層。

一次管理很多個
==============

**控制中心**\ 分頁碰得到每一個覆蓋層，不管是哪一頁開的。它可以一次全部隱藏、
全部靜音、鎖定、重設位置，或在意電池時降低畫質。想把某一個拖到別的位置，
要先解除鎖定——放開的地方它會記住。

把畫面清乾淨
============

控制中心的「關閉所有」會一次關掉全部，也可以到「設定」→「快速鍵」綁一個全域
快速鍵。萬一有東西沒有反應，按 **F12** 會立刻關閉 FrontEngine。

選單列
======

* **選擇語言** - 七種語言：English、繁體中文、简体中文、Deutsch、Русский、
  Français、Italiano。切換後畫面立刻改變，不需要重新啟動，開著的東西也都留在原地。
* **選擇 UI 樣式** - 配色主題，也可以讓它依日夜自動切換。
* **預設集** - 把各分頁的設定整組取名存起來，之後再叫回來。見 :doc:`menus`。
* **設定** - 快速鍵、開機啟動、智慧暫停、應用情境、提醒、看板模式、手機遙控、
  螢幕分享隱私、螢幕使用時間與剪貼簿歷史。同樣見 :doc:`menus`。
* **幫助** - 「使用說明…」會在程式裡開一份簡短的指引，內容和這一頁涵蓋的範圍
  相同。裡面還有問題回報，以及 F12 的提醒。
* **文件** - 在瀏覽器裡打開這份文件。

分頁
====

把東西放到畫面上

* :doc:`video`、:doc:`image`、:doc:`web`、:doc:`gif_and_webp`、:doc:`sound`、
  :doc:`text` - 一種分頁放一種東西。
* :doc:`scene` - 把好幾種組合起來，存成檔案。
* :doc:`particle` - 在桌面上灑粒子效果。
* :doc:`pet` - 會走動、爬牆、對你有反應的夥伴。

讓自己工作得舒服一點

* :doc:`screen_care` - 螢幕濾鏡、閱讀尺、休息提醒、色覺模擬。
* :doc:`focus` - 調暗背景，或把會分心的東西遮起來。
* :doc:`wallpaper` - 位於所有視窗之下的動態桌布。

把畫面給別人看的時候

* :doc:`presentation` - 螢幕塗鴉、游標強調、按鍵顯示、放大鏡、白板。
* :doc:`tools` - 量測、截圖、讀取文字、錄影、虛擬攝影機、攝影機、視窗釘選。
* :doc:`widgets` - 音訊頻譜、系統監控、正在播放、便條紙。
