# 寵物互動、換裝與高對比 chibi 設計

後續使用者接受黑橘孔版怪趣 chibi 的 v3 方向，要求延伸更多角色與服裝。新增 [六角色與十二套新服裝目錄](../design/pet-inkside-catalog-2026-10-28.md) 及三張概念板。含原 MOCHI 的 WORK 與 RAIN 共十四套構想。下列 v2 為早期紀錄，已不作最新美術基準。未新增程式功能或動畫。

完成 [設計規格](../design/pet-interactions-wardrobe-2026-10-28.md)，包含操作意圖、照顧與玩耍、陪伴模式、四槽衣櫃、試穿交易、獨立存檔、舊包相容與動作製作驗收。

使用內建 image_gen 產生四角色及八套服裝的兩張 v2 概念板，依使用者指示採高對比 chibi。v1 柔和風探索稿保留但不再作美術基準。完整提示詞與參考關係存於 `docs/design/assets/pet-concepts-2026-10-28/prompts-v2.md`。

已閱讀目前 Sprite 與存檔實作。現有 change_sprite 是整套替換，draw_content 只繪製單張圖，沒有已完成的分層換裝。這次未改功能、未執行 GUI、未執行測試，也未產生可播放動畫或 Steam 實機截圖。

檢查包括直接檢視生成圖、確認本地檔案可解碼及規格內相對檔案連結存在。原執行計畫標記了新需求及舊工期估算的適用範圍。
