# 每個體的點心偏好

寵物自訂介面新增「喜歡的點心」與「不喜歡的點心」。各自可選四種虛構點心或無偏好；兩個非空選項不能相同，衝突時顯示具體訊息並保留草稿。Puppet 與 Sprite 共用，與頁面外觀預設繼承分開。

存檔沿用 v2，可選的 `preferences.taste` 必須恰好包含 favorite、disliked，值限 null、snack、feast、music、book。省略表示無偏好，不改寫舊個體預設。選項經既有原子保存、複製及匯出匯入流程，取消與恢復預設只改草稿。

CompanionState 在接受餵食時記住當餐偏好。完成時，喜歡的點心比原收益多四點心情；不喜歡的點心少六點心情收益，最低為零。飽足、好感與所有食物共用的冷卻完全不變。中途改偏好只影響下一餐，取消未完成餵食沒有效果。

餵食完成後可顯示兩秒 `food_like` 或 `food_dislike`。分層素材與 Puppet 腳本可宣告相應反應；未提供素材時沿用原有回退，不宣稱已完成表情美術。這是短暫呈現，不持久保存，也不額外發好感。

設計比較與獨立設計檢查記錄在 `.audit/pet-implementation/taste.todo.md`。採兩個選項而非每食物分數表，避免加入沒有使用需求的偏好強度設定。

驗證包含非法欄位與值拒絕、舊存檔無偏好、完成前後的數值與反應、共用冷卻、取消、進食中更改、原子保存失敗、草稿重試、重開、複製隔離及匯出匯入。相關功能、格式、翻譯與文件共 121 項通過，pyflakes 通過。實際離屏介面已檢查，圖片為 `.audit/pet-implementation/pet-taste-controls.png`。七種介面語言與十份 README、七份 pet.rst 已同步。
