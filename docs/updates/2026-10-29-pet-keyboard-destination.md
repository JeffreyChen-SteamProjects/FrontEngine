# 鍵盤指定寵物呼叫落點

寵物管理頁的互動選單新增「過來這裡」。水平與垂直欄位接受 -320 至 320 邏輯像素的位移，負值向左／向上。執行時重新解析所選的寵物身分，以當前寵物中心為起點放置附近目標，不需要拖動桌面標記。既有半徑與工作區限制仍適用，欄位值不是保證行走距離。

地板模式忽略垂直位移；漫遊與追游標模式沿兩軸前進。欄位提示說明此限制。目標維持不接受焦點，沒有加入新的移動計時器。抵達後沿用既有招呼完成與冷卻；「結束互動」可取消。

呼叫路徑在共用照顧清理之前判定能力。忙碌、工作／休息、拖曳、安靜、隱藏或尚不支援移動的 Puppet 不會被強制切換，也不會取消既有照顧。成功時才替換既有玩具。QAction 的 checked 布林值不會被當成位移。

獨立檢查發現原本的地板投影順序會讓垂直輸入影響水平落點。新增測試先重現相同水平位移得到 `-216` 與 `-246.11239895337172` 的不同落點，再修正共用 LightToy 計算：地板模式先忽略垂直差，再限制距離。

95 項鍵盤呼叫、既有呼叫、管理頁照顧、光點、球、翻譯及文件測試通過，pyflakes 通過。實際管理頁已離屏繪製並檢視。Qt 本機鍵盤事件驗證選擇、數值輸入與 Space 啟動，沒有注入作業系統輸入；原生鍵盤焦點、Puppet 移動及正式動畫仍待驗收。
