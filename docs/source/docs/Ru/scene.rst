Сцена
-----

.. image:: ../image/scene/scene.png

Сцена держит сразу несколько слоёв и сохраняется в файл.

* Добавить веб-страницу - адрес и непрозрачность.
* Добавить видео - файл, непрозрачность, скорость, громкость.
* Добавить изображение - файл и непрозрачность.
* Добавить GIF - файл, непрозрачность, скорость.
* Добавить звук - файл и громкость.
* Добавить текст - текст, непрозрачность, размер шрифта, выравнивание.
* Запустить сцену - показать всё добавленное.
* Сохранить файл сцены.
* Загрузить файл сцены - вернуть сохранённую сцену.
* Очистить все сценарии - начать заново.
* Показывать на всех экранах - по копии на монитор.

Сцены: страница сцен принимает старое JSON-отображение записей, версионный документ frontengine.scene и переносимые пакеты .fescene. Запись PUPPET содержит позицию, размер, непрозрачность, конечные числовые параметры и необязательные движение, выражение и скрипт. Пути JSON разрешаются относительно файла сцены. .fescene включает используемые медиа, исходный .puppet и необязательный .petscript.json для переноса между компьютерами. Импорт проверяет пути, символические ссылки, версии и лимиты распаковки. Сцена FrontEngine остаётся пакетом сцены; .puppet остаётся одним персонажем Imervue.

Сцена → Визуальный редактор даёт список и превью слоёв изображения/GIF/текста, групповое перемещение, изменение размера углом, позицию/размер/масштаб/поворот/порядок/непрозрачность, выравнивание, блокировку, видимость, дублирование и 100 отмен/повторов (Ctrl+Z/Ctrl+Y). Остальные типы сохраняются как заглушки. Экспортируйте переносимый .fescene; во вкладке скрипта редактируйте и применяйте JSON. Воспроизведение восстанавливает явные размеры, масштаб, поворот и видимость. Внешний JSON начинает новую историю отмен; существующие поля сохраняются.

Сцена → Скрипт → Шаблоны сцен (также в палитре команд) предлагает Рабочий стол, Обучение и Сосредоточение с переведённым редактируемым текстом. Просмотрите макет, выберите основной экран или номер, затем Применить и воспроизвести; пропорции вписываются в доступный логический размер. Все ресурсы включены. Отсутствующие ресурсы указаны как слой/поле/путь и блокируют применение. Транзакция сцены заменяет редактор и воспроизведение; неудачная подготовка сохраняет прежнюю сцену. Изменяйте текст, добавляйте материалы и экспортируйте JSON или переносимую .fescene. Закрытие библиотеки отменяет только её ожидающее применение. Сосредоточение содержит редактируемые напоминания; расписания и таймеры остаются отдельными инструментами.

Сцена → Визуальный редактор добавляет видео, веб, Puppet и аудио к изображениям/GIF/тексту. Включайте просмотр явно: до восьми источников, звук только после Прослушать, пауза при скрытии, освобождение при отключении и закрытии. Кадры ограничены 1280 пикселями по стороне; ошибки отображаются. Именованные сцены объединяют видео, собственную поверхность веб и внеэкранные кадры Imervue Puppet со всеми визуальными слоями по z; аудио невидимо. Двойной щелчок веб/Puppet при воспроизведении или Взаимодействовать в редакторе открывает то же нативное окно ввода. Puppet требует нативного OpenGL и дополнительного runtime; просмотр не запускает скрипты, питомцы сцены используют временное состояние. Отдельные окна веб/видео/Puppet доступны. JSON/.fescene сохраняет все поддержанные типы и ссылки.

Сцена → Визуальный редактор → Шкала анимации меняет x/y/прозрачность незаблокированного слоя, с шаблонами появления и въезда. Уникальное возрастающее время: 0–3600 секунд, 128 кадров на слой; прозрачность 0–100, позиции ±100000, linear или smooth. Пустые ячейки сохраняют канал. Изменение отменяемо; JSON/.fescene сохраняет дорожки. Просматривайте время, воспроизводите, ставьте на паузу, продолжайте и повторяйте без сохранения временных позиций; перед правкой сбросьте просмотр. Воспроизведение имеет свои команды и общие монотонные часы для экранов. Скрытие останавливает время; явная пауза сохраняется после показа. Медиа приостанавливается вместе с анимацией; повтор касается дорожек. Действия сцены смешивают старый снимок 0,5 секунды, сразу закрывают старые движки и начинают с нуля. Старые сцены совместимы.

Сцена → Независимый вывод показывает сцену редактора в 640×480, 1280×720 или 1920×1080 пикселях независимо от позиции, перекрытия и DPI рабочего стола. Просмотр не открывает камеру; явная передача требует pyvirtualcam и совместимого драйвера. Открытие/передача/закрытие в одном worker с последним ожидающим RGB-кадром; медленные устройства пропускают промежуточные. Без аудио. IMAGE/GIF/TEXT и нативные VIDEO/WEB/PUPPET соблюдают порядок; SOUND невидим. Puppet требует дополнительного runtime и нативного OpenGL; ошибки видимы. До 256 слоёв, восьми нативных источников и 16 мегапикселей общего растра. Стоп, Escape, закрытие или правки освобождают движки и запрашивают закрытие камеры; после правок перезапустите. Читатели закрываются до освобождения пакетов.

Сборки Windows используют --preset и --debug из Python CLI. Для нативной проверки установить frontengine[puppet] в среде сборки; динамические декодеры Pillow и данные установленного Imervue включаются. Создать локальные входы: ``py tests/integration/scene_build_fixtures.py FIXTURES --puppet SAMPLE.puppet`` (PyAV нужен для видео). На нативном рабочем столе запустить ``FrontEngine.exe --verify-scene-build FIXTURES REPORT`` с новым каталогом отчёта. Фиксированная проверка изолирует настройки временно, отключает звук и открывает только свои окна сцены/редактора. Проверяет семь типов, старый/версионный JSON, экспорт/загрузку, GIF-анимацию, веб-взаимодействие, отмену/повтор, паузу/возобновление и освобождение; пишет result.json и PNG и выходит. Переданные Python-скрипты не исполняются. Проверить отчёт и код выхода; отсутствие runtime/нативного рендера явно завершается ошибкой.
