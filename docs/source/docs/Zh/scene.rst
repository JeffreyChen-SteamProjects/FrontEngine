場景頁面
--------

.. image:: ../image/scene/scene.png

一個場景可以同時放好幾種覆蓋層，並存成檔案。

* 加入網頁到場景 - 位址與不透明度。
* 加入影片到場景 - 檔案、不透明度、播放速度、音量。
* 加入圖片到場景 - 檔案與不透明度。
* 加入 GIF 到場景 - 檔案、不透明度、速度。
* 加入音效到場景 - 檔案與音量。
* 加入文字到場景 - 文字、不透明度、字體大小、對齊。
* 開始場景 - 顯示所有加進去的東西。
* 輸出場景檔 - 把組好的內容存起來。
* 載入場景檔 - 把存過的場景叫回來。
* 清除所有腳本 - 重新開始。
* 顯示在所有螢幕 - 每個螢幕各一份。

場景：場景頁支援舊 entry mapping JSON、有版本的 frontengine.scene envelope，以及可攜式 .fescene 套件。PUPPET 項目可設定位置、大小、不透明度、有限數值參數，以及選用動作、表情與腳本。JSON 路徑相對於場景檔解析。.fescene 包含引用媒體、原始 .puppet 與選用 .petscript.json，可移到其他電腦。匯入會檢查路徑、符號連結、版本與解壓上限。FrontEngine 場景維持場景套件；.puppet 維持單一 Imervue 角色。

:doc:`runtime_interoperability`

場景 → 視覺編輯提供圖片／GIF／文字圖層清單與預覽、群組拖曳、角落縮放、位置／尺寸／倍率／旋轉／順序／透明度控制、畫布對齊、位置鎖定、顯示、複製及 100 步復原／重做（Ctrl+Z／Ctrl+Y）。可直接匯出可攜 .fescene；腳本頁也能編輯並套用 JSON。播放會還原明確尺寸、倍率、旋轉與顯示狀態。載入／套用外部 JSON 時開啟新的復原紀錄，保留既有欄位。

場景 → 腳本 → 情境範本（亦可由命令面板開啟）提供工作桌面、教學與專注配置，附目前語言的可修改文字。先預覽並選擇主螢幕或編號螢幕，再按「套用並播放」；配置會依該螢幕的可用邏輯尺寸等比例調整。範本已包含所需素材；素材缺失時會列出圖層／欄位／路徑並禁止套用。套用透過既有場景建立流程替換編輯內容與播放，準備失敗會保留原場景。之後可修改文字、加入素材，再由場景匯出另存 JSON 或可攜 .fescene。關閉範本庫只會取消自身待處理的套用。專注範本提供可修改的提醒文字，排程與計時器仍由各自工具設定。

場景 → 視覺編輯可在圖片／GIF／文字之外加入影片、網頁、Puppet 與音訊。須手動啟用即時預覽，最多八個來源，預設靜音；試聽選取媒體才開啟聲音，隱藏時暫停，停用或關閉時釋放資源。影格每邊最多 1280 像素，無法預覽會顯示原因。具名場景播放將影片影格、網頁自己的渲染畫面及 Imervue 離屏 Puppet 影格依順序與所有視覺圖層合成；音訊播放不顯示圖層。播放時雙擊網頁／Puppet，或在編輯器選擇與選取媒體互動，可開啟同一個原生輸入視窗。Puppet 預覽需要原生 OpenGL 與選用執行環境，不執行寵物腳本，場景寵物採用暫存狀態。獨立網頁／影片／Puppet 視窗仍可使用。JSON／.fescene 匯出保留全部支援類型與素材引用。

場景 → 視覺編輯 → 動畫時間軸可編輯單一未鎖定圖層的 x／y／透明度關鍵影格，提供淡入與滑入範例。時間須唯一遞增，範圍 0–3600 秒，每層最多 128 個影格；透明度 0–100、位置 ±100000，緩動可用 linear 或 smooth。空白欄位保留該屬性。套用為一筆可復原編輯，JSON 與可攜 .fescene 保留動畫。可拖曳時間、播放、暫停、繼續或重播預覽，暫時位置不會存檔；重設恢復儲存配置後再編輯。場景播放另有動畫控制，多螢幕共用單調時鐘，隱藏時停止推進；明確暫停不會因重新顯示而取消。動畫暫停會暫停媒體，重播控制動畫軌。場景動作切換以舊合成畫面的快照淡入淡出 0.5 秒，立即釋放舊渲染器，新時間軸從零開始。沒有動畫的舊場景仍相容。

場景 → 場景獨立輸出可將目前編輯器場景預覽為固定 640×480、1280×720 或 1920×1080 像素，不受桌面位置、遮擋及 DPI 影響。開始預覽不開啟攝影機；送至虛擬攝影機才會明確使用選用 pyvirtualcam 與已安裝相容驅動。裝置啟動、傳送及關閉由單一背景工作執行，僅保留最新待送 RGB 影格，裝置較慢時略過中間影格。輸出靜音且不含音訊。圖片／GIF／文字及原生影片／網頁／Puppet 依圖層順序合成，音訊圖層不可見。Puppet 需要選用執行環境及原生 OpenGL；媒體或裝置不可用時顯示原因。支援最多 256 圖層、八個原生媒體來源，圖層點陣圖總計 1600 萬像素。停止、Escape、關閉對話框／程式或編輯場景都會釋放渲染器並請求關閉攝影機；場景編輯後須重新啟動。舊素材讀取會在場景封包租期釋放前停止。

Windows 封裝共用 Python CLI 的 --preset 與 --debug。原生封裝驗收前，於建置環境安裝選用 frontengine[puppet] 執行期（包含 Pillow 動態解碼外掛及已安裝 Imervue 的套件資料）。用 ``py tests/integration/scene_build_fixtures.py FIXTURES --puppet SAMPLE.puppet`` 產生本機合成素材（產生影片另需 PyAV）。在原生桌面執行 ``FrontEngine.exe --verify-scene-build FIXTURES REPORT``，REPORT 必須是新目錄。固定驗收以暫存目錄隔離設定、保持預覽靜音，只建立自己的場景／編輯器視窗，驗證七種類型、舊／版本化 JSON、匯出再載入、GIF 動畫、網頁互動、復原重做、暫停恢復與清理，寫入 result.json 及預覽 PNG 後退出；不執行傳入的 Python 測試腳本。請檢查報告及退出碼，缺少執行期或原生渲染會明確失敗。

3D 場景編輯與播放
=================

在場景的視覺編輯器選擇「3D」，即可沿用原有圖層清單、JSON、
復原／重做、範本與開始播放操作。舊場景維持 2D 格式。
切換為 3D 後，現有媒體仍是螢幕圖層；在 3D 面板將放置方式改成
「空間平面」，就能設定空間位置。切回 2D 會保留媒體並移除 3D
物件與設定，可透過復原回到原場景。

新增物件選單提供 GLB、glTF、OBJ 模型、基本形狀、相機、燈光及群組。
模型的子節點可在 3D 面板查看，模型內部階層為唯讀。
glTF 使用核心 metallic-roughness 材質，支援骨架與 morph 動畫；
OBJ 使用靜態幾何與 MTL 基本色／漫反射貼圖。
必要擴充不支援時會顯示原因；目前不含 Draco、Meshopt、KTX2 解碼、
陰影、物理模擬或模型建模工具。

滑鼠左鍵選取或拖曳物件，Ctrl 加左鍵可多選。工具列可切換移動、旋轉、
縮放、軸向限制與吸附。右鍵拖曳旋轉編輯視角，中鍵平移，滾輪調整遠近。
「聚焦選取」方便檢視不同尺寸的模型；編輯視角獨立於播放相機，
按「將視角套用至相機」後才會改變實際播放構圖。

在動畫面板選擇屬性並編輯數值關鍵影格；旋轉以角度輸入，文件內使用四元數。
模型可選擇內建動畫片段、起點、速率與循環。場景時間軸控制物件、相機、
燈光、影片、GIF 與音效，支援暫停、定位、重播、速率及循環。
網頁與 Puppet 為即時來源，跳轉時間不會還原歷史內容。
預覽預設靜音，媒體預覽與試聽需明確啟用。

開始播放仍使用原有螢幕選擇。多螢幕共用場景時間與音訊來源，
畫面依畫布比例留白。可設定穿透滑鼠點擊，也可使用控制中心切換鎖定。
新播放完成模型解析、GPU 初始化及首幀驗證後才替換舊播放；
失敗或取消時保留原場景。

螢幕中斷連線時只關閉該螢幕的播放視窗，沒有可見播放目標時暫停共用時鐘。
同一螢幕重新連線後會重建視窗，保留媒體來源及使用者的暫停狀態；
手動關閉的目標不會自動重開。控制中心的畫質與低耗電設定也適用於 3D
預覽、播放及輸出。降低畫質會縮小內部算繪解析度，輸出仍維持選定的像素尺寸。

3D 場景以 version 2 JSON 或 .fescene 儲存，後者包含模型、buffer、
MTL 與貼圖，可透過既有 Workshop 流程分享。外部模型資源必須位於
模型目錄之內。每場景最多 256 個物件、8 個原生媒體來源、8 個燈光；
封裝上限 256 MiB，模型解碼預算 512 MiB。

輸出視窗使用獨立靜音副本與離屏 OpenGL 算繪，不擷取桌面。
虛擬攝影機的透明部分會合成所選背景色，預設黑色。
修改場景會停止舊輸出，需重新預覽。
3D 需要桌面 OpenGL 3.3，請使用自動或 GPU 算繪；
2D 場景仍可使用軟體備援。

開發驗證
--------

CPU 與 offscreen 單元測試可執行 ``python -m pytest tests/unit_test/test_scene_3d.py``。
真實 GPU 驗收另行執行 ``python -m tests.integration.scene3d_gl_smoke``，
不可將 offscreen 平台測試視為 GPU 驗收。此工具會建立自己的小型測試視窗，
驗證透明度、骨架／morph 動畫、桌面與固定尺寸輸出及播放候選的首幀。

加上 ``--report REPORT`` 可將原生驗收結果寫入新目錄。加上
``--media-fixtures FIXTURES`` 驗證前述七種媒體素材，``--camera`` 驗證 Windows
實際 OBS 虛擬攝影機傳送與 DirectShow 接收像素（需 PyAV、pyvirtualcam 與已安裝
驅動），``--stress-vertices 250000`` 驗證靜態及骨架／morph 大模型。
要求的執行期或裝置缺失會明確失敗，未要求的項目標示為 ``not_run``。
螢幕重建驗收使用模擬斷線回呼及真實原生播放視窗。

以 ``python exe/build_exe.py --output-dir build/nuitka-scene3d --jobs 2`` 建置，再執行
``FrontEngine.exe --verify-3d-scene-build REPORT --require-compiled``，可搭配相同
選項驗證實際二進位檔，報告含 EXE 的 SHA-256。獨立資料夾版本須保留整個
distribution 資料夾。Linux 可在唯讀掛載本工作樹至 ``/workspace`` 的拋棄式
Debian/Python 容器中執行 ``tests/integration/linux_scene3d_acceptance.sh``，
驗證完整測試與原生 Xvfb／Mesa GL；此結果不代表所有 GPU 與視窗合成器皆已驗收。
建置預設使用全部 CPU 核心（``--jobs auto``）。正數的 ``--jobs`` 可限制並行編譯數、降低編譯時的記憶體需求；負數（例如 ``--jobs -2``）則保留該數量的核心不用。

Qt 支援範圍為 6.11.2 至低於 6.13。選用 Imervue 執行期固定使用 Qt 6.11.2，
包含 Puppet 的發行版應先安裝 Puppet extra。Python 3.14 的 EXE 建置需
Nuitka 4.3.1 以上版本。
