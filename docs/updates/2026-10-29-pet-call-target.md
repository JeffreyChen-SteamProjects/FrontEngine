# 寵物過來指令

Sprite 互動選單新增「過來這裡」。顯示紙白圓框、橘色向下箭頭的落點標記，使用者可拖動標記調整附近目的地，右鍵取消。標記是自有的小型覆蓋視窗，不接受鍵盤焦點，也不操作其他應用程式。

`CallTarget` 沿用 `LightToy` 已有的工作區限制、目標追蹤、拖曳與取消機制，僅更換外觀與抵達動作。LightToy 的預設抵達動作仍為 play，CallTarget 為 greet。單一 `_toy` 所有權確保呼叫、球與光點不會同時控制寵物。

目標距離以寵物大小的兩倍為基準，限制在 96 至 320 像素，並限制於工作區內。地板模式投影到地板，漫遊與追游標模式沿兩軸追蹤。抵達附近且未拖動標記半秒後收起標記，開始共同的短招呼；完成與冷卻沿用招呼規則，不另發呼叫獎勵。三十秒未完成則取消。

選擇結束互動、切工作／休息、隱藏、開始撫摸、餵食或換玩具會釋放目標，打字安靜亦沿用既有互動可用條件。Puppet 尚無移動控制，未新增無效入口。

三種模式抵達、負座標工作區、拖動範圍、逾時、取消、模式切換、餵食與玩具切換的測試通過。連同既有光點、球、翻譯與文件共 82 項通過，pyflakes 通過。原生焦點與正式行走／招呼動畫驗收仍未完成；離屏測試不代替原生操作。
