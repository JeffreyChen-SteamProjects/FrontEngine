Забота о глазах
---------------

* Фильтр экрана - тёплая, янтарная, розовая, жёлтая, зелёная, синяя или серая
  пелена поверх изображения, с регулируемой силой.
* Линейка для чтения - полоса, следующая за курсором, чтобы не терять строку.
* Перерывы для глаз (мин / с) - через столько-то минут экран гаснет на
  столько-то секунд и возвращается.
* Цветовое зрение - смоделировать протанопию, дейтеранопию, тританопию или
  ахроматопсию и проверить, читается ли ваш макет.
* Показывать на всех экранах / Целевой экран - как и везде.

Эти слои пропускают щелчки насквозь, всё под ними продолжает работать.
