小工具頁面
----------

* 音訊頻譜 - 隨喇叭播放的聲音起伏的長條或環形，頻段數可調。
  這一項確實會擷取音訊，但只在記憶體裡分析以計算頻率；不會錄下也不會送出，
  停止頻譜就停止擷取。Windows 與 macOS（macos extra 與權限；此處未驗證 macOS 實機）。
* 系統監控 - 以小面板常駐顯示 CPU、記憶體、磁碟、電池與網路上下行。
  要顯示哪幾條線可以自己勾；沒有顯示的線照樣在記錄，打開就看得到這段時間發生的事。
* 顯示正在播放 - 你的播放器現在放到哪一首。
* 便條紙 - 「新便條」在桌面上貼一張，「關閉便條」清掉全部。
  勾選「FrontEngine 啟動時重新打開我的便條」下次就會自動回來。

小工具 → 待辦與行事曆提供勾選式待辦、可選本地到期時間與本機 UTF-8 .ics 獨立 VEVENT／VTODO 匯入。今日小工具顯示未完成的無日期、今日及逾期待辦，以及今日重疊事件；全天與午夜結束時間採不含結束日。已知 IANA TZID 使用 Qt 平台規則，UTC 顯示本地時間，浮動時間維持本地、全天日期不換日。DST 重複時段取首次，缺失時段用變更前偏移；DURATION 的天數保持本地時間。UID＋RECURRENCE-ID 識別更新，較低 SEQUENCE 不覆蓋新版，重匯保留勾選，CANCELLED 移除匹配事項。支援折行與 TEXT 跳脫，不開啟連結、鬧鈴或附件。循環規則／RDATE／EXDATE 與未知自訂時區會整批拒絕，請匯出獨立事件。設定旁 tasks.json 最高 500 項／4 MiB，標題 1000、說明 2000 字，原子保存失敗保留舊資料；匯入 4 MiB、單行 8192 字。沒有網路同步或鬧鈴。延後啟動的單一背景工作處理檔案，關閉停止計時並丟棄晚到結果。今日小工具納入批次關閉／隱藏；須明確開啟，事項保存但不自動重開浮窗。

取消紀錄仍計入 500 筆上限，防止舊匯入重新建立已取消事件。清空全部會先確認，並刪除待辦、事件及取消資料。今日小工具使用一般 Qt 軟體繪製，避免合成層蓋住互動控制項。
