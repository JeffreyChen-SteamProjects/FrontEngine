Page Image
----------

.. image:: ../image/image_page/image_page.png

* Choisir une image - l'image à afficher.
* Afficher l'image.
* Opacité - à quel point l'image est translucide.
* Plein écran - étirer sur tout l'écran.
* Afficher sur tous les écrans - une copie par moniteur.
* Afficher sous toutes les fenêtres - la placer sous les autres fenêtres.
* Diaporama - afficher tour à tour toutes les images d'un dossier.

    * Choisir un dossier - où se trouvent les images.
    * Intervalle - secondes par image.
    * Aléatoire - ordre mélangé.
    * Inclure les sous-dossiers.

* Écran cible - quel écran utiliser, ou demander à chaque fois.
* Récents - les images déjà affichées.
