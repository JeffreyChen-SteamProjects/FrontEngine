# 寵物衣櫃風格色票

衣櫃新增六個可直接點選的色票：黑 `#171613`、橘 `#ff7417`、紙白 `#fff1cf`、萊姆綠 `#c8f141`、青綠 `#24b8b0`、桃紅 `#f45588`。保留原有自由選色與恢復原色按鈕。

色票只套用到目前選取、素材有宣告的配色部位。沒有可調色部位時停用，不對整張圖片加濾鏡。使用既有草稿流程，預覽不修改存檔，按套用才保存；取消後保留上次套用結果，同種角色的另一隻寵物不受影響。

每個色票提供色碼工具提示與無障礙名稱，可用鍵盤焦點與按鈕啟動。新增標籤已加入七種介面語言，十份 README 與七份 pet.rst 同步說明。色票之間有鮮明差異，但任意兩個部位的組合不保證對比，仍應查看角色預覽。

實際衣櫃離屏渲染已檢查，六個色票與鍵盤焦點框完整顯示。重跑腳本為 `.audit/pet-implementation/preview_swatches.py`，圖片為同目錄的 `wardrobe-swatches.png`。預覽使用測試遮罩，不能當作正式角色素材。

新增測試逐個點選色票，檢查渲染像素、透明度、未染色輪廓、套用前存檔不變、套用後重開、取消草稿、恢復原色與另一個體隔離。配色與衣櫃測試共 18 項通過。

連同翻譯與文件檢查共 67 項通過；修改的產品模組及配色測試 pyflakes 通過。
