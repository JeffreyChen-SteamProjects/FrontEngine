网页页面
--------

.. image:: ../image/web/web.png

* 以网址打开网页 - 显示输入框里的地址。
* 打开本地文件 - 把输入框当成本地 html 文件的路径。
* 允许输入 - 让网页可以接收点击与键盘输入。
* 不透明度 - 网页有多透明。
* 缩放 - 网页缩放，50% 到 200%。
* 自动刷新 - 每 30 秒到每 15 分钟重新加载一次。
* 仪表板网址 - 一行一个地址；以 # 开头的行会被忽略。

    * 启动仪表板 - 依次轮播那些地址。
    * 下一页 - 立刻换下一个。

* 显示在所有屏幕 / 显示在所有窗口底下 / 目标屏幕 - 和其他页面相同。
