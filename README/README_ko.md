**무엇이든 화면 위에 — 또는 화면 아래에 놓으세요.**

FrontEngine은 데스크톱 오버레이 앱입니다. 동영상, 이미지, GIF, 웹 페이지, 텍스트,
파티클, 사운드, 그리고 애니메이션 펫을 다른 모든 창 위에 올려놓거나(클릭 통과되므로
아래에 있는 것도 그대로 작동합니다), 라이브 배경화면처럼 창 뒤에 배치할 수 있습니다.
그 주변에는 화면 자체를 위한 도구 모음이 있습니다. 눈 편안함 필터, 프레젠테이션 주석,
측정과 캡처, 집중 마스크, 데스크톱 위젯이 그것입니다.

## 설치

Python 3.11 이상을 지원하지만 3.14.0부터 3.14.4까지는 제외합니다. Python 3.14를 사용한다면 3.14.5 이상의 패치 버전을 설치하세요. Windows 10/11이 주요 대상이며, macOS와 Linux에서도 앱이
실행됩니다. 플랫폼 차이는 [플랫폼 지원](#platform-support)에 나열되어 있습니다.

Windows의 Python 3.14.4에서 Qt 네이티브 충돌이 재현되어, 이전 3.14 패치 버전도 예방 차원에서 제외합니다. 기존 가상 환경은 호환되는 인터프리터로 다시 만들고, 소스 실행에도 해당 인터프리터를 사용하세요. 제외된 버전을 내장한 EXE는 호환되는 인터프리터로 다시 빌드해야 합니다. FrontEngine 패키지를 업데이트해도 Python은 업그레이드되지 않습니다.

```bash
pip install frontengine

frontengine                    # or: python -m frontengine
frontengine --preset "Work"    # apply a saved preset on launch
```

사전 빌드된 Windows 바이너리는
[Releases 페이지](https://github.com/JeffreyChen-SteamProjects/FrontEngine/releases)에
있으며, Steam 빌드는 Workshop 지원을 포함한 동일한 애플리케이션을 제공합니다.

> **빠져나오기.** 오버레이는 FrontEngine 자체 창을 포함해 화면 전체를 덮을 수
> 있으므로, 마우스 없이도 쓸 수 있는 두 가지 탈출구가 있습니다.
> `Ctrl+Shift+F12`는 모든 오버레이를 닫고, **F12는 어디서든 애플리케이션을 즉시
> 종료합니다**(Windows 전용 — *Help → How to force close* 참조).

## 화면에 올리는 것

사이드바는 페이지를 용도별로 묶습니다. 이 절은 그 순서를 따릅니다.

사이드바의 각 페이지에는 아이콘이 있고, 위쪽 검색 상자(Ctrl+K)를 누르면 명령이 열립니다. 메뉴 막대의 도움말과 문서 메뉴는 이름 그대로 표시됩니다. 넓은 창에서는 설정 페이지의 카드가 가운데 한 열에 머물고, 펫 집과 장면 편집기는 전체 너비를 씁니다.

### 홈

**펫 하우스** — 첫 페이지입니다. 저장된 펫이 작은 집으로 이사해 스스로 생활하고 일해서 코인을 법니다.

- *집 만들기*를 누르면 침대, 식탁, 책상과 10코인을 받습니다. 누르기 전에는 아무것도 만들어지거나 시작되지 않으며, 다른 도구는 집 없이도 모두 동작합니다. 집을 만들기 전에 저장된 모든 펫이 *함께 이사 오는 펫* 아래에 모두 체크된 채 표시되며, 남을 펫은 체크를 풀면 됩니다. 체크한 펫은 그대로 이사 옵니다(같은 ID·이름·친밀도·기분·포만감·기력·모습·옷장). 아무것도 복제되거나 초기화되지 않으며, 빠진 펫은 나중에 주민 탭에서 이사 올 수 있고 시작 물품은 다시 지급되지 않습니다. 집의 1년은 7게임일씩인 네 계절(봄·여름·가을·겨울)로 이루어지며, 상태 줄과 전체 보기 하늘의 꽃잎·낙엽·눈으로 보입니다(*움직임 줄이기*에서는 멈춰 있음). 겨울에는 비가 눈으로 내립니다. 계절마다 그 계절의 목표(꽃 기르기, 놀기, 허브 수확, 휴식)가 있고 보상은 한 번만 받습니다. 놓친 계절은 이듬해에 다시 돌아옵니다. 저장된 반려동물이 없으면 *집 만들기*가 첫 반려동물도 데려오고 선택해 둡니다.
- 저장된 펫을 *입주*시키거나 *새 펫*을 만듭니다. 한 펫은 집과 바탕화면에 동시에 있을 수 없습니다. 에너지·포만감·기분·애정도는 그대로 이어지고, 이사 나갈 때 프로필로 돌아갑니다.
- *배치*는 보관함의 가구를 바닥에 놓습니다. 빨간 미리보기가 놓을 수 없는 이유(집 밖, 이미 무언가 있음, 입구를 막음)를 알려 주며, Esc로 배치를 끝냅니다. *보관*하면 가구가 보관함으로 돌아가고, 그 가구에서 하던 일은 진행도를 유지한 채 일시 정지됩니다. 배치 중에는 가구를 끌어서 옮기거나, 선택한 뒤 ← / → 로 한 칸씩 움직일 수 있습니다. *실행 취소*와 *다시 실행*(Ctrl+Z / Ctrl+Y)은 모든 배치 변경에 쓸 수 있습니다. *배치 복사*는 배치 코드(가구와 위치만, 펫·코인 등 개인적인 것은 없음)를 클립보드에 넣고 *배치 붙여넣기*로 다시 읽어 옵니다. 네 가지 기본 배치(*시작 집*, *아늑한 구석*, *공방*, *정원 작업실*)는 *배치 적용*으로 사서 놓기 전에 부족한 것과 가격을 보여 주며, 이전 배치는 *실행 취소* 한 번이면 돌아옵니다. *바닥에 구역 칠하기*로 바닥 구간을 *생활*, *일*, *휴식*, *식사*로 표시(또는 표시 제거)할 수 있으며, 펫은 하고 있는 일에 맞는 구역의 가구를 우선하지만 다른 가구가 금지되지는 않습니다. 두 번째 모니터가 있으면 *그 화면에 구역 추가*로 거기에 자기 바탕화면 띠를 가진 구역이 생기고 *이 구역을 그쪽으로 이동*으로 옮길 수 있으며, 펫은 *그 구역으로 이동*으로만 구역을 바꿉니다. 모니터를 뽑으면 그 구역의 펫은 기다리고 가구는 그 자리에 남으며(아무것도 복제되지 않음), 화면이 돌아오면 이어서 생활합니다. *캣타워*와 *클라이밍 월*은 높은 곳에 있습니다. 장난스러운 펫은 스스로 뛰어오르고, 다른 펫은 옆에 *펫 계단*이 있어야 하며, 둘 다 없으면 빨간 미리보기에 *아무도 올라갈 수 없음*이 표시됩니다(작업대는 항상 바닥에 있습니다). *입구 연결 대상*으로 두 구역의 입구를 이으면 통로가 되어, 펫이 쉬는 시간에 가끔 놀러 가고 잘 시간에는 자기 침대로 돌아옵니다. 연결되지 않은 화면으로는 가지 않습니다. *설계도 공유…*는 집 전체의 방과 가구를 JSON 파일로 저장합니다(펫·이름·코인·목표·화면 이름 등 개인적인 것은 없음). *설계도 방문…*은 그런 파일을 읽기 전용으로 엽니다. 방을 둘러볼 수 있지만 아무것도 동작하거나 구매되거나 저장되지 않으며 온라인에도 연결되지 않습니다. 설계도가 아닌 파일은 거부되고, 이 FrontEngine에 없는 가구는 보여 주는 대신 목록으로 표시합니다.
- *일*은 설정이 필요 없습니다. 펫은 근무 시간에 작업대가 허락하는 일을 자기 직업부터 스스로 맡고, 가방에 이미 있는 재료만 씁니다. 탭에는 각 펫이 무엇을 하는지 만드는 물건의 그림과 함께 표시되며, 어떤 일이든 취소할 수 있습니다. 완료한 단위는 정확히 한 번만 지급되고, 취소한 단위는 지급되지 않습니다. 시작 가구는 저절로 놓이고, *배치하기*는 보관함의 가구를 첫 빈자리에 놓으며(또는 *배치*를 켜고 바닥을 클릭), *상점*에서 산 가구는 바로 집에 들어가고, 끝난 *첫걸음 목표* 보상과 물건이 갖춰진 의뢰는 저절로 정산됩니다. 상점, 가방, 보관함은 모든 가구와 물건을 그림으로 보여 줍니다. 타일의 이름과 가격은 서로 다른 줄에 표시되고, 타일 크기는 글꼴에 맞게 조정되며, 긴 이름도 도구 설명에서 전체를 확인할 수 있습니다. *설정* 탭에는 바탕화면 표시와 움직임 줄이기만 남습니다. 작업대는 오른쪽 클릭 메뉴나 가구 탭에서 두 번까지 *업그레이드*할 수 있습니다(가격은 가구와 레벨에 따라 다르며 자유 배치에서는 무료). 같은 종류의 작업대는 레벨을 공유하므로 넣어 두거나 다시 배치해도 사라지지 않고, 레벨마다 4분의 1씩 빨라집니다. 한가한 펫이 일하는 펫을 도우러 가기도 하며(도우미는 둘까지, 한 명마다 속도 4분의 1 증가) 그 일을 조금 배웁니다. 창고에 그 물건이 스무 개 있으면 자동 작업은 더 이상 그것을 만들지 않습니다. 가구에는 지금 일어나는 일이 표시됩니다. 사용 중에는 점, 펫이 일하는 동안에는 그 직업의 도구(✎ ❀ ⚒), 일이 끝나면 몇 초 동안 ✓가 나타납니다. *집중할 때 펫도 함께 일하기*를 켜면 펫 페이지의 집중 타이머를 시작할 때 한가한 펫마다 일 부탁이 대기열에 들어갑니다(하던 일은 끊기지 않고, 보상은 평소와 같으며, 입력 내용을 읽거나 쉬는 것을 탓하지 않음). 휴식하거나 타이머를 멈추면 집이 넣은 부탁만 거둬들입니다. 직업마다 기술 레벨 4인 펫과 레벨 4인 집에서 할 수 있는 고급 일이 있습니다. *장편 소설 쓰기*(120코인), *꽃다발 만들기*(꽃 세 송이로 30짜리 꽃다발), *오르골 만들기*(나무 세 개와 장난감 하나로 80짜리 오르골)입니다.
- *상점*에서 가구를 더 살 수 있습니다. 되팔면 최대 절반 가격만 돌려받으며, 기본 침대·식탁·책상은 사고팔 수 없습니다. 집의 가구는 45가지이며 저마다 쓰임새나 모양이 다릅니다(펫 쿠션부터 이층 침대까지의 침대, 식탁, 직업마다 여러 작업대, 소파, 빈백, 볼풀, 피아노, 러그, 수조 등). 일부는 집 레벨이 더 높아야 열리며 상점에 필요한 레벨이 표시되고, 단편 소설·꽃·의자도 마찬가지입니다. *컬렉션* 탭에는 가구 도감(모든 가구와 얻는 방법), 펫이 만든 것, 사진첩이 있습니다. 일과가 자동이 되면서 첫걸음 목표 "일과 고르기"는 "장식 하나 놓기"로 바뀌었고, 예전 저장 파일은 상태를 그대로 유지합니다. 가구 팩을 넣으면 상점과 컬렉션에 가구가 늘어납니다. 각 팩은 `pet-home-packs`(설정 탭의 *팩 폴더 열기*) 안의 폴더이며, `pack.json`(형식 `frontengine.home-pack` 버전 1, 폴더 이름과 같은 고정 ID, 이름, 출처, 라이선스, 최대 64개 가구의 ID·이름·분류·너비·단단함·상호작용 지점·용도·원하는 자세·가격·편안함)과 가구마다 `furniture/warm_home/<art>.png`(다른 테마는 선택), 그리고 `thumbnail.png`가 들어 있습니다. 알 수 없는 항목, 팩 밖으로 나가는 경로나 링크, PNG가 아니거나 2 MB를 넘는 그림, 중복 ID, 실행될 수 있는 파일이 있으면 팩 전체를 거부하고 이유를 설정 탭에 표시합니다. 팩의 내용은 절대 실행되지 않습니다. 가구 ID는 `<pack>__<id>`가 되며, 팩을 빼도 저장 파일의 가구는 남아 있다가 팩을 다시 넣으면 돌아옵니다. 두 번째 컬렉션으로 스탠드 조명, 걸이 화분, 옷장, 요, 코타츠, TV, 벽난로, 흔들목마, 망원경, 샤워실이 추가되었습니다.
- 팩은 테마도 가져올 수 있습니다(이름, 가구 그림을 빌려 쓰는 내장 테마, 바닥·낮 하늘·밤 하늘 색). 테마는 가구 탭의 테마 목록에 추가되며, 테마만 있는 팩도 괜찮습니다. 팩이 사라진 테마를 쓰는 집은 그 테마를 유지하고, 팩이 돌아올 때까지 따뜻한 집처럼 보입니다. 가구 팩, 테마, 설계도는 Steam 창작마당에도 각각의 종류로 올라갑니다. 구독한 팩과 테마는 다음에 FrontEngine을 시작할 때 집에 들어오고, 구독한 설계도는 읽기 전용 방문으로 열립니다. 설계도는 필요한 콘텐츠 팩을 적어 두며, 창작마당 목록과 방문 화면 모두 설치되지 않은 팩을 알려 줍니다.
- 페이지는 게임 화면처럼 배치됩니다. 위에는 집이 있고 날짜·시간·날씨·코인과 *시작* / *일시 정지*가 한 줄에 놓이며, 그 아래에 *주민*, *일*, *가구*, *상점*, *가방*, *목표*, *받은 편지함*, *컬렉션*, *설정* 탭이 있어 사용하는 동안에도 집이 계속 보입니다. 아직 집이 없으면 위쪽에 새 집에 딸린 침대·식탁·책상이 *집 만들기* 옆에 보입니다. 개요 아래에는 *바탕화면으로*, *가방*, *목표*와 확대/축소(− / + 또는 Ctrl+휠)가 있고, 집이 스스로 처리할 수 없는 일(입주할 펫, 읽지 않은 알림, 보관함의 가구, 재료를 기다리는 일, 준비된 축하, 소원)을 보여 주는 *기다리는 일* 목록이 있어 줄을 누르면 해당 탭이 열립니다. 배치 중에는 바탕화면 띠에 *배치 끝내기*가 표시됩니다(띠는 키보드를 받지 않기 때문). 더 새로운 FrontEngine의 저장 파일이면 *최신 FrontEngine 받기*가 나타납니다. *자유 배치*는 모든 가구를 쓸 수 있고 비용도 코인도 없는 별도의 집(``pet-home-sandbox.json``)으로 전환합니다. 거기서 한 일은 운영 중인 집과 그 코인·목표, 펫 자신의 수치에 닿지 않으며, 오갈 때는 먼저 저장하고 펫이 하던 일은 보상 없이 멈춥니다.
- 시간은 집이 실행 중일 때(*시작* / *일시 정지*)만 흐르며, FrontEngine이 꺼져 있거나 컴퓨터가 잠자던 시간은 계산하지 않습니다. 집은 설정 옆의 `pet-home.json`에 저장되고, 직전의 정상 사본은 `pet-home.json.bak`으로 남습니다. 읽을 수 없거나 더 새로운 버전의 저장 파일은 절대 덮어쓰지 않으며, 페이지에서 백업을 복원하거나 옛 파일을 남기고 새 집을 시작할 수 있습니다. 저장 실패 후 재시도에 성공하면 해당 저장의 오류 표시가 사라지고, 받은 편지함에는 오류 기록이 남습니다. 종료할 때 설정, 반려동물이나 집 상태, 메모, 이전 세션 또는 사용 기록을 저장할 수 없으면 FrontEngine은 열린 상태로 유지되어 문제를 해결한 뒤 다시 시도할 수 있습니다. 앞서 성공한 저장과 취소된 활동은 되돌리지 않습니다.

작업 목록의 접근성 이름은 인터페이스 언어에 따라 업데이트됩니다.

작업 목록에 키보드 포커스가 이동하면 작업을 선택하기 전에도 테두리가 강조됩니다.

각 프로세스에는 FrontEngine 제어 창이 하나만 있습니다. 해당 백그라운드 작업과 창의 종료가 완료될 때까지 설정 폴더를 점유하므로 다른 프로세스가 같은 폴더를 열 수 없습니다. JEditor와 PyBreeze는 내장 창을 재사용하며 저장에 실패하거나 종료가 진행 중이면 호스트 창을 유지합니다.

좁은 창에서는 집 상태 텍스트가 작업 버튼 위에 표시되고 버튼은 필요에 따라 다음 줄로 넘어갑니다. GIF 오버레이가 완전히 닫히면 원본 파일을 이동하거나 삭제할 수 있습니다.

호스트의 작업 디렉터리가 바뀌어도 펫 생성, 미리 보기, 데스크톱 펫과 집 주민의 기본 옷장과 집 이미지는 설정 페이지가 보유한 데이터 디렉터리를 사용합니다. 명시적으로 지정한 펫 자산 라이브러리는 유지됩니다. 집 사진, 앨범 및 로컬 콘텐츠 팩 폴더도 같은 데이터 디렉터리를 사용합니다. 사진 저장이 성공하면 집이 일시 정지된 상태에서도 즉시 앨범에 표시됩니다.

종료 준비 중이거나 종료 중에는 집 패널 작업을 거부하며 청사진 파일 선택 결과도 사용 전에 다시 확인합니다. 종료를 취소하면 새 작업을 허용하지만 거부된 작업을 다시 실행하지 않습니다.

집을 만든 뒤에도 좁은 창에서는 바로 가기와 긴 버튼 및 체크박스 설명이 줄 바꿈됩니다. 집 컨트롤은 패널에 맞게 줄어들며 집 그림은 자체 가로 스크롤을 유지합니다. 선택한 가구 이름과 안내는 좁은 패널에서 줄 바꿈되어 가구 탭이 다른 집 탭의 너비를 늘리지 않습니다. 집 제목과 배낭 및 컬렉션의 가구 수 표시도 좁은 패널에 맞게 줄 바꿈됩니다.

집 작업 메시지는 언어 변경에 맞춰 갱신되며 수량, 파일 경로와 원래 오류 내용을 유지합니다. 저장에 성공하면 해당 실패 알림만 지우고 더 새로운 작업 메시지는 유지합니다.

게임 속 날짜가 바뀌면 다른 생활 이벤트나 보상이 없어도 화면의 일일 의뢰가 갱신됩니다.

기존 받은 편지함 이벤트도 언어 변경을 반영하며 반복 횟수, 당시 반려동물 이름과 보상 금액을 유지합니다. 집이 일시 정지된 상태에서도 새 알림과 모두 읽음 처리가 대기 목록에 즉시 반영됩니다.

설정 페이지를 개별적으로 내장하는 호스트는 lifetime=으로 명시적인 DefaultSettingsLifetime을 전달해야 합니다. 해당 수명 주기를 닫기 전에 페이지를 저장하고 중지하며, finished 신호를 확인한 뒤 호스트를 종료해야 합니다. [Runtime lifetime API](../docs/formats/runtime-lifetime.md)
- 레이어 캐릭터(내장 INKSIDE 캐릭터나 옷장의 캐릭터)를 입은 펫은 집에서도 그 모습 그대로 나타납니다. 이동 중에는 걷고, 책상이나 안락의자에 앉고, 침대에서 자고, 식탁에서 먹고, 장난감 상자에서 놀고, 서로 인사하며, 걷는 방향을 바라봅니다. 주민의 *옷장…*은 평소의 옷장을 열고, 새 옷은 곧바로 집에 나타납니다. 캐릭터는 백그라운드에서 불러오며, 그 전까지는 색 표시로 대신합니다. 바탕화면에 나온 적이 있는 그림 펫(GIF, 그림, 스프라이트 팩)과 Puppet 펫은 집에서도 자기 모습으로 나타납니다. 스프라이트 팩은 자체 걷기·대기·잠 애니메이션을, GIF는 자체 프레임을, Puppet은 자기 캔버스에서 찍은 정지 이미지를 씁니다. 정지 그림 한 장뿐인 펫은 걸을 때 통통 튀고, 놀 때 뛰어오르며, 잘 때 웅크립니다. 쓸 수 있는 자기 모습이 없는 펫(새 펫이나 그림이 옮겨진 경우)은 늘 같은 내장 캐릭터 하나로 나타나며, 펫 자신의 모습과 바탕화면 펫은 바뀌지 않습니다. 옷을 입지 않고 기본 부위와 색을 유지한 내장 캐릭터에는 전용으로 그린 자세가 있습니다. 침대에서 자고, 안락의자에 앉고, 먹고, 놀고, 책상에서 글을 쓰고, 화단에 물을 주고, 작업대에서 망치질을 합니다(앉기·자기·먹기·놀기는 바탕 화면에서도 보입니다). 옷을 입거나 색을 바꾸면 레이어 애니메이션을 유지한 채 작업 자리에 앉습니다. 아직 예전 버전의 내장 캐릭터를 입은 펫은 옷과 색을 그대로 둔 채 자동으로 현재 버전으로 바뀝니다.
- 집에는 네 가지 *모드*가 있습니다. *보통*, 바탕화면 띠를 조용히 하는 *집중*(말풍선과 카드 없음), 집을 숨기고 일시 정지하며 그렇다고 알려 주는 *회의*, 펫의 생활 속도는 그대로 두고 띠를 초당 15프레임으로 그리는 *절전*입니다. 화면 공유 중에는 회의 모드가 됩니다. *받은 편지함*은 완료한 일, 욕구, 생활 순간, 문제를 모으며 반복은 한 줄로 합치며, 절대 팝업을 띄우거나 포커스를 가져가지 않습니다. 펫이 스스로 밥 먹고 낮잠 잔 일은 올라오지 않습니다.
- 집에는 낮과 밤, 날씨가 있습니다. 개요의 하늘은 게임 시계에 따라 새벽에서 밤으로 바뀌고, 맑음·흐림·비는 게임 시간 6시간마다 바뀌는데 집 자체로 정해지므로 매번 같습니다. 날씨는 분위기일 뿐 아무것도 망가뜨리지 않고 기다리게 하지도 않습니다. 세 가지 테마(*따뜻한 집*, *초록 작업실*, *밤의 작업실*)는 색만 바꾸고 배치는 바꾸지 않습니다. 가구는 Blender로 모델링한 윤곽선 있는 카툰 그림으로 그려지며 테마마다 색이 맞춰집니다. 가구 이름은 선택했거나 배치하는 동안에만 보입니다. 비 오는 날, 별이 빛나는 밤, 첫 단짝, 일솜씨 향상, 초록빛 집, 북적이는 집, 첫 단편, 풍년이 순간에 더해져 모두 열두 가지가 되었습니다. *움직임 줄이기*를 켜면 펫이 걸음 사이를 미끄러지지 않고 비도 멈춰 보입니다. 모든 사건은 카드와 순간 목록에도 글로 표시되며, 집은 소리를 내지 않습니다.
- 환경음은 *설정* 탭에서 켜기 전까지 꺼져 있으며, 자체 음량이 있습니다. 낮에는 새소리, 밤에는 귀뚜라미, 그런 날씨에는 빗소리나 잔잔한 겨울바람이 들립니다. 집이 일시 정지 중이거나 회의 중이거나 컴퓨터가 잠겨 있으면 조용합니다. 데스크톱 띠에서는 저녁과 밤에 가구와 반려동물이 살짝 어두워집니다. 띠의 빈 부분은 투명하게 남아 클릭이 뒤의 창으로 그대로 전달됩니다. 비나 눈이 오면 띠 위에도 빗방울이나 눈송이가 내립니다. 마우스와 포커스를 전혀 받지 않는 별도 레이어에 그려지며, 집중 모드와 회의 모드에서는 멈추고 *움직임 줄이기*에서는 정지해 있습니다.
- *목표*는 집과 함께 자랍니다. 생활 속 이정표(세 가지 일 모두 해 보기, 주민 늘리기, 가구 늘리기, 깊은 우정)로 집 레벨이 오르고, 저절로 받는 작은 보상이 있는 *첫걸음 목표* 10개(언제든 건너뛸 수 있고 나중에 다시 볼 수 있음), 연속 보상이나 놓친 날 벌칙 없이 상품을 코인으로 사 가는 하루 3건의 *의뢰*, 이루는 방법을 알려 주고 기한이 없는 펫별 작은 소원, 생일·첫 수공예품·친구들과의 저녁 같은 순간, 그리고 두 마리 이상이 함께 살며 세 가지 일을 모두 해 본 뒤 한 번 열리는 집 축하 파티가 있습니다. *사진 찍기*는 집 그림만 설정 옆 `pet-album`에 저장하며 바탕화면은 담지 않습니다. 가방에는 가구 도감 수집 현황이 표시됩니다.
- 펫에게도 편안함과 친구가 필요합니다. 침대, 안락의자, 장식이 집을 편안하게 하고, 편안함이 낮으면 기분이 나빠집니다. 펫들은 서로 인사하고 함께 밥을 먹고 놀며 가까워지고, 가끔은 마지막 빈자리를 두고 티격태격합니다. 펫마다 고정된 성격(부지런함, 장난꾸러기, 조용함, 사교적, 또는 원예·글쓰기·공예를 좋아함)이 있어 선택에 영향을 주고 좋아하는 일은 조금 더 빨리 합니다. 어떤 성격도 펫을 무언가에 맞지 않게 만들지는 않습니다. 카드에는 성격, 가장 친한 친구, 현재 행동의 남은 시간이 표시되고, 바탕화면에서는 짧은 말풍선으로 방금 시작한 일, 인사한 상대, 번 금액을 알려 줍니다. 예전 저장 파일은 불러올 때 새 욕구가 추가되며, 이 버전으로 저장한 집은 이전 FrontEngine 버전으로부터 보호됩니다.
- 반려동물은 깨끗한 것도 좋아합니다. 청결은 천천히 떨어지고(놀 때는 더 빨리), 더러워진 반려동물은 그 자리에서 몸단장을 하거나 더 빠른 욕조에서 목욕합니다. 빗질도 도움이 되며, 욕조 없는 집에 더러워진 반려동물이 있으면 집 아래 목록이 욕조를 권합니다.
- 직업은 세 가지입니다. 책상에서 글쓰기, *화분*에서 원예(허브는 식사를 더 즐겁게, 꽃은 판매 가능), 상점에서 산 나무로 *작업대*에서 공예(장난감은 판매, 의자는 바로 보관함으로). 일은 보이는 단계(파종, 물주기, 수확…)로 진행되며, 재료가 부족하면 시작하지 않고 기다립니다. *가방*에는 집이 가진 모든 것과 작업용으로 따로 둔 수량이 표시되며 상품을 팔 수 있습니다. 구매가는 항상 판매가보다 높고, 어떤 작업 사슬도 물건을 원래 자신으로 되돌리지 못합니다.
- 집은 바탕화면에도 삽니다. 화면 아래쪽 가장자리, 작업 표시줄 위에 서 있는 투명한 띠입니다. 마우스를 받는 것은 펫, 가구, 작은 ⌂ 버튼뿐이고 나머지 픽셀은 뒤쪽 창으로 클릭을 통과시키며, 띠는 포커스를 빼앗지 않습니다. 펫을 클릭하면 카드, 오른쪽 클릭하면 명령, 끌면 이동하고, 가구를 오른쪽 클릭하면 보관합니다. *바탕화면에 집 표시*로 끌 수 있고, 표시 레이어로 창 위 또는 아래를 고릅니다(기본은 위). 모두 숨기기를 하면 다시 보일 때까지 집이 일시 정지되며, 제어 센터의 화질 설정으로 초당 60·30·15프레임을 고를 수 있고 집의 시간 흐름은 바뀌지 않습니다. ⌂ 옆의 화살표를 누르면 *배치*, *주민*, *일* 버튼과 코인, 마지막으로 누른 펫, 진행 중인 일이 있는 도구 모음이 열립니다. ⌂ 메뉴에서 띠의 반대쪽 끝으로 옮길 수 있고, 열림 여부와 위치는 기억됩니다. 펫의 오른쪽 클릭 메뉴는 *먹이 주기*, *쓰다듬기*, *대화하기*(포만감·기분·교류가 조금 오르며, 종류마다 30초에 한 번까지, 다른 곳에서 쉬고 있는 펫에게는 쓸 수 없음)로 시작하고, *부탁하기*(명령), *옷장…*, *이 펫의 일…*, *전체 보기에서 따라가기*(확대한 전체 보기에서 화면 안에 둠)가 이어집니다. 가구의 오른쪽 클릭 메뉴는 용도와 사용 중인 펫을 알려 주고 *이동*(바탕화면에서 바로 배치)과 *넣어 두기*를 제공합니다. 컴퓨터를 잠그면 집도 같은 방식으로 일시 정지되며, 잠금을 풀 때까지 상태 줄에 표시됩니다. 집의 펫에게 파일을 끌어다 놓으면 먹이를 준 것으로 칩니다(마찬가지로 30초에 한 번). 파일은 열리거나 바뀌거나 지워지지 않으며 재료나 코인이 되지도 않습니다. 펫 메뉴에는 *털 손질*과 *장난감으로 놀기*(일하거나 먹거나 자는 중에는 불가), *이리 와*(오른쪽 클릭한 곳까지 걸어와 잠시 기다림), *술래잡기*(가장 가까운 한가한 펫과 함께, 바쁜 펫은 끌어들이지 않으며 둘 다 즐거워함), *사진 찍기*(전체 보기에서 그 펫을 찍어 앨범에 저장)도 있습니다.
- 띠를 작게 또는 크게 할 수 있습니다(75~200 %, 가구·반려동물·높이가 함께 바뀜). 반려동물이나 가구 위에서 Ctrl + 마우스 휠, ⌂ → *크기*, 또는 설정 탭에서 고를 수 있으며 선택은 기억됩니다. 그 크기에서 화면보다 넓은 집은 화면 안에 머물고, 마지막으로 클릭한 반려동물(또는 반려동물들)이 보이도록 부드럽게 따라갑니다. 띠의 반려동물을 두 번 클릭하면 쓰다듬습니다.
- 첫 번째 메뉴 **기능**에 모든 도구가 용도별로 모여 있습니다(미디어, 장면과 배경화면, 위젯, 집중과 눈 보호, 발표, 캡처, 펫, 자동화, 콘텐츠와 Workshop, 오버레이 관리, 설정과 도움말). *기능 검색*(Ctrl+K), *고정됨*, *최근 사용*도 있습니다. 각 항목은 예전과 같은 페이지를 열고 같은 명령을 실행하므로 단축키, 프리셋, 규칙, 휴대폰 리모컨, MIDI가 그대로 동작하며, 프리셋·설정·언어·도움말 메뉴도 그대로 들어 있습니다. 사이드바 그룹은 제목을 클릭하면 접히고 그 상태가 저장됩니다. 트레이 메뉴에 *펫 하우스 열기*가 추가되었습니다.

작업 목록이 비어 있으면 주민의 일과, 작업대, 배낭의 재료를 확인하세요. 아직 끝나지 않은 작업을 선택하면 취소 버튼을 사용할 수 있습니다.

모든 튜토리얼 목표의 보상을 받거나 목표를 건너뛰면 건너뛰기 버튼이 사라집니다. 목표 목록은 계속 확인할 수 있습니다.

### 화면에 (On screen)

미디어 오버레이. 각각 자신의 모니터를 선택하거나(모든 모니터에 걸칠 수도 있음),
드래그한 위치를 기억하며, 자체 불투명도를 가집니다.

오버레이는 기본적으로 묻지 않고 FrontEngine이 있는 화면에 열립니다. 파일을 고르면 바로 표시되고, 페이지에 끌어다 놓아도 마찬가지입니다. 파일 없이 *시작*을 누르면 선택 창이 열립니다. 텍스트나 주소 칸이 비어 있으면 경고 대화상자 대신 그 칸을 가리키며, 칸에서 Enter를 누르면 시작합니다.

- **동영상** — 볼륨, 재생 속도, 반복 기능 포함.
- **이미지** — 한 장의 사진, 슬라이드쇼로서의 폴더, 또는 **레퍼런스 보드**: 하나의
  캔버스에 여러 이미지를 올리고 각각 드래그할 수 있으며, 보드 전체를 확대·이동할 수
  있습니다.
- **웹** — URL 또는 로컬 HTML 파일, 선택적으로 상호작용 가능. **대시보드 모드**는
  URL 목록을 순환하므로, 벽면 디스플레이가 단축키나 타이머로 페이지를 넘길 수
  있습니다.
- **GIF / WebP** — 조절 가능한 속도의 애니메이션.
- **텍스트** — 글꼴, 색상, 외곽선, 정렬, 마퀴 기능이 있으며, 고정된 문자열 또는
  **라이브 소스**(시계, 날짜, 카운트다운, 스톱워치, 시스템 부하, 날씨)를 표시합니다.
  라이브 소스는 `{field}` 템플릿을 사용하며, 페이지에는 각 소스가 제공하는 필드가
  나열됩니다.
- **사운드** — 음악 재생과 저지연 WAV 효과음.
- **씬** — 위의 여러 가지를 하나의 구성으로 합칩니다. 저장하고 공유할 수 있는 JSON
  문서로 기술됩니다.
- **파티클** — OpenGL 파티클 효과.

### 데스크톱

**데스크톱 펫** — 바탕화면에 사는 애니메이션 스프라이트.

페이지는 *내 반려동물*로 시작합니다. 내장 캐릭터를 클릭하면 그 차림의 반려동물이 바로 바탕화면에 나타나고, *내 그림…*도 고를 수 있습니다. 아래에는 바탕화면의 반려동물이 *옷장*, *반려동물 불러오기*, *넣어 두기*와 함께 나열되며(두 번 클릭하면 불러옴), 다른 설정은 섹션을 열기 전까지 접혀 있습니다.

- 돌봄은 개체별 에너지와 놀이/작업/휴식 모드를 저장하며 버전 1의 UUID와 수치를 유지합니다. 스프라이트 메뉴에 인사, 쓰다듬기, 털 손질이 추가됩니다. 시간제 행동은 완료해야 보상을 주며, 배부른 펫은 먹이를 거부하고 반복 행동에는 대기 시간이 필요합니다. 돌봄은 활동 시간을 따르며 숨김 또는 오프라인 시간은 나중에 합산하지 않습니다. Puppet은 공통 세션과 먹이 규칙을 사용하며 실제 반응은 런타임과 모델 지원에 따라 달라집니다. 

- **스프라이트** — 하나의 GIF/WebP/PNG, 또는 파일 이름이 상태에 매핑되는 *펫 팩*
  폴더: `walk`, `idle`, `sleep`, `climb`, `fall`, `drag`(없는 상태는 `walk`로
  대체됩니다). 선택적 `pet.json`은 크기, 속도, 그리고 등반·대화·창에 앉기 가능
  여부를 설정합니다.
- **행동** — 중력을 받으며 바닥을 걷거나(던지면 튕깁니다), 자유롭게 돌아다니거나,
  커서를 쫓습니다. 바닥 펫은 화면 가장자리를 오르고 다른 창의 위쪽 가장자리에 섭니다.
- **삶** — 기분, 포만감, 그리고 실행 간에 유지되는 애정도. 레벨이 오르면 성장하고,
  말풍선으로 이야기하며, 자리를 비운 사이 낮잠을 자고, 배터리가 부족하면 경고합니다.
- **상호작용** — 드래그하고, 오른쪽 클릭으로 복제 / 먹이 주기 / 알림 설정을 하며,
  **파일을 그 위에 떨어뜨리세요**: 이미지나 펫 팩은 새로운 모습이 되고, 그 밖의
  것은 먹힙니다. 무엇을 먹느냐가 중요합니다 — 압축 파일은 성찬이고, 음악은 배를
  채우기보다 기분을 더 북돋우며, 문서는 소박한 식사이고, 바이너리는 씹기 너무
  어렵습니다.
- **술래잡기** — 화면에 둘 이상의 펫이 있을 때 *서로 술래잡기하기*를 체크하면 하나가
  "술래"가 됩니다: 가장 가까운 이웃을 향해 걸어가고 나머지는 반대로 달아나며,
  누군가를 잡으면 술래를 넘깁니다.
- **소리에 반응** — 펫이 스피커 출력에 맞춰, 또는 **마이크**에 맞춰 고동치므로 말할
  때 움직입니다. 둘 다 출력 *미터*만 읽습니다 — 오디오가 아니라 숫자입니다. 피크는
  RMS 윈도우와 빠른 어택/느린 디케이 엔벨로프로 부드럽게 처리되어, 깜빡이는 대신
  숨쉬듯 고동칩니다. 모니터가 여러 개일 때 각 펫은 자기 화면에 맞는 오디오 엔드포인트를
  따릅니다.
- **집중 타이머** — 같은 페이지의 뽀모도로로, 펫이 알려줍니다: 집중이 끝날 때와
  휴식이 끝날 때를 말해줍니다.
- **채팅** — `ANTHROPIC_API_KEY`가 설정되어 있으면 펫이 Claude를 통해 대답할 수
  있습니다. 활성화하지 않는 한 꺼져 있습니다. [기기에서 나가는 것](#what-leaves-the-machine)을
  참조하세요.

**배경화면** — 이미지와 애니메이션 폴더를 모든 창 *아래에서* 재생합니다. 각 모니터는
자체 타이머로 자기 폴더를 가리키며, 섞거나 재귀적으로 읽을 수 있고, 스피커 레벨에
맞춰 고동칠 수 있습니다. 두 번째 폴더는 조용한 시간대에 대신 나설 수 있습니다.

**위젯** — 바탕화면에 놓이는 네 가지:

- **오디오 스펙트럼** — 막대 또는 링 형태, 로그 간격 대역, 빠른 어택/느린 디케이
  팔로워로 부드럽게 처리되며, 아래로 흘러내리는 피크 마커가 있습니다.
- **재생 중** — 선택적 `winsdk` 바인딩이 설치되어 있으면 Windows의 미디어 컨트롤에서
  가져온 현재 트랙; 그렇지 않으면 실제로 소리를 내고 있는 앱의 이름.
- **시스템 모니터** — CPU, 메모리, 디스크, 배터리, 네트워크 처리량을 작은
  스파크라인으로; 원하는 선을 체크하세요. 평균은 멈춤을 숨기지만 선은 그렇지
  않습니다. 숨긴 선도 계속 기록하므로, 다시 켜면 그동안 무슨 일이 있었는지
  보여줍니다.
- **스티키 노트** — 모든 창 위의 편집 가능한 카드로, 세션 간에 텍스트, 색상, 위치를
  유지합니다.
  전체 렌더링 백엔드를 변경해도 스티키 노트의 텍스트는 계속 표시되며 편집할 수 있습니다.

### 작업 (Work)

**집중** — 화면이 작업과 경쟁할 때를 위한 두 가지 오버레이. *배경 창 어둡게*는 작업
중인 창을 제외한 모든 것을 조절 가능한 세기로 어둡게 합니다. *방해 요소 가리기*는
화면의 일부를 가립니다: 작업 표시줄, 알림 모서리, 가장자리, 또는 전체. 둘 다 클릭을
통과시키므로 가려진 것도 그대로 작동합니다 — 다만 시선을 끄는 일이 멈출 뿐입니다.

**화면 케어** — 화면 앞에서 긴 시간을 보낼 때를 위해:

- **색상 필터** — 따뜻한 색부터 앰버, 로즈, 회색까지 일곱 가지 색조를 조절 가능한
  세기로.
- **읽기 자** — 페이지를 어둡게 하고 커서를 따라가는 밝은 띠를 남깁니다.
- **휴식 알림** — 20-20-20 규칙으로, 간격이 되면 휴식 오버레이를 띄웁니다.
- **색각 시뮬레이션** — Machado 외(2009) 모델을 사용해 적색맹, 녹색맹, 청색맹,
  전색맹을 조절 가능한 정도로. 다른 오버레이와 달리 이것은 불투명한데, 다른 사람이
  보는 것을 보여주려면 화면에 색조를 입히는 것이 아니라 다시 그려야 하기 때문입니다.

**프레젠테이션** — 데모, 수업, 녹화를 위해:

- **주석** — 펜, 형광펜, 지우개로 화면 위에 그리며, 실행 취소와 지우기 기능이
  있습니다.
- **커서 효과** — 포인터 주위의 링, 클릭 시 파문, 그리고 나머지를 어둡게 하는
  스포트라이트.
- **키 입력 표시** — 방금 누른 키와 클릭한 마우스 버튼을 보여주어 시청자가 따라올 수
  있게 하며, 몇 초 후에 사라집니다. 패널이 놓일 위치와 텍스트 크기를 고르고, 마우스
  클릭만 따로 끌 수 있습니다.
- **돋보기** — 커서 주변 영역의 확대된 뷰.
- **화이트보드** — 무한 캔버스: 드래그로 이동, 스크롤로 확대, 그린 것을 저장.
  선은 캔버스 좌표에 존재하므로, 이동하고 확대해도 제자리에 남습니다.
- **정지** — 모니터의 현재 프레임을 고정해 정지 이미지 뒤에서 계속 작업할 수
  있습니다. `Ctrl+Shift+F7`이 해제하는데, 정지된 이미지가 그 역할을 할 버튼을 덮기
  때문에 중요합니다.

**도구** — 측정, 캡처, 창 처리:

- **색상 선택기 / 픽셀 자 / 각도기** — 클릭으로 샘플링하거나 측정합니다. 결과는
  `#rrggbb`, `rgb(...)`, `hsl(...)` 또는 CSS 사용자 지정 속성 형태로 바로
  클립보드에 들어갑니다.
- **영역 캡처** — 영역을 드래그하세요. 클립보드에 들어가고, 파일로 저장하거나, 위에
  떠 있는 확대 가능한 사본으로 **고정**할 수 있습니다.
- **영역 녹화** — 녹화: 영역을 선택하고 캡처 시작 전에 출력 GIF를 고릅니다. 취소하면 녹화를 시작하지 않습니다. 백그라운드에서 프레임을 순차 기록하며 큐는 3프레임과 64 MiB로 제한됩니다. 너무 큰 단일 프레임은 거부합니다. 큐가 가득 차면 캡처를 건너뛰고 재생에 실제 경과 시간을 반영합니다. 프레임률, 시간, 프레임 수 제한과 카메라 삽입 화면은 유지됩니다. 중지는 비동기로 파일을 완성하며 성공 후에만 대상을 원자적으로 교체합니다. 취소와 쓰기 오류는 임시 파일을 지우고 기존 대상 파일을 보존합니다.
- **카메라** — 원, 둥근 상자, 사각형 형태의 웹캠으로, 로컬에서만 표시되고 절대
  녹화되지 않습니다. 캡처 카드를 포함한 모든 비디오 입력이 작동하며, 카드는 보통 앱이
  이미 실행 중일 때 꽂으므로 장치 목록은 재시작 없이 새로 고쳐집니다.
- **가상 카메라** — 오버레이까지 포함한 영역을, Zoom, Teams, Discord가 비디오
  소스로 선택할 수 있는 웹캠으로 보냅니다. 선택적 `pyvirtualcam` 패키지와 가상 카메라
  드라이버(OBS가 하나 설치합니다)가 필요합니다. 둘 중 하나라도 없으면, 버튼이 조용히
  실패하는 대신 그 사실을 알립니다.
- **텍스트 읽기** — 화면 글자: 도구 → 텍스트 읽기는 먼저 로컬 OCR을 사용합니다. Windows는 Windows.Media.Ocr, macOS는 Vision, 또는 실행 파일과 언어 데이터가 설치된 Tesseract를 사용합니다. 로컬 추출에는 클라우드 동의나 ANTHROPIC_API_KEY가 필요 없고, 성공한 빈 결과도 스크린샷을 업로드하지 않습니다. 번역과 질문은 별도 텍스트 동의 및 키가 있을 때만 인식한 텍스트를 Anthropic으로 보낼 수 있습니다. 로컬 실패 후 스크린샷 대체 처리는 별도 캡처 동의와 키가 필요합니다. 결과는 백엔드와 오류를 표시하며 동의를 철회할 수 있습니다.
- **창 고정** — 다른 프로그램의 창을 위에 유지하거나 흐리게 하면서, 그것을 참고해
  작업합니다. 스태킹과 불투명도만 건드리며, 창 내용은 절대 건드리지 않습니다.
- **창 복제** — 다른 창의 작지만 항상 위에 뜨는 라이브 사본으로, 렌더링이나 채팅이
  묻혀 있는 동안에도 지켜볼 수 있습니다.
- **창 레이아웃** — 모든 창이 놓인 위치를 저장하고 나중에 되돌립니다. 창은 제목으로
  매칭되며, 화면에 없는 창은 추측하지 않고 건너뜁니다.

## 모든 것을 한 번에 제어하기

**컨트롤 센터** 페이지는 어느 탭에서 열었든 상관없이, 모든 페이지의 모든 오버레이에
닿습니다: 숨기기, 보이기, 닫기, 음소거, 잠금, 위치 초기화, 불투명도 단계 조절, 그리고
각 오버레이의 새로 고침 속도를 제한하고 렌더링 해상도를 낮추는 **품질 등급**(고급 /
균형 / 절약) 적용. 또한 OBS용 크로마키 배경, *캡처에서 숨기기* 토글, 로그 패널,
그리고 **이 데스크톱에 고정** 기능도 갖추고 있습니다 — 가상 데스크톱을 전환하면
오버레이가 비켜서고 돌아오면 다시 나타납니다. 고정을 해제하면 치워두었던 것을 모두
되돌립니다.

기본 전역 단축키, 모두 **Settings → Hotkeys**에서 재설정 가능:

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+F12` | 모든 오버레이 닫기 |
| `Ctrl+Shift+F11` / `F10` | 모든 오버레이 숨기기 / 보이기 |
| `Ctrl+Shift+F9` | 모두 음소거 |
| `Ctrl+Shift+↑` / `↓` | 불투명도 올리기 / 내리기 |
| `Ctrl+Shift+L` | 잠금 또는 잠금 해제 (클릭 통과 vs 드래그 가능) |
| `Ctrl+Shift+→` | 다음 대시보드 페이지 |
| `Ctrl+Shift+F8` | 단축키 시트를 화면에 표시 |
| `Ctrl+Shift+F7` | 화면 정지 / 정지 해제 |
| `Ctrl+Shift+F6` / `F5` / `F4` | 미디어 재생/일시정지, 다음 및 이전 트랙 |
| `Ctrl+Shift+F3` | 포그라운드 창을 다음 모니터로 이동 |
| `F12` | 즉시 종료 (Windows / macOS*) |

미디어 트랜스포트는 시스템 미디어 키를 보내므로, 그것을 수신하는 모든 플레이어에
닿습니다. 창을 옮길 때는 Windows 자체의 `Win+Shift+Arrow`처럼 화면을 가로질러
붙이는 대신 비율을 유지합니다.

원격 제어가 구동하는 것은 동일한 동작이며 — 그 이상은 아닙니다:

- **당신의 휴대폰** (Settings → Remote control) — FrontEngine이 로컬 네트워크에 작은
  페이지를 제공합니다. 휴대폰에서 링크를 열면 버튼이 그 동작들을 구동합니다.
- **MIDI 컨트롤러** — Learn을 누르고 노브나 패드를 조작해 연결합니다. Windows는 내장 winmm을, macOS는 macos extra의 CoreMIDI를 사용합니다. 노브는 최상단에서 한 번만 실행되고 패드에서 손을 떼는 것은 추가 누름이 아닙니다.

## 프리셋과 자동화

**프리셋**은 모든 페이지의 설정을 한 번에 담습니다. **Presets** 메뉴에서 저장,
불러오기, 삭제, 내보내기, 가져오기를 하고, 실행 시 하나를 적용하거나, 이전 세션을
자동으로 복원할 수 있습니다. 프리셋은 **패키지**로 내보낼 수 있습니다 — 참조하는
미디어를 담은 zip이므로 — 그 파일이 없는 기기에서도 열립니다.

그런 다음 스스로 결정하는 것들, 모두 **Settings** 메뉴에 있습니다. 스마트 일시정지만
처음부터 켜져 있고, 나머지는 켜기 전까지 꺼져 있습니다.

| | |
| --- | --- |
| **규칙** | *"이 조건들이 성립하면 이것을 하라."* 요일, 시간대, 그리고 어느 애플리케이션이 포커스를 가졌는지를 조합한 뒤, 프리셋을 적용하거나, 오버레이를 숨기기/보이기/닫기 하거나, 품질을 설정합니다. 빈 조건은 "아무거나"를 뜻하며, 규칙은 조건이 성립하는 동안 반복적으로가 아니라 성립하기 **시작할 때 한 번** 실행됩니다. 이곳이 조건이 조합되는 유일한 곳이며, 아래의 각 행은 단일 종류만 압니다. |
| **스마트 일시정지** | 전체 화면 앱이 실행되는 동안, 기기가 배터리로 작동하는 동안, 또는 지정한 앱이 포커스를 가진 동안 오버레이를 물러서게 합니다. *(전체 화면 규칙에 한해 기본으로 켜짐.)* |
| **앱 프로필** | 지정한 앱으로 전환할 때 프리셋을 적용합니다. |
| **프리셋 예약** | 선택한 요일의 정해진 시간에 프리셋을 적용합니다. |
| **테마** | 시스템을 따르거나 항상 밝게 또는 어둡게(*설정 → 테마*). 창은 내장 캐릭터의 먹색, 종이색, 주황색을 쓴 FrontEngine 고유 디자인을 사용하며, 이전 버전의 설정은 밝거나 어두운 모습을 그대로 유지합니다. |
| **테마 예약** | 시계에 맞춰 낮 테마와 밤 테마를 전환합니다. |
| **사이니지 모드** | 메인 창을 치워둔 채 프리셋 목록을 타이머로 순환합니다. 디스플레이로 계속 켜둔 기기를 위한 것입니다. |
| **화면 보호기** | 유휴 임계값을 넘으면 선택한 동영상 / 이미지 / GIF / 파티클 / 웹 페이지를 띄우고, 돌아오면 내립니다. |
| **알림** | N분마다, 또는 하루에 한 번 정해진 시간에, 스스로 닫히는 토스트로 표시됩니다. |
| **깨어 있기** | 오버레이가 떠 있는 동안 디스플레이가 절전되지 않게 합니다. |
| **시스템과 함께 시작** | 로그인 시 실행합니다. |
| **화면 시간** | 어느 앱이 얼마나 오래 포커스를 가졌는지를, 일일 세부 내역과 7일 요약과 함께. 키보드에서 떨어져 있는 동안 일시정지되고, 최대 60일을 보관하며, 지우기는 파일 자체를 삭제합니다. |
| **클립보드 기록** | 복사한 것을 검색하고 자주 쓰는 문구를 고정하세요. 클립보드는 흔히 비밀번호를 담으므로, "세션 간 유지"를 따로 체크하지 않는 한 **메모리에만** 보관됩니다. |

## 언어

일곱 가지: English, 繁體中文, 简体中文, Deutsch, Русский, Français, Italiano.

**Language** 메뉴에서 하나를 고르면 인터페이스가 **즉시** 바뀝니다 — 재시작 없이.
열어두었던 것은 그대로 열려 있습니다: 오버레이는 계속 실행되고, 모든 페이지의 설정은
있던 그대로 남습니다. Steam 설치판에서는 첫 실행 시 Steam 클라이언트 자체의 언어를
따릅니다.

## 개인정보 및 플랫폼 참고 사항

### 기기에서 나가는 것

FrontEngine의 모든 것은 이 목록에 있지 않는 한 로컬입니다. 예외는 네 가지이며, 모두
옵트인입니다:

| Feature | Where it goes | Guard |
| --- | --- | --- |
| **텍스트 읽기** (Tools) | Anthropic API | 화면 글자: 도구 → 텍스트 읽기는 먼저 로컬 OCR을 사용합니다. Windows는 Windows.Media.Ocr, macOS는 Vision, 또는 실행 파일과 언어 데이터가 설치된 Tesseract를 사용합니다. 로컬 추출에는 클라우드 동의나 ANTHROPIC_API_KEY가 필요 없고, 성공한 빈 결과도 스크린샷을 업로드하지 않습니다. 번역과 질문은 별도 텍스트 동의 및 키가 있을 때만 인식한 텍스트를 Anthropic으로 보낼 수 있습니다. 로컬 실패 후 스크린샷 대체 처리는 별도 캡처 동의와 키가 필요합니다. 결과는 백엔드와 오류를 표시하며 동의를 철회할 수 있습니다. |
| **펫 채팅** | 당신의 메시지가 Anthropic의 API로 갑니다 | 같은 키, 같은 규칙. 기본으로 꺼져 있습니다. |
| **날씨** (텍스트 소스) | 좌표가 Open-Meteo로 갑니다 | 키 없음, 계정 없음, 식별 데이터 없음. 위치로 입력한 것만. |
| **휴대폰 원격** | HTTPS | 휴대폰 제어: 설정 → 원격 제어는 HTTPS만 제공하고 시작마다 바뀌는 토큰과 고정 동작 목록을 사용합니다. 휴대폰은 자체 서명 인증서를 자동으로 신뢰하지 않습니다. 공개 인증서를 내보내고 표시된 SHA-256 지문을 비교한 뒤 휴대폰/브라우저 설정에서 가져오거나 신뢰하세요. 개인 키는 사용자 데이터 폴더에 남습니다. IP 변경, 만료, 재생성 시 새 인증서를 신뢰해야 할 수 있습니다. TLS 시작 실패 시 HTTP로 돌아가지 않습니다. |

오디오 기능은 출력 **미터**만 읽습니다 — 하나의 숫자 — 단, 주파수를 계산하려면 실제
샘플이 필요해 시스템 출력 스트림을 캡처하는 스펙트럼은 예외입니다. 그 샘플은
메모리에서 분석되고, 디스크에 기록되거나 어디로도 전송되지 않으며, 스펙트럼을 멈추는
순간 캡처도 멈춥니다.

플러그인: 로딩을 켜도 플러그인이 승인되지는 않습니다. plugin.json이나 단일 파일 sidecar에 버전, 식별자, 진입점, 기능을 선언합니다. Python import 전에 동의를 확인하고 내용 해시에 연결합니다. 코드나 선언이 바뀌면 다시 승인해야 하며 기존 플러그인은 명시적으로 완전 신뢰해야 합니다. 설정에서 플러그인 승인을 철회할 수 있습니다. 실행 중 코드를 내리려면 재시작하세요. Python 플러그인은 여전히 전체 앱 권한으로 실행되며 선언과 동의는 OS 샌드박스가 아닙니다.

### 화면 공유 개인정보

당신의 오버레이는 당신을 위한 것이지, 공유하는 상대를 위한 것이 아닙니다. **Settings →
Screen-sharing privacy**에서 FrontEngine은 회의 앱이 열려 있는 동안 오버레이를 캡처
밖으로 빼낼 수 있습니다:

- **당신 자신의 화면에는 그대로 남습니다.** 캡처된 사본만 비어 있습니다 — 이것은
  Windows의 `WDA_EXCLUDEFROMCAPTURE`를 사용하며, 회의 앱과 녹화기가 존중하는
  OS 수준의 플래그입니다.
- **마스크는 예외입니다.** 방해 요소 마스크는 무언가를 가리기 위해 존재하므로,
  캡처에서 의도적으로 계속 보입니다.
- **트리거는 당신의 목록입니다.** Windows에는 신뢰할 만한 "내가 캡처되고 있는가" API가
  없으므로, 당신이 지정한 창 제목을 감시합니다 — 이는 브라우저 탭에서 열린 회의도
  잡아내는데, 그 경우 실행 파일은 그냥 브라우저이기 때문입니다.

컨트롤 센터에도 수동 *캡처에서 숨기기* 버튼이 있습니다.

> 이것은 개인정보이지 보안이 아닙니다: 일반적인 캡처 경로를 무력화하며, 책상에 앉은
> 사람에게서는 아무것도 숨기지 않습니다.

### 플랫폼 지원

여기에 나열되지 않은 모든 것은 세 플랫폼 모두에서 작동합니다.

| 공통 오버레이와 UI | ✅ | ✅ | Qt / X11 |
| 시스템 오디오, 스펙트럼, 마이크 | ✅ | backend* | Pulse† |
| 재생 중 트랙 정보 | ✅ | — | — |
| 창 기하, 배치, 모니터 이동 | ✅ | backend* | X11† |
| 실시간 창 복제 | ✅ | backend* | — |
| 다른 창 최상위 / 불투명도 | ✅ | — | X11† |
| 캡처에서 오버레이 제외 | ✅ | — | — |
| MIDI 제어 | ✅ | backend* | — |
| 미디어 키 | ✅ | backend* | — |
| 가상 데스크톱 / Space 선택 | ✅ | — | — |
| F12 긴급 종료 | ✅ | backend* | — |
| 다른 창 위에 서는 펫 | ✅ | backend* | wmctrl |

* macOS의 backend 항목은 macos extra, macOS 13+, 해당 권한이 필요합니다. 공개 framework 경로 구현을 뜻하며 이 Windows 환경의 macOS 실기 검증을 뜻하지 않습니다. 아래 실행 환경 설명을 참고하세요.

기능이 작동할 수 없는 곳에서는 버튼이 조용히 실패하는 대신 그 사실을 알립니다.

## 실행 환경, 개인정보 및 상호 운용

녹화: 영역을 선택하고 캡처 시작 전에 출력 GIF를 고릅니다. 취소하면 녹화를 시작하지 않습니다. 백그라운드에서 프레임을 순차 기록하며 큐는 3프레임과 64 MiB로 제한됩니다. 너무 큰 단일 프레임은 거부합니다. 큐가 가득 차면 캡처를 건너뛰고 재생에 실제 경과 시간을 반영합니다. 프레임률, 시간, 프레임 수 제한과 카메라 삽입 화면은 유지됩니다. 중지는 비동기로 파일을 완성하며 성공 후에만 대상을 원자적으로 교체합니다. 취소와 쓰기 오류는 임시 파일을 지우고 기존 대상 파일을 보존합니다.

휴대폰 제어: 설정 → 원격 제어는 HTTPS만 제공하고 시작마다 바뀌는 토큰과 고정 동작 목록을 사용합니다. 휴대폰은 자체 서명 인증서를 자동으로 신뢰하지 않습니다. 공개 인증서를 내보내고 표시된 SHA-256 지문을 비교한 뒤 휴대폰/브라우저 설정에서 가져오거나 신뢰하세요. 개인 키는 사용자 데이터 폴더에 남습니다. IP 변경, 만료, 재생성 시 새 인증서를 신뢰해야 할 수 있습니다. TLS 시작 실패 시 HTTP로 돌아가지 않습니다.

화면 글자: 도구 → 텍스트 읽기는 먼저 로컬 OCR을 사용합니다. Windows는 Windows.Media.Ocr, macOS는 Vision, 또는 실행 파일과 언어 데이터가 설치된 Tesseract를 사용합니다. 로컬 추출에는 클라우드 동의나 ANTHROPIC_API_KEY가 필요 없고, 성공한 빈 결과도 스크린샷을 업로드하지 않습니다. 번역과 질문은 별도 텍스트 동의 및 키가 있을 때만 인식한 텍스트를 Anthropic으로 보낼 수 있습니다. 로컬 실패 후 스크린샷 대체 처리는 별도 캡처 동의와 키가 필요합니다. 결과는 백엔드와 오류를 표시하며 동의를 철회할 수 있습니다.

Puppet 펫: 선택 puppet extra와 사용 가능한 Imervue runtime을 설치한 뒤 펫 페이지에서 원본 Imervue .puppet v1을 선택하거나 놓습니다. 기존 이미지와 스프라이트 팩은 계속 사용할 수 있습니다. Puppet은 Imervue 캔버스, 동작, 표정을 사용하며 복제/닫기, FrontEngine 오버레이 제어 및 프리셋을 지원합니다. 선택 .petscript.json은 기존 Imervue 스크립트 엔진을 사용합니다. FrontEngine pet.json 팩은 puppet 파일이 아닙니다. 알 수 없는 버전, 위험한 압축 경로, 잘못된 자원은 로딩 전에 거부합니다.

Puppet 펫도 스스로 산책합니다. 몇 초 쉰 뒤 지금 높이에서 왼쪽이나 오른쪽으로 걷기 동작과 함께 조금 걸어가고, 화면 작업 영역 밖으로는 나가지 않으며, 다시 쉽니다. 드래그, 쓰다듬기, 이리 와와 장난감, 입력 중 얌전히 있기, 스스로 움직이지 않는 모드가 우선합니다.

"행동" 메뉴의 기본값 "모든 동작 순환(무작위)"에서는 펫이 모든 동작 중에서 다음에 할 일을 무작위로 고르고, "바닥 걷기"는 걷기와 대기만 합니다. 스프라이트 펫은 걷기, 대기, 앉기, 놀기, 털 고르기, 가까운 벽으로 가서 오르기, 손 흔들기, 잠자기, 축하하기, 옷 자랑하기 중에서 고르고, Puppet 펫은 산책과 제자리에서 앉기·놀기·털 고르기·손 흔들기·축하하기 중에서 고릅니다. 불러낸 펫은 곧바로 걷기 시작합니다. 포즈는 제자리에서 취하며, 해당 포즈 이미지가 없는 펫은 대기 이미지를 보여 줍니다.

장면: 기존 엔트리 매핑 JSON, 버전이 있는 frontengine.scene, 이동 가능한 .fescene 패키지를 읽습니다. PUPPET에는 위치, 크기, 불투명도, 유한 숫자 매개변수와 선택 동작, 표정, 스크립트를 설정할 수 있습니다. JSON 경로는 장면 파일을 기준으로 해석합니다. .fescene은 참조 미디어, 원본 .puppet, 선택 .petscript.json을 포함해 다른 컴퓨터로 옮길 수 있습니다. 가져오기는 경로, 심볼릭 링크, 버전, 압축 해제 한도를 검사합니다. FrontEngine 장면은 장면 패키지이며 .puppet은 한 Imervue 캐릭터입니다.

macOS: 선택 macos extra는 macOS 13+와 공개 PyObjC framework를 사용합니다. ScreenCaptureKit 화면/창 캡처와 시스템 오디오, 마이크, Quartz 창 기하, Accessibility 창 배치/이동, CoreMIDI, 미디어 키, F12 종료를 제공합니다. 화면 기록, 손쉬운 사용, 마이크 권한을 따로 확인합니다. 시스템 설정 → 개인정보 보호 및 보안에서 허용하고 안내에 따라 재시작하세요. 다른 앱 창의 불투명도/강제 최상위, Space 선택, 다른 앱 캡처에서 오버레이 제외는 지원하지 않습니다. 이 Windows 개발 컴퓨터에서는 macOS의 실제 권한, 하드웨어, 성능을 검증하지 않았습니다. 설정 → macOS 권한 및 기능에서 각 기능을 사용 가능, 사용 불가, 미지원으로 표시하고 권한 또는 설치 관련 이유를 안내합니다.

플러그인: 로딩을 켜도 플러그인이 승인되지는 않습니다. plugin.json이나 단일 파일 sidecar에 버전, 식별자, 진입점, 기능을 선언합니다. Python import 전에 동의를 확인하고 내용 해시에 연결합니다. 코드나 선언이 바뀌면 다시 승인해야 하며 기존 플러그인은 명시적으로 완전 신뢰해야 합니다. 설정에서 플러그인 승인을 철회할 수 있습니다. 실행 중 코드를 내리려면 재시작하세요. Python 플러그인은 여전히 전체 앱 권한으로 실행되며 선언과 동의는 OS 샌드박스가 아닙니다.

렌더링: 설정 → 오버레이 렌더링에서 Auto, GPU, Software를 선택하고 실제 백엔드를 확인합니다. GPU 합성기는 OpenGL 텍스처, 셰이더, 프레임버퍼로 순서, 변환, 불투명도, 클리핑을 처리하며 초기화 실패 시 이유와 함께 소프트웨어로 돌아갑니다. QPainter 콘텐츠는 CPU에서 래스터화한 뒤 업로드할 수 있고 web/video/네이티브 widget은 별도 창을 사용할 수 있습니다. 캡처나 녹화가 GPU 프레임을 CPU로 읽어올 수 있습니다. 무복사 캡처나 측정된 속도 향상을 보장하지 않습니다. 오버레이를 다시 그릴 때는 부모 창의 그리기가 끝난 뒤 합성기를 갱신하도록 예약합니다. 백엔드나 모니터를 전환할 때도 같은 순서를 따릅니다.

선택 기능은 아래 명령으로 설치합니다. Windows OCR의 WinRT projection 패키지는 Windows용 FrontEngine 기본 설치에 포함되며 Windows 인식 언어를 추가해야 합니다. Tesseract 실행 파일과 언어 데이터는 따로 설치합니다. puppet extra는 Imervue>=1.0.90을, macos extra는 macOS 13+용 PyObjC framework를 추가합니다. 형식과 예제는 docs/formats/를 참고하세요.

```bash
pip install "frontengine[puppet]"
pip install "frontengine[macos]"
```

## 확장

- **Steam Workshop** — 구독한 항목은 Steam 자체의
  `steamapps/workshop/content` 폴더에서 가져옵니다: 프리셋은 임포트되고 펫 팩은

  신뢰 관련 참고를 읽으세요.

## 개발

```bash
pip install -r dev_requirements.txt
pip install -e .

python -m pytest tests/ -q          # the whole suite, headless (Qt offscreen)
```

정적 검사는 pyflakes(`dev_requirements.txt`에 포함)를 사용하며, 깨끗한 트리는 아무것도
출력하지 않습니다:

```bash
python -m pyflakes frontengine/ exe/ tests/
```

테스트 스위트는 전적으로 오프스크린으로 실행되며 디스플레이, 사운드 카드, 카메라가
필요 없습니다. 외부 세계에 닿는 것은 무엇이든 주입 가능한 소스를 취해 가짜로 테스트할
수 있습니다.

- **아키텍처** — [`architecture_explore.md`](../architecture_explore.md)는 모든

## 지속적 통합과 릴리스

작업은 `feature → dev → main`으로 흐르며, 마지막 단계만 게시합니다:

```
feat/xyz  ──PR──►  dev  ──PR──►  main
                    │              │
              CI, no release   CI + release
```

| Workflow | Trigger | Purpose |
| --- | --- | --- |
| `CI` (`ci.yml`) | `main` 또는 `dev`로의 Push / PR, 수동 디스패치, 또는 `Nightly`가 호출 | 컴파일하고, 유닛 테스트를 실행한 뒤, *그 체크아웃*에서 wheel을 빌드해 설치하고 앱을 시작 — Python 3.11 / 3.12, Windows에서 |
| `Nightly` (`nightly.yml`) | 매일 cron, 수동 디스패치 | `CI`를 호출합니다. 스케줄이 일부러 여기 있습니다: GitHub은 cron을 담은 워크플로를 약 60일간 비활성 상태면 비활성화하는데, 그렇지 않으면 그것이 PR 검사까지 함께 무너뜨리기 때문입니다 |
| `Release` (`release.yml`) | **`dev`에서 온** 풀 리퀘스트가 `main`에 병합되거나, 수동 디스패치 | 버전을 올리고, `[skip ci]`와 함께 되커밋하며, `stable.toml` → `pyproject.toml`을 바꾸고, sdist + wheel을 빌드해 PyPI에 `frontengine`으로 업로드하고, `v<version>` 태그가 붙은 GitHub 릴리스를 만들며, `dev`를 fast-forward 합니다 |

게시는 **`dev`가 `main`에 병합될 때만** 일어납니다. 기능은 버전을 만들지 않고 `dev`에
안착하며, 릴리스는 의도적인 `dev → main` 풀 리퀘스트입니다. 실수로 `main`을 겨냥한
기능 PR도 병합은 되지만 게시하지는 않습니다 — 실패의 방향은 원치 않는 릴리스가 아니라
누락된 릴리스입니다.

패치 세그먼트는 자동으로 올라갑니다. 마이너 또는 메이저 릴리스는 *Actions → Release →
Run workflow*를 실행해 세그먼트를 고르세요. 그 경로는 실패한 게시를 새 병합 없이 다시
실행하기도 합니다.

버전은 두 파일에 존재합니다: `pyproject.toml`은 dev 패키지(`frontengine_dev`)이고
`stable.toml`은 게시되는 것(`frontengine`)입니다.

저장소 시크릿 하나가 필요합니다: `PYPI_API_TOKEN`, `frontengine` 프로젝트로 범위가
한정된 PyPI 토큰. 워크플로는 twine 사용자명으로 `__token__`을 사용하므로, 토큰 자체만
저장하면 됩니다.

Workshop 콘텐츠 매니페스트는 버전을 포함하며 사용 전에 검증됩니다. 알 수 없는 메타데이터 JSON은 프리셋으로 처리하지 않습니다. 프리셋 패키지는 안전하지 않은 경로, 리소스 한도 초과 및 미디어 파일 이름 충돌을 거부합니다.

프리셋 → Workshop 관리에서 Steam 관리 창을 엽니다. 장면과 반려동물 페이지에도 진입점이 있습니다. Windows x64에서는 온라인 Steam 클라이언트, App 2793470 세션 및 steam_api64.dll이 필요합니다. 저장한 .fescene/장면 JSON, 프리셋 ZIP 또는 sprite 동물 폴더를 1 MB 미만 PNG/JPEG 미리보기와 함께 게시합니다. 새 항목은 기본적으로 비공개이며 업데이트 시 소유자를 확인합니다. 업로드는 진행률과 약관 상태를 표시하고 재시도용 ID를 저장하며 창을 숨겨도 계속됩니다. 중단된 결과는 Steam에서 확인하세요. 구독은 검증 후 별도 버전 폴더에 복사하며 로컬 변경 충돌 시 새 버전 또는 로컬 버전을 선택합니다. 불러온 콘텐츠는 해당 페이지에서 재생합니다. 프리셋 가져오기는 새 이름을 사용합니다. 오프라인 폴더 가져오기도 유지됩니다. Steam 빌드는 exe/build_exe.py에 --steam-runtime DLL경로를 추가하며 DLL은 실행 파일 옆에 놓입니다(--onefile 포함). SDK와 개발용 steam_appid.txt는 포함하지 않습니다. 반려동물 집의 가구 팩과 테마는 팩 폴더에서 게시되며(`pack.json`, 미리보기, 가구 그림만 복사), 설계도는 파일에서 확인된 부분만으로 다시 써서 게시하므로 반려동물, 이름, 코인, 채팅, 설정이 함께 나가지 않습니다. 설계도가 쓰는 콘텐츠 팩은 매니페스트에 적힙니다.

Windows 설치에 winrt-Windows.Media.Control이 포함되어 재생 중 위젯이 SMTC의 곡명과 아티스트를 표시합니다. 기존 winsdk도 지원합니다. 미디어 세션이 없으면 빈 결과를 반환하며 기존 오디오 앱 이름 대체 표시를 유지합니다.

실행 파일 빌드는 컴파일 전에 필수 의존성과 버전을 확인합니다. 빌드 환경에 requirements.txt를 먼저 설치하세요.

장면 → 시각 편집은 이미지/GIF/텍스트 레이어 목록과 미리보기, 그룹 이동, 모서리 크기 조정, 위치/크기/배율/회전/순서/불투명도, 정렬, 배치 잠금, 표시, 복제 및 100단계 실행 취소/재실행(Ctrl+Z/Ctrl+Y)을 제공합니다. .fescene을 직접 내보내며 스크립트 탭에서 JSON을 편집·적용할 수 있습니다. 재생은 명시된 크기, 배율, 회전, 표시 상태를 복원합니다. 외부 JSON을 불러오거나 적용하면 새 취소 기록을 시작하며 기존 필드는 유지합니다.

메뉴의 명령 또는 FrontEngine에서 Ctrl+K / Ctrl+Shift+P로 엽니다. 현재 언어, 영어 이름, 고정 명령 이름을 검색하고 위/아래 키로 선택하여 Enter로 실행합니다. 페이지 이동, 캡처, 메모, 화면 필터, Workshop 및 기존 전역 동작을 지원합니다. 프리셋/품질에는 값을 입력할 수 있습니다. 즐겨찾기와 최근 20개 명령은 재시작 후 유지되며 인수와 검색어는 저장하지 않습니다.

플러그인 이름이 내장 페이지 항목을 대체하지 않습니다.

로드된 플러그인 페이지도 명령 검색에 표시됩니다. 결과를 열면 기존 페이지로 돌아가며 현재 입력한 내용을 유지합니다.

현재 인터페이스 언어에서 이름이 정확히 일치하는 명령이 즐겨찾기와 최근 명령보다 먼저 표시됩니다. 검색어를 바꾸면 가장 잘 맞는 결과를 선택합니다. 검색어를 바꾸지 않고 즐겨찾기나 인터페이스 언어를 변경하면 선택한 명령과 인수를 유지합니다.

설정은 카드로 묶고 자주 쓰는 동작은 표시하며 보조 명령은 More actions에 모읍니다. Show details로 고급 도구와 메시지를 펼칩니다. 장면 편집기는 캔버스 옆에 Properties, Preview, Animation 탭을 배치합니다. 좁은 창에서는 입력 항목과 컨트롤이 줄바꿈되고 하단 동작은 계속 보입니다. 명령 검색은 즐겨찾기 상태와 키 안내를 표시합니다. 실패하면 재시도할 입력을 보존하고 다른 명령을 선택하면 이전 인수를 지웁니다.

텍스트 → 로컬 TXT / JSON / CSV에서 UTF-8 파일, 필드, 1–3600초 갱신 간격을 선택합니다. JSON은 /키/인덱스(예: /build/tasks), CSV는 고유 열 이름을 사용하고 열을 여러 줄로 표시합니다. 빈 필드는 전체 파일입니다. 백그라운드 읽기는 소스당 한 작업, 입력 1 MiB, 출력 65,536자까지입니다. 파일/필드 누락, 형식, 권한, 크기 오류를 표시하고 수정 후 자동 복구합니다. 프리셋은 파일/필드/간격을 저장합니다. 휴대용 장면은 데이터 파일을 복사하므로 패키지 공유 시 해당 데이터도 공유됩니다.

도구 → 색상 팔레트는 수집을 활성화하면 연속 클릭으로 색을 모읍니다. 이름/그룹, 정확한 hex 편집, 검색, 복사, 삭제 및 최근 샘플 재사용을 지원합니다. 최대 512색과 서로 다른 최근 50색을 로컬에 저장해 재시작 후 유지합니다. 그룹 내 이름은 대소문자 구분 없이 고유하며 중복은 거부합니다. CSS/JSON은 RGB를 유지하고 CSS 이름 충돌에는 번호를 붙입니다. 완전히 쓴 후 파일을 교체합니다. 명령 팔레트에서도 열 수 있습니다.

팔레트를 내보낼 때는 설정, 홈, 백업, 임시 및 잠금 파일의 예약된 이름과 링크된 대상 파일을 사용할 수 없습니다.

프리셋 → 프리셋 버전은 재시작 후에도 프리셋마다 서로 다른 설정 스냅샷을 최대 50개 보관합니다. 저장할 때 이전 및 새 구성을 기록하며 같은 내용은 중복하지 않습니다. 버전을 선택하면 현재 페이지 설정과 필드 차이를 비교합니다. 미리 보기는 해당 구성을 페이지 컨트롤에 적용하며 취소, Escape 또는 창 닫기로 원래 설정을 복원합니다. 버전 복원은 적용 후 저장하며 적용이나 저장이 실패하면 페이지 설정을 되돌립니다. 스냅샷은 미디어 경로만 보관하고 파일을 복사하지 않으며 미리 보기에서 오버레이를 열지 않습니다. 기존 JSON/ZIP 프리셋과 호환됩니다. 기록은 presets/.versions에 있으며 프리셋을 삭제한 뒤 같은 이름을 다시 쓰면 이용할 수 있습니다.

펫 → 펫 식별 정보는 sprite 또는 Puppet마다 UUID, 이름, 기분, 포만감, 호감도를 독립적으로 저장합니다. 재시작 후 생성 전에 저장된 식별 정보를 선택하면 상태를 이어갑니다. 새 펫은 새 상태로 시작합니다. 기존 공통 수치는 첫 식별 정보로 한 번만 이전합니다. 복제는 현재 수치를 새 식별 정보로 복사하며 먹이 주기는 다른 펫을 바꾸지 않습니다. 개별 JSON 저장을 이름 변경, 새로 고침, 내보내기, 가져오기 할 수 있고 가져오기는 항상 새 식별 정보를 만듭니다. 같은 식별 정보는 동시에 하나만 활성화할 수 있습니다. 이미지, 스크립트, 대화 기록은 저장하지 않으며 이동용 프리셋에는 로컬 ID를 넣지 않습니다. 설정에 최대 256개를 보관하며 sprite 변경은 짧은 지연 후와 닫을 때 저장합니다. Puppet 먹이 주기는 저장 수치만 바꾸고 Imervue 동작이나 크기는 바꾸지 않습니다.

펫 저장 파일을 내보낼 때는 별도의 파일 이름을 사용하세요. 설정, 홈, 백업, 임시 및 잠금 파일의 예약된 이름과 링크된 대상 파일로는 내보낼 수 없습니다.
