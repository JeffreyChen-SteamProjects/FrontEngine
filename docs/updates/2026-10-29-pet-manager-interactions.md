# 寵物管理頁互動入口

管理頁選定已顯示的寵物後，可用互動選單執行招呼、撫摸、梳理、結束互動、玩耍／工作／休息模式及四種點心。執行時重新查找選定的存檔識別碼，因此切換選擇後不會沿用上一隻寵物。未啟動或隱藏的寵物顯示提示，不自動建立或顯示視窗。

Sprite 與 Puppet 共用既有 session 的照顧計時、冷卻與完成獎勵。管理頁撫摸直接開始兩秒照顧，作為手勢操作的鍵盤入口；執行前釋放指標撫摸與 Sprite 玩具。這個入口沒有提供玩具落點或移動目的地的鍵盤選擇。

84 項互動、存檔、找回寵物、翻譯及文件測試通過。Qt 本機鍵盤事件驗證按鈕啟動，涵蓋選定身分隔離、取消無獎勵、冷卻、不可用寵物與 Puppet。實際管理頁以 offscreen 平台繪製並檢查，沒有注入作業系統輸入。原生焦點、實際鍵盤導覽與正式角色動畫仍待驗收。
