Particle Page
-------------

* Choose Image - the picture each particle is drawn from.
* Start play particle - begin the effect.
* Choose particle direction - down, up, left or right.
* Particle size, Particle count, Particle speed - how heavy the effect is.
  Fewer and slower costs less; the Control Center's quality tier can lower it
  further for every overlay at once.
* Opacity - how see-through the particles are.
* Show on all screen - one copy per monitor.
* Target monitor - which screen to use, or ask each time.
