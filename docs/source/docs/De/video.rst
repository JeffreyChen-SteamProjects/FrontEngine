Video-Seite
-----------

.. image:: ../image/video/video.png

* Videodatei wählen - die abzuspielende Datei.
* Video abspielen - anzeigen.
* Deckkraft - wie durchsichtig das Video ist.
* Abspielgeschwindigkeit - wie schnell es läuft.
* Lautstärke.
* Vollbild - auf den ganzen Bildschirm strecken.
* Auf allen Bildschirmen zeigen - eine Kopie je Monitor.
* Unter allen Fenstern zeigen - unter die anderen Fenster legen.
* Zielbildschirm - welcher Bildschirm, oder jedes Mal nachfragen.
* Zuletzt verwendet - vorher abgespielte Dateien.
