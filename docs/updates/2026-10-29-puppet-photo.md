# Puppet 拍照接入

Puppet 右鍵選單新增「寵物拍照」，沿用透明照片預覽與 QSaveFile 保存流程。影像由 Imervue 的 `render_offscreen_puppet` 以透明背景輸出，只含角色，沒有讀取桌面或對話泡泡。開啟後凍結影像，重複開啟沿用同一對話框，不重拍或改動寵物狀態。

接入前檢查 runtime 是否提供此方法、GL 畫布是否有效。無效畫布、空影像或原生渲染例外會提示重試，不開啟空白照片。Puppet 目前只拍當前姿勢；分層 Sprite 的姿勢時間選擇不套用到原生模型。

驗證：Puppet 照片接入、Sprite 照片與 Puppet 生命週期共 20 項通過；文件檢查 22 項通過；變更模組 pyflakes 通過。Puppet 照片測試替換 native render 方法與畫布有效性，驗證參數、影像分離、透明像素保存、狀態不變及失敗提示；不是實際 GL 渲染驗收。

仍待在不干擾使用者前景的原生環境驗證真實模型照片、GL context 狀態還原及透明邊緣。正式角色擺姿素材也尚未完成。
