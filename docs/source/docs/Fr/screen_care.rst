Page Confort visuel
-------------------

* Filtre d'écran - un voile chaud, ambre, rosé, jaune, vert, bleu ou gris sur
  l'écran, d'intensité réglable.
* Règle de lecture - une bande qui suit le curseur pour garder sa ligne.
* Pauses visuelles (min / s) - au bout de tant de minutes l'écran s'assombrit
  pendant tant de secondes, puis vous le rend.
* Vision des couleurs - simuler protanopie, deutéranopie, tritanopie ou
  achromatopsie, pour vérifier qu'une maquette reste lisible.
* Tous les écrans / Écran cible - comme ailleurs.

Ces calques laissent passer les clics : tout ce qui est dessous continue de
fonctionner.
