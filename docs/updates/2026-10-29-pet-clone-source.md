# 複製寵物保留來源設定

原先右鍵複製雖建立新 UUID 並複製存檔，但新視窗仍讀取設定頁當前素材與基本參數。使用者改選其他圖片甚至 Puppet 後，複製可能產生錯誤種類的寵物。

現在複製會把來源視窗傳入建立流程，使用來源圖片／模型、基本顯示設定、聲音、音量反應、資產庫及已保存外觀與偏好。語音／對話使用來源啟用狀態，音量輸入提供者另建，不共用可關閉的輸入實例。設定頁選擇不被改寫。

Puppet 保存來源腳本路徑供複製使用，並從來源畫布取得參數值與已選表情。新個體仍有獨立 session 和 UUID；複製後的部件編輯不改變來源。此次不宣稱複製正在播放的動畫時間或暫時互動。

驗證：Sprite／Puppet 複製、session 與生命週期 18 項通過；自訂、衣櫃與文件 47 項通過；變更模組 pyflakes 通過。新增案例包含設定頁跨 Sprite/Puppet 改選後的複製，以及真實分層資產庫、部件畫面一致與後續編輯隔離。Qt 全程離屏；原生模型視覺驗收仍待完成。
