小工具页面
----------

* 音频频谱 - 随扬声器播放的声音起伏的长条或环形，频段数可调。
  这一项确实会捕获音频，但只在内存里分析以计算频率；不会录下也不会发送，
  停止频谱就停止捕获。Windows 与 macOS（macos extra 与权限；此处未验证 macOS 实机）。
* 系统监控 - 以小面板常驻显示 CPU、内存、磁盘、电池与网络上下行。
  要显示哪几条线可以自己勾；没有显示的线照样在记录，打开就看得到这段时间发生的事。
* 显示正在播放 - 你的播放器现在放到哪一首。
* 便签 - 「新便签」在桌面上贴一张，「关闭便签」清掉全部。
  勾选「FrontEngine 启动时重新打开我的便签」下次就会自动回来。

小工具 → 待办与日历提供勾选式待办、可选本地到期时间与本地 UTF-8 .ics 独立 VEVENT／VTODO 导入。今日小工具显示未完成的无日期、今日及逾期待办，以及今日重叠事件；全天与午夜结束时间不含结束日。已知 IANA TZID 使用 Qt 平台规则，UTC 显示本地时间，浮动时间维持本地、全天日期不换日。DST 重复时段取首次，缺失时段用变更前偏移；DURATION 天数保持本地时间。UID＋RECURRENCE-ID 更新，较低 SEQUENCE 不覆盖新版，重导保留勾选，CANCELLED 移除匹配事项。支持折行与 TEXT 转义，不打开链接、闹铃或附件。循环规则／RDATE／EXDATE 与未知自定义时区整批拒绝，请导出独立事件。设置旁 tasks.json 最高 500 项／4 MiB，标题 1000、说明 2000 字，原子保存失败保留旧数据；导入 4 MiB、单行 8192 字。无网络同步或闹铃。延迟启动的串行后台任务处理文件，关闭停止定时并丢弃迟到结果。今日工具纳入批量关闭／隐藏；须明确打开，事项保存但不自动重开浮窗。

取消记录仍计入 500 条上限，防止旧导入重建已取消事件。清空全部先确认，并删除待办、事件及取消数据。今日工具使用普通 Qt 软件绘制，避免合成层盖住交互控件。
