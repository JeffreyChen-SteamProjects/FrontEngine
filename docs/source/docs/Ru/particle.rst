Частицы
-------

* Выбрать изображение - из чего рисуется каждая частица.
* Запустить частицы.
* Направление - вниз, вверх, влево или вправо.
* Размер, количество и скорость частиц - насколько эффект тяжёл.
  Меньше и медленнее - дешевле; уровень качества в Центре управления снижает
  нагрузку сразу для всех слоёв.
* Непрозрачность - насколько частицы просвечивают.
* Показывать на всех экранах - по копии на монитор.
* Целевой экран - какой экран использовать или спрашивать каждый раз.
