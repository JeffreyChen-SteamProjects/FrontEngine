Фокус
-----

* Затемнять фоновые окна - приглушить всё, кроме используемого окна, с
  регулируемой силой.
* Закрыть отвлекающее - спрятать часть экрана: нижнюю полосу с панелью задач,
  правый нижний угол, верхнюю полосу, любой из боковых краёв или весь экран.
* Целевой экран - какой экран использовать или спрашивать каждый раз.

Оба пропускают щелчки насквозь: закрытое продолжает работать, просто перестаёт
отвлекать. Заслонка к тому же остаётся видимой при показе экрана - закрывать
что-то и есть её единственное назначение.
