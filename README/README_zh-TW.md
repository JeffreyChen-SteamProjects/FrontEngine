**把任何東西放在螢幕最上層——或是放到最底下。**

FrontEngine 是一款桌面覆蓋層應用程式。影片、圖片、GIF、網頁、文字、
粒子、音效與一隻會動的寵物，都能疊在其他所有視窗之上（可穿透點擊，
所以底下的東西照樣能用），或是放到它們後面當成動態桌布。除此之外還有
一整套針對螢幕本身的工具：護眼濾鏡、簡報標註、量測與擷取、專注遮罩與
桌面小工具。

[在 Steam 上支持這個專案](https://store.steampowered.com/app/2793470/FrontEngine/)
 · [說明文件](https://frontengine.readthedocs.io/en/latest/)
 · [觀看示範影片](https://youtu.be/fewogcb3b8Y)

## 安裝

支援 Python 3.11 以上，但排除 3.14.0 至 3.14.4。使用 Python 3.14 時，請安裝 3.14.5 或更新的修補版本。主要支援平台是 Windows 10/11；macOS 與 Linux 也能
執行這款應用程式，各平台的差異列在 [平台支援](#平台支援) 一節。

已在 Windows 的 Python 3.14.4 重現 Qt 原生崩潰；較早的 3.14 修補版本則預防性排除。請使用相容的直譯器重建既有虛擬環境，並以該直譯器執行原始碼。內嵌被排除版本的 EXE 也須使用相容的直譯器重新建置。更新 FrontEngine 套件不會升級 Python。

```bash
pip install frontengine

frontengine                    # or: python -m frontengine
frontengine --preset "Work"    # apply a saved preset on launch
```

預先編譯好的 Windows 執行檔在
[Releases 頁面](https://github.com/JeffreyChen-SteamProjects/FrontEngine/releases)，
Steam 版則是同一套應用程式，另外附帶 Workshop 支援。

> **怎麼離開。** 覆蓋層可以蓋滿整個螢幕，包括 FrontEngine 自己的視窗，
> 所以有兩條不需要用滑鼠的逃生通道：`Ctrl+Shift+F12` 會關閉每一個覆蓋層，
> 而 **F12 會直接結束整個應用程式**，在任何地方都能用（Windows；macOS 需輔助使用權限——
> 見 *Help → How to force close*）。

## 它會在螢幕上放什麼

側邊欄依用途把各頁面分組。本節依循這個分組。

側邊欄的每個頁面都有圖示，頂端的搜尋框（Ctrl+K）會開啟指令。選單列的說明與文件選單就叫這兩個名字。視窗很寬時，設定頁的卡片會集中在置中的一欄；寵物家園與場景編輯器則使用整個寬度。

### 家園（Home）

**寵物家園** — 第一頁。已儲存的寵物可以搬進一個小家園，在那裡自己生活，並靠工作賺取家園幣。

- *建立家園* 會給一張床、一張餐桌、一張書桌和 10 枚家園幣。按下之前什麼都不會建立或啟動，其他功能不需要家園也能使用。建立家園之前，所有已存的寵物都會列在 *和你一起搬進來的寵物* 底下並預設勾選，不想搬的取消勾選即可。勾選的寵物以原本的身分搬進來——同樣的識別碼、名字、親密度、心情、飽足、精力、造型與衣櫃——不會複製或重設；沒搬的寵物之後可以從居民分頁再搬進來，初始物資也不會重發。家園的一年有四季，每季七個遊戲日——春、夏、秋、冬——會顯示在狀態列，總覽的天空也會出現花瓣、落葉或雪花（開啟 *減少動態* 時靜止不動）；冬天的雨會變成雪。每一季都有一個當季目標（種花、玩耍、收成香草、放鬆），只會發一次獎勵；錯過的季節明年還會再來。 還沒有任何寵物時，「建立家園」會順便帶來第一隻寵物並選取牠。
- *搬進家園* 一隻已儲存的寵物，或用 *新寵物* 建立一隻。同一隻寵物不會同時住在家園和桌面上；牠的精力、飽足、心情與親密度會帶進來，搬離時寫回牠的角色紀錄。
- *布置* 把收納中的家具放到地板上。紅色預覽會說明為什麼不能放（超出家園範圍、那裡已經有東西、擋住出入口），按 Esc 結束布置。*收納* 會把家具收回，正在那裡進行的工作會暫停並保留進度。布置時可以直接拖曳家具，或選取後按 ← ／ → 一次移一格；*復原* 與 *重做*（Ctrl+Z ／ Ctrl+Y）涵蓋所有配置變更。*複製配置* 會把配置碼放到剪貼簿（只有家具與位置，不含寵物、金幣或任何個人資料），*貼上配置* 再讀回來；四種現成配置（*新手家園*、*溫馨角落*、*工坊*、*園藝工作室*）在 *套用配置* 購買並擺好之前，會先顯示還缺什麼與價格，原本的配置按一次 *復原* 就回來。*在地板上畫區域* 可以把一段地板標成 *居住*、*工作*、*休閒* 或 *用餐*（或清除標籤）；寵物會優先使用標籤符合當下活動的家具，但不會被禁止使用其他家具。接上第二台螢幕時，*在那個螢幕新增區域* 會在那裡多一個有自己桌面長條的區域，*把這個區域移過去* 可以搬移區域；寵物只有透過 *移到那個區域* 才會換區。螢幕被拔掉時，那個區域的寵物會等待、家具留在原處，不會複製任何東西，螢幕回來後就繼續生活。*貓跳台* 與 *攀爬牆* 在高處：活潑的寵物會自己跳上去，其他寵物需要旁邊有 *寵物階梯*；兩者都沒有時，紅色預覽會顯示「沒有寵物上得去」。工作台一律放在地面。*入口通往* 可以把兩個區域的入口連成交通點：寵物空閒時偶爾會走過去串門子，睡覺時間再走回自己的床，不會走進未連接的螢幕。*分享藍圖…* 會把整個家園的房間與家具存成 JSON 檔——不含寵物、名字、金幣、目標、螢幕名稱或任何個人資料；*拜訪藍圖…* 以唯讀方式開啟這種檔案：可以逛各個房間，但不會運作、不會購買、不會存檔，也完全不連網。不是藍圖的檔案會被拒絕；這個 FrontEngine 沒有的家具會列出名稱，而不顯示出來。
- *工作* 不需要設定：寵物在工作時段會依家裡的工作台自己接工作，先做自己擅長的行業，只用背包裡已有的材料；分頁會列出每隻正在做什麼，附上產出物的圖，任何工作都能取消。每個完成的單位只付一次錢，取消的不付錢。起始家具會自己擺好，*擺放* 會把收納中的家具放到第一個空位（或用 *布置* 點地板指定位置），在 *商店* 買的家具直接進家裡，完成的 *新手目標* 獎勵與物品足夠的委託會自動結算。商店、背包與收納都以圖片顯示每件家具和物品。格子內的名稱與價格分行顯示，格子大小隨字型調整，較長的完整名稱仍可在工具提示中查看。*設定* 分頁只保留在桌面顯示家園與減少動態。工作台可以從右鍵選單或家具分頁 *升級* 兩次（價格依家具與等級而定，自由布置時免費）；同一種工作台共用等級，所以收起或重新布置都不會失去，每升一級工作快四分之一。空閒的寵物可能會走過去幫正在工作的寵物——最多兩位幫手，每位讓速度再加四分之一——也會學到一點那項職業。倉庫裡某樣成品已有二十個時，自動工作就不再做它。家具會顯示正在發生的事：有人使用時有一個圓點，有寵物在工作時顯示該職業的工具（✎ ❀ ⚒），完成一份工作後顯示 ✓ 幾秒鐘。勾選 *專注時寵物陪我一起工作* 後，開始寵物頁的專注計時會替每隻有空的寵物排一個工作請求——不會打斷牠正在做的事、工作照一般獎勵計算，也不讀取你打的字、不在意你暫停——休息或停止計時時，只收回家園自己排的請求。每項職業都有一份進階工作，需要技能等級 4 的寵物，以及等級 4 的家園：*寫一部長篇小說*（120 金幣）、*紮一束花*（三朵花紮成價值 30 的花束）與 *做一個音樂盒*（三份木材加一個玩具，做成價值 80 的音樂盒）。
- *商店* 販售更多家具；賣回最多拿回半價，基本的床、餐桌與書桌不能買賣。家園共有 45 件家具，每件都有自己的用途或風格（從寵物軟墊到雙層床的床鋪、餐桌、每種職業各有工作台、沙發、懶骨頭、球池、鋼琴、地毯、魚缸等）；部分要家園等級更高才會開放，商店會標示所需等級，短篇故事、花與木凳也一樣。*收藏* 分頁有家具圖鑑（每件家具與取得方式）、寵物的作品與相簿。因為作息已自動安排，新手目標「選擇作息」改為「擺一件裝飾」；舊存檔的狀態會保留。家具包可以在商店與收藏裡加入家具：每個家具包是 `pet-home-packs` 裡的一個資料夾（設定分頁的 *開啟家具包資料夾*），裡面有 `pack.json`——格式 `frontengine.home-pack` 第 1 版、與資料夾同名的穩定 ID、名稱、來源與授權，以及最多 64 件家具（ID、名稱、類別、寬度、是否實心、互動點、用途、需要的姿勢、價格與舒適度）——每件家具都要有 `furniture/warm_home/<art>.png` 圖片（其他主題可省略），另附 `thumbnail.png`。只要有未知欄位、指向家具包外的路徑或連結、不是 PNG 或超過 2 MB 的圖片、重複的 ID，或任何可執行的檔案，整個家具包都會被拒絕，原因會顯示在設定分頁；家具包裡的東西一律不會被執行。家具的 ID 會變成 `<pack>__<id>`，移除家具包後，存檔裡的這些家具會先保留著，等家具包裝回來。 第二批家具新增落地燈、吊掛盆栽、衣櫥、和式床墊、暖桌、電視、壁爐、搖搖馬、望遠鏡與淋浴間。
- 內容包也可以帶主題：名稱、沿用哪套內建主題的家具圖，以及地板、白天天空與夜晚天空的顏色；主題會加入家具分頁的主題清單，只有主題的包也可以。使用中的主題所屬的包被移除時，家園會保留該主題，在包回來之前以溫暖小屋的樣子呈現。家具包、主題與藍圖在 Steam 創意工坊上也是各自獨立的類別：訂閱的包與主題會在下次啟動 FrontEngine 時出現在家園，訂閱的藍圖則以唯讀參觀開啟。藍圖會寫明需要哪些內容包，創意工坊清單和參觀畫面都會標出還沒安裝的包。
- 頁面排得像遊戲畫面：家園在最上方，同一行顯示日子、時間、天氣、金幣與 *開始* ／ *暫停*；*居民*、*工作*、*家具*、*商店*、*背包*、*目標*、*待閱*、*收藏* 與 *設定* 是下方的分頁，使用時家園一直看得到。還沒有家園時，上方會顯示新家園附帶的床、餐桌與書桌，旁邊是 *建立家園*。總覽下方有 *回到桌面*、*背包*、*目標* 與縮放（− ／ + 或 Ctrl+滾輪），以及 *等你處理* 清單，列出家園無法自己解決的事（還沒有寵物、待閱新訊息、收納裡的家具、等材料的工作、可以舉辦的慶典、願望），點一行就打開對應分頁。布置時桌面長條會顯示 *布置完成*，因為長條不接收鍵盤。較新版本 FrontEngine 的存檔會提供 *取得最新版 FrontEngine*。*自由布置* 會切換到另一個獨立的家園（``pet-home-sandbox.json``），所有家具都能用、不花錢也沒有金幣；在那裡做的事不會影響經營中的家園、它的金幣與目標，也不會改到寵物本身的數值。來回切換時會先存檔，並取消寵物正在做的事、不發獎勵。
- 只有家園在進行中（*開始*／*暫停*）時時間才會前進；FrontEngine 關閉或電腦睡眠的時間不會補算。家園存在設定檔旁的 `pet-home.json`，上一份正常的存檔保留為 `pet-home.json.bak`。讀不了的存檔或較新版本的存檔永遠不會被覆寫：頁面會提供還原備份，或保留舊檔後建立新家園。 存檔失敗後若重試成功，該次存檔的即時錯誤提示會清除，待閱仍保留錯誤紀錄。 關閉時若無法儲存設定、寵物或家園狀態、筆記、上次工作階段或使用紀錄，FrontEngine 會保持開啟，讓你排除問題後重試。先前成功的寫入與已取消的活動不會回復原狀。

工作清單的無障礙名稱會隨介面語言更新。

工作清單取得鍵盤焦點時會顯示強調色邊框，即使尚未選取工作也能辨認焦點。

每個程序只有一個 FrontEngine 控制視窗。設定資料夾會持續保留給該視窗，直到所屬背景作業與視窗完成關閉；其他程序無法開啟同一資料夾。JEditor 與 PyBreeze 會重用嵌入視窗，並在存檔失敗或關閉尚未完成時保留宿主視窗。

窄視窗中的家園狀態文字位於操作按鈕上方，按鈕可自動換行。GIF 覆蓋層完成關閉後，來源檔案即可移動或刪除。

寵物生成、預覽、桌面寵物與家園居民的預設衣櫃與家園圖片使用設定頁已持有的資料目錄，不隨主機工作目錄切換。明確指定的寵物素材庫仍會保留。 家園照片、相簿與本機內容包資料夾也使用同一個已持有的資料目錄。 照片保存成功後立即出現在相簿中，家園暫停時也一樣。

準備關閉及關閉期間會拒絕家園面板操作，藍圖選檔結果也會在使用前重新檢查。取消關閉後可執行新操作，不會重播先前被拒絕的操作。

建立家園後，快捷列及較長的按鈕、勾選說明會在窄視窗換行。家園控制項可隨面板縮放，家園畫布仍保有自己的水平捲動。 選取家具的名稱與提示會在窄面板換行，家具分頁不會因此撐寬其他家園分頁。 家園標題及背包、收藏中的家具統計也會隨窄面板換行。

家園操作訊息會隨語言切換更新，並保留數量、檔案路徑與原始錯誤內容。存檔成功會清除對應的失敗提示，不會清除較新的操作訊息。

遊戲內換日時，每日委託會同步更新到畫面，不必等待其他生活或獎勵事件。

收件匣中的既有事件會隨語言切換重新顯示，並保留重複次數、當時的寵物名稱與獎勵數值。家園暫停時，新通知與全部已讀操作也會立即同步到待處理清單。

獨立嵌入設定頁時，宿主必須透過 lifetime= 傳入明確的 DefaultSettingsLifetime。關閉該生命週期前，先儲存並停止頁面；宿主須觀察 finished 訊號後才結束。 [Runtime lifetime API](../docs/formats/runtime-lifetime.md)
- 穿上分層角色（內建的 INKSIDE 角色或衣櫃裡的角色）的寵物，會以牠本來的樣子出現在家園裡：在路上時走路、在書桌或扶手椅上坐著、在床上睡覺、在餐桌吃飯、在玩具箱玩、互相打招呼，並朝著走路的方向。居民的 *衣櫃…* 會打開原本的衣櫃，換好的造型會立刻出現在家園。角色在背景載入；載入完成前會先用彩色標記代替。曾在桌面上出現過的圖片寵物（GIF、圖片或精靈包）與 Puppet 寵物，在家園裡也會以自己的樣子出現：精靈包用自己的走路、待機與睡覺動畫，GIF 用自己的影格，Puppet 則用從自己畫布拍下的靜態圖；只有一張靜態圖的寵物走路時會彈跳、玩耍時會跳起、睡覺時會縮成一團。沒有可用外觀的寵物（新寵物，或圖片後來被移走）會以固定的一位內建角色出現；牠本身的外觀與桌面寵物都不會改變。
- 家園有四種 *模式*：*一般*；*專注*，桌面長條保持安靜（沒有泡泡與卡片）；*會議*，隱藏家園並暫停，狀態會明說；*省電*，長條每秒只畫 15 格，寵物的生活速度不變。分享螢幕期間會自動切到會議模式。*待閱* 會收集工作完成、需求、生活點滴與問題，重複的事件合成一行，從不跳窗或搶焦點；寵物自己去吃飯睡覺不會列出來。
- 家園有白天、夜晚和天氣：總覽的天空會隨遊戲時鐘從黎明變到夜晚，晴天、多雲或雨天每六個遊戲小時變換一次，由家園本身決定，所以每次都一樣。天氣只是氣氛，不會弄壞東西，也不會讓你乾等。三套主題（*溫暖居家*、*綠意工作室*、*夜間創作室*）只改顏色，不改布局。家具是用 Blender 建模的描邊卡通圖，顏色會配合各套主題；選取家具或布置時才會顯示名稱。聽雨的日子、星光夜晚、交到好朋友、手藝精進、綠意之家、熱鬧之家、第一篇短篇故事和豐收也加入生活點滴，一共十二種。*減少動態* 會讓寵物不在步伐之間滑動、雨也保持靜止；所有事件也都會寫在卡片與點滴清單裡，家園本身沒有聲音。
- 環境音在 *設定* 分頁開啟前都是關閉的，並有獨立的音量：白天鳥鳴、夜晚蟲鳴，下雨或下雪時是雨聲或輕柔的冬風。家園暫停、會議中或電腦鎖定時不會發聲。桌面長條在傍晚與夜裡會讓家具和寵物稍微變暗；長條的空白處仍保持透明，點擊照樣穿透到後面的視窗。 下雨或下雪時，桌面長條上也會落下雨滴或雪花，畫在一層完全不接收滑鼠與焦點的獨立圖層上；專注與會議模式會暫停，*減少動態* 時則靜止不動。
- *目標* 會隨著家園成長：家園等級靠生活里程碑提升（三種工作都做過、更多居民、更多家具、深厚的友誼），十個 *新手目標* 附小額獎勵、完成後自動領取（隨時可以略過，之後仍可回看），每天三筆 *委託* 用家園幣收購商品、沒有連續登入獎勵也沒有錯過懲罰，每隻寵物一個說明達成方式、永不倒數的小願望，生日、第一件手作、好友聚餐等生活點滴，以及兩隻以上寵物同住且三種工作都做過之後的一次性家園慶典。*拍一張合照* 會把家園畫面存到設定檔旁的 `pet-album`，不會擷取你的桌面。背包會顯示家具圖鑑的收集度。
- 寵物也需要舒適與陪伴。床、扶手椅和裝飾讓家更舒適，舒適度太低會讓心情變差。寵物會互相打招呼、一起吃飯玩耍而變得更親近，偶爾也會為了最後一個空位鬧彆扭。每隻寵物都有固定的個性（勤快、愛玩、安靜、愛社交，或喜歡園藝、寫作、手作），會影響牠的選擇，做喜歡的工作也稍微快一點；沒有哪種個性會讓寵物不適合做任何事。卡片會顯示個性、最要好的朋友，以及目前動作還剩幾分鐘；桌面上的小泡泡會說出寵物剛開始做什麼、跟誰打了招呼、賺了多少。舊的家園存檔讀取時會補上新需求；這個版本存的家園不會被舊版 FrontEngine 覆寫。
- 寵物也喜歡保持乾淨：清潔度會慢慢下降（玩耍時降得更快），覺得髒的寵物會就地整理毛髮，或去浴缸泡澡（更快）；梳毛也有幫助，家裡沒有浴缸卻有髒兮兮的寵物時，家園下方的清單會建議買一個。
- 三種工作：在書桌寫作、在 *花盆* 園藝（香草讓用餐更開心，花可以賣）、用商店買的木材在 *工作台* 手作（玩具可以賣，木凳做好直接進收納）。工作分成看得到的階段（播種、澆水、採收…），材料不夠時會等待而不是硬做。*背包* 列出家園擁有的所有東西、保留給工作的數量，並能賣出商品。買價一定高於賣價，任何工作串都不能把東西變回自己。
- 家園也會出現在桌面上：沿著螢幕底部、站在工作列邊緣的一條透明長條。只有寵物、家具和小小的 ⌂ 按鈕會接收滑鼠，其他像素都會穿透到後面的視窗，長條也不會搶走焦點。點寵物看牠的卡片，右鍵下指令，拖曳可以移動牠；家具按右鍵可以收納。*在桌面顯示家園* 可以關掉它，*桌面圖層* 決定放在視窗上層或下層（預設上層）；全部隱藏時家園會暫停，重新顯示才繼續；控制中心的畫質設定決定每秒 60、30 或 15 格，不影響家園生活的速度。⌂ 旁邊的箭頭會展開工具列，有 *布置*、*居民*、*工作*，以及金幣、最後點選的寵物與進行中的工作；⌂ 選單可以把工具列移到長條另一端，展開與否和位置都會記住。寵物的右鍵選單最前面是 *餵食*、*摸摸*、*聊天*——稍微提升飽足、心情或陪伴，每種每半分鐘最多一次，正在別處休息的寵物不能用——接著是 *請牠去*（各種指令）、*衣櫃…*、*安排這隻寵物的工作…* 與 *在總覽中跟隨*（總覽放大時讓牠保持在畫面內）。家具的右鍵選單會說明用途與目前誰在使用，並提供 *移動*（直接在桌面上布置）與 *收起*。鎖定電腦時家園也會同樣暫停，狀態列會顯示原因，直到解鎖為止。把檔案拖到家園裡的寵物身上就等於餵食（同樣每半分鐘一次）；檔案不會被開啟、修改或刪除，也不會變成材料或金幣。寵物選單還有 *理毛* 與 *玩玩具*（工作、吃飯或睡覺時不行）、*過來這裡*（走到你按右鍵的位置並在那裡待一下）、*玩鬼抓人*（找最近的空閒寵物一起玩，正在忙的不會被拉進來，兩隻都會開心）與 *拍張照*（從總覽拍下這隻寵物，存進相簿）。
- 長條可以縮小或放大（75–200 %，家具、寵物與高度一起變）：在寵物或家具上按住 Ctrl 滾動滑鼠滾輪、⌂ → *大小*，或在設定分頁選擇，選擇會被記住。放大後比螢幕寬的家園仍留在螢幕內，並平滑跟隨最後點選的寵物（或所有寵物）保持在畫面中。在長條上雙擊寵物就能摸摸牠。
- 第一個選單 **功能** 依用途收齊所有工具（媒體、場景與桌布、桌面小工具、專注與護眼、簡報、擷取與工具、寵物進階、自動化與整合、內容與創意工坊、覆蓋層管理、設定與說明），並附 *搜尋功能*（Ctrl+K）、*已釘選* 與 *最近使用*。這些項目打開的是原本的頁面、執行原本的指令，所以快速鍵、預設集、規則、手機遙控與 MIDI 都照常運作；預設集、設定、語言與說明選單原樣出現在裡面。側欄群組點標題即可收合，並會記住。系統匣選單多了 *開啟寵物家園*。

工作清單為空時，請檢查居民作息、工作站與背包材料。選取尚未完成的工作後，才能按「取消工作」。

所有教學目標都已領獎或跳過後，跳過按鈕會隱藏；目標清單仍可回顧。

### 螢幕上（On screen）

媒體覆蓋層。每一個都能選定自己的螢幕（或是橫跨所有螢幕）、記住你把它
拖到哪裡，並各自擁有自己的不透明度。

覆蓋層預設直接開在 FrontEngine 所在的螢幕，不會詢問。 選好檔案就會直接顯示，把檔案拖進頁面也一樣；還沒選檔就按「開始」會直接開出選檔視窗。文字或網址欄空白時會把游標移到欄位上提示，而不是跳出警告框；在欄位裡按 Enter 就會開始。

- **影片（Video）**——附音量、播放速率與循環。
- **圖片（Image）**——單一張圖片、把一個資料夾當成投影片播放，或是一塊
  **參考板**：多張圖片放在同一個畫布上，各自可拖曳，整塊板子可縮放、可平移。
- **網頁（Web）**——一個網址或一個本機 HTML 檔，可選擇是否可互動。
  **儀表板模式**會輪播一份網址清單，讓一面牆上的顯示器能靠快捷鍵或計時器
  循環切換頁面。
- **GIF / WebP**——可調速度的動畫。
- **文字（Text）**——字型、顏色、外框、對齊與跑馬燈，可顯示固定字串，
  或一個**即時來源**：時鐘、日期、倒數、碼表、系統負載或天氣。即時來源
  接受 `{field}` 樣板，頁面上會列出每一種來源提供的欄位。
- **音效（Sound）**——音樂播放與低延遲的 WAV 音效。
- **場景（Scene）**——把上面幾樣組成一個構圖，用一份可儲存、可分享的
  JSON 文件來描述。
- **粒子（Particle）**——一種 OpenGL 粒子效果。

### 桌面（Desktop）

**桌面寵物（Desktop pet）**——一隻住在你桌面上、會動的精靈。

頁面一開始就是「你的寵物」：點一個內建角色，穿著牠樣子的寵物就會立刻出現在桌面上；也可以選「自己的圖片…」。下方列出桌面上的寵物，附上「衣櫃」「找回寵物」「收起來」（雙擊也能找回）；其他設定都先收合，打開該區塊時才會出現。

- 陪伴照護為每個身分保存精力與玩耍／工作／休息模式，保留第 1 版 UUID 與數值。精靈選單新增打招呼、撫摸和梳理毛髮。計時動作完成才給獎勵；吃飽拒絕餵食，重複動作需冷卻。照護依活動時間推進，隱藏或離線不補算。Puppet 共用互動工作階段與餵食規則，原生反應依執行期及模型能力而定。

- **精靈圖（Sprites）**——單一個 GIF/WebP/PNG，或一個 *pet pack* 資料夾，
  其檔名對應到各種狀態：`walk`、`idle`、`sleep`、`climb`、`fall`、`drag`
  （缺少某個狀態時會退回用 `walk`）。可另外用一個 `pet.json` 設定大小、
  速度，以及它能不能爬牆、說話或坐在視窗上。
- **行為（Behaviour）**——在地板上帶重力地走動（把它丟出去會彈跳）、
  自由漫步，或追著游標跑。地板型寵物會爬螢幕邊緣，站在其他視窗的上緣。
- **生命（Life）**——心情、飽足度與一個好感度，都會在多次執行之間保留。
  它會隨著升級而長大、用對話框說話、在你離開時打盹，並在電量偏低時提醒你。
- **互動（Interaction）**——拖曳它、右鍵複製／餵食／設定提醒，還能
  **把檔案拖放到它身上**：圖片或 pet pack 會變成它的新造型，其他東西則會
  被吃掉。吃什麼很有講究——壓縮檔是一頓大餐，音樂讓它開心的程度大於填飽的
  程度，文件是一頓普通餐點，二進位檔則太難嚼了。
- **鬼抓人（Tag）**——螢幕上有兩隻以上的寵物時，勾選 *Play tag with each
  other*，其中一隻會變成「鬼」：它會朝最近的鄰居走去，其他寵物則往反方向跑，
  抓到某一隻就把「鬼」傳出去。
- **對聲音有反應（Reacts to sound）**——寵物會隨你喇叭的輸出而跳動，或是
  隨你的**麥克風**跳動，讓它在你說話時跟著動。兩者都只讀取輸出的*音量計*
  ——一個數字，而不是音訊本身。峰值會經過一個 RMS 視窗與一條快速上升／
  緩慢衰減的包絡線平滑處理，讓跳動像呼吸而不是閃爍。有多台螢幕時，每隻寵物
  會跟隨對應自己螢幕的那個音訊端點。
- **專注計時器（Focus timer）**——同一頁上的番茄鐘，由寵物來播報：它會
  在專注結束時、以及休息結束時告訴你。
- **聊天（Chat）**——設定了 `ANTHROPIC_API_KEY` 時，寵物可以透過 Claude
  回答你。除非你啟用，否則預設關閉；見 [有什麼會離開這台機器](#有什麼會離開這台機器)。

**桌布（Wallpaper）**——把一整個資料夾的圖片與動畫播放在每一個視窗*底下*。
每台螢幕各自指向自己的資料夾、各自有自己的計時器，可打亂順序或遞迴讀取，
並可隨喇叭音量跳動。在安靜時段可由第二個資料夾接手。

**小工具（Widgets）**——四樣坐在桌面上的東西：

- **音訊頻譜（Audio spectrum）**——長條或圓環、對數間隔的頻段，經一條
  快速上升／緩慢衰減的追蹤器平滑處理，並有會慢慢往下飄的峰值標記。
- **正在播放（Now playing）**——在安裝了選用的 `winsdk` 綁定時，顯示
  Windows 媒體控制中目前的曲目；否則顯示實際正在發出聲音的那個應用程式名稱。
- **系統監視器（System monitor）**——把 CPU、記憶體、磁碟、電池與網路
  吞吐量顯示成小小的走勢線；勾選你想要的那幾條線。平均值會藏住卡頓；
  一條線不會。隱藏的線仍持續記錄，所以重新打開時會顯示這段期間發生了什麼。
- **便利貼（Sticky notes）**——浮在每個視窗之上、可編輯的卡片，會在多次
  工作階段之間保留文字、顏色與位置。
  切換全域繪圖後端時，便利貼文字仍保持可見且可編輯。

### 工作（Work）

**專注（Focus）**——當螢幕在跟你的工作搶注意力時的兩種覆蓋層。
*Dim background windows* 會把你正在使用的視窗以外的一切都調暗，強度可調整。
*Cover a distraction* 會遮住螢幕上的一條區域：工作列、通知角落、某個邊緣，
或整個螢幕。兩者都會讓點擊穿透，所以它們遮住的東西照樣能用——只是不再
把你的目光拉過去。

**護螢幕（Screen care）**——給長時間盯著螢幕的場合：

- **色彩濾鏡（Colour filter）**——七種色調，從暖色經琥珀、玫瑰色到灰色，
  強度可調整。
- **閱讀尺（Reading ruler）**——把頁面調暗，只留一條跟著游標移動的亮帶。
- **休息提醒（Break reminder）**——20-20-20 法則，時間到時會出現一個
  休息覆蓋層。
- **色覺模擬（Colour-vision simulation）**——紅色盲、綠色盲、藍色盲與
  全色盲，嚴重程度可調整，採用 Machado 等人（2009）的模型。與其他覆蓋層
  不同，這一個是不透明的，因為要呈現別人眼中所見，就得重畫整個螢幕，
  而不是替它上色。

**簡報（Presenting）**——給示範、教學與錄影：

- **標註（Annotation）**——用筆、螢光筆或橡皮擦在螢幕上畫，附還原與清除。
- **游標效果（Cursor effects）**——指標周圍一圈光環、點擊時的漣漪，以及
  一道把其他部分調暗的聚光燈。
- **按鍵顯示（Keystroke display）**——顯示你剛按下什麼，以及你按了哪個
  滑鼠鍵，好讓觀看的人跟得上；它會在幾秒後淡出。可以挑面板要放在哪裡、
  文字要多大，也可以單獨關掉滑鼠點擊。
- **放大鏡（Magnifier）**——游標周圍區域的放大檢視。
- **白板（Whiteboard）**——一塊無限大的畫布：拖曳可平移、捲動可縮放、
  可儲存你畫的東西。筆畫存在畫布座標裡，所以平移與縮放時它們都會留在
  該在的位置。
- **凍結（Freeze）**——把某台螢幕目前的畫面釘住，讓你可以在一張靜止影像
  後面繼續工作。`Ctrl+Shift+F7` 會解除它，這很重要，因為凍結的影像會蓋住
  本來要按的那個按鈕。

**工具（Tools）**——量測、擷取與視窗處理：

- **色彩選取器／像素尺／量角器（Colour picker / pixel ruler / protractor）**
  ——點一下就取樣或量測；結果會直接進到剪貼簿，格式為 `#rrggbb`、
  `rgb(...)`、`hsl(...)` 或一個 CSS 自訂屬性。
- **區域擷取（Region capture）**——拖出一塊區域；它會進到剪貼簿、可存成
  檔案，或**釘**在最上層成為一份可縮放的浮動副本。
- **錄製區域（Record area）** — 錄製：框選範圍後，先選擇輸出 GIF 或 AVI 才開始擷取；取消不會啟動錄製。影格由背景執行緒逐張寫入，佇列上限為三張與 64 MiB，單張超限會拒絕。佇列已滿時略過擷取，並保留實際經過的播放時間。仍保留幀率、時長、影格數上限與攝影機子母畫面。停止後非同步完成寫檔，只有成功時才原子替換目標；取消與寫入失敗會清除暫存檔，保留既有目標檔。
- **相機（Camera）**——把你的網路攝影機放進一個圓形、圓角方框或矩形，
  只在本機顯示，絕不錄下。任何視訊輸入都能用，包括擷取卡，而且裝置清單
  不用重新啟動就會刷新，因為擷取卡通常是在應用程式已經在跑的時候才插上。
- **虛擬攝影機（Virtual camera）**——把一塊區域連同所有覆蓋層一起，送成一個
  網路攝影機，讓 Zoom、Teams 或 Discord 能把它選為視訊來源。需要選用的
  `pyvirtualcam` 套件與一個虛擬攝影機驅動程式（OBS 會裝一個）；少了任一項，
  按鈕會明講，而不是默默失敗。
- **讀取文字（Read text）** — 畫面文字：Tools → Read text 優先使用本機 OCR：Windows 的 Windows.Media.Ocr、macOS 的 Vision，或已安裝且具有語言資料的 Tesseract 執行檔。本機擷取文字不需雲端同意或 ANTHROPIC_API_KEY；成功但沒有文字時不會上傳截圖。翻譯與提問只有在另行同意傳送文字且提供金鑰時，才會將辨識文字送至 Anthropic。本機失敗後的截圖回退需要獨立的畫面傳送同意與金鑰。結果會顯示後端及錯誤，也能撤回同意。
- **釘住視窗（Pin a window）**——在你對照它工作時，把另一個程式的視窗保持
  在最上層，或讓它淡出。只動到堆疊順序與不透明度，絕不碰視窗內容。
- **視窗複本（Window replica）**——另一個視窗的一份小小的、永遠置頂的即時
  副本，讓你能在某個算圖或某段對話被埋住時仍看著它。
- **視窗版面（Window layouts）**——儲存每個視窗的位置，稍後再把它們放回去。
  視窗以標題比對；不在螢幕上的視窗會被略過，而不是用猜的。

## 一次控制全部

**控制中心（Control center）**頁面能觸及每一頁上的每一個覆蓋層，無論它是
從哪個分頁開啟的：隱藏、顯示、關閉、靜音、鎖定、重設位置、逐級調整不透明度，
並套用一個 **品質層級（quality tier）**（高／平衡／省電），為每個覆蓋層的
刷新率設上限並降低其算圖解析度。它還帶著一個給 OBS 用的色鍵背景、一個
*Hide from capture* 開關、記錄面板，以及 **Pin to this desktop**——你切換
虛擬桌面時覆蓋層會讓開，回來時再回來。取消釘選會把它收起來的東西都帶回來。

預設的全域快捷鍵，全部都可在 **Settings → Hotkeys** 重新綁定：

| 快捷鍵 | 動作 |
| --- | --- |
| `Ctrl+Shift+F12` | 關閉每一個覆蓋層 |
| `Ctrl+Shift+F11` / `F10` | 隱藏／顯示每一個覆蓋層 |
| `Ctrl+Shift+F9` | 全部靜音 |
| `Ctrl+Shift+↑` / `↓` | 不透明度提高／降低 |
| `Ctrl+Shift+L` | 鎖定或解鎖（穿透點擊 vs. 可拖曳） |
| `Ctrl+Shift+→` | 下一個儀表板頁面 |
| `Ctrl+Shift+F8` | 在螢幕上顯示快捷鍵一覽表 |
| `Ctrl+Shift+F7` | 凍結／解除凍結螢幕 |
| `Ctrl+Shift+F6` / `F5` / `F4` | 媒體播放/暫停、下一首與上一首 |
| `Ctrl+Shift+F3` | 把前景視窗移到下一台螢幕 |
| `F12` | 立即結束（Windows / macOS*） |

媒體傳輸送的是系統媒體鍵，所以它能觸及任何會監聽這些鍵的播放器。移動視窗
時會保持它的比例，而不是把它硬切過去，後者正是 Windows 自己的
`Win+Shift+Arrow` 的做法。

遠端遙控所驅動的，就是這些相同的動作——不多不少：

- **你的手機**（Settings → Remote control）——FrontEngine 會在你的區域網路
  上提供一個小頁面；在手機上打開那個連結，按鈕就會驅動那些動作。
- **一個 MIDI 控制器** — 按 Learn，轉動旋鈕或按 pad 即可綁定。Windows 使用內建 winmm；macOS 透過 macos extra 使用 CoreMIDI。旋鈕到頂端只觸發一次，放開 pad 不算再次按下。

## 預設集與自動化

**預設集（Presets）**會一次擷取每一頁的設定。你可以從 **Presets** 選單
儲存、載入、刪除、匯出與匯入它們、在啟動時套用其中一個，或自動還原上一次的
工作階段。一個預設集可以匯出成一個**套件（package）**——一個帶著它所引用媒體
的 zip 檔——所以它在沒有那些檔案的機器上也能打開。

接下來是一些會自己做決定的東西，全都在 **Settings** 選單裡。Smart pause
是唯一一個一開始就開著的；其餘的在你打開之前都是關的。

| | |
| --- | --- |
| **Rules** | *「當這些條件成立時，就做這件事。」* 結合一個星期幾、一個時間區間，以及哪個應用程式取得焦點，然後套用一個預設集、隱藏/顯示/關閉覆蓋層，或設定品質。空白條件代表「任何」，而一條規則會在它的條件開始成立時執行**一次**，而不是在成立期間反覆執行。這是唯一一處條件會組合起來的地方；下面各列各自只認得單一種類。 |
| **Smart pause** | 在全螢幕應用程式執行時、在機器使用電池時，或在某個指定的應用程式取得焦點時，讓覆蓋層退下。*（預設開啟，用於全螢幕那條規則。）* |
| **App profiles** | 在你切換到某個指定應用程式時套用一個預設集。 |
| **Preset schedule** | 在選定的星期幾、指定的時間套用一個預設集。 |
| **主題** | 跟隨系統，或固定淺色／深色（*設定 → 主題*）。視窗使用 FrontEngine 自己的設計，配色取自內建角色的墨黑、紙白與橘色；舊版本的設定會保留原本的淺色或深色。 |
| **Theme schedule** | 依時鐘在日間主題與夜間主題之間切換。 |
| **Signage mode** | 收起主視窗，依計時器輪播一份預設集清單，適合一台長時間開著當顯示器用的機器。 |
| **Screensaver** | 閒置超過某個門檻後，帶出你選的影片／圖片／GIF／粒子／網頁，並在你回來時把它收掉。 |
| **Reminders** | 每 N 分鐘,或每天在指定時間一次,以會自己關閉的浮動通知顯示。 |
| **Keep awake** | 在覆蓋層開著時阻止螢幕進入睡眠。 |
| **Start with the system** | 在登入時啟動。 |
| **Screen time** | 哪些應用程式取得過焦點、各持續多久，附每日明細與七天摘要。你離開鍵盤時它會暫停,最多保留 60 天,而清除會把檔案本身刪掉。 |
| **Clipboard history** | 搜尋你複製過的內容,並釘住你會重複使用的字句。剪貼簿經常存著密碼,所以除非你另外勾選「keep between sessions」,否則這是**只存在記憶體裡**的。 |

## 隱私與平台注意事項

### 有什麼會離開這台機器

FrontEngine 裡的一切都是在本機進行的,除非它在這份清單上。有四個例外,
全部都是需要主動選擇加入(opt-in)的:

| 功能 | 送到哪裡 | 防護 |
| --- | --- | --- |
| **Read text**(Tools) | Anthropic API | 畫面文字：Tools → Read text 優先使用本機 OCR：Windows 的 Windows.Media.Ocr、macOS 的 Vision，或已安裝且具有語言資料的 Tesseract 執行檔。本機擷取文字不需雲端同意或 ANTHROPIC_API_KEY；成功但沒有文字時不會上傳截圖。翻譯與提問只有在另行同意傳送文字且提供金鑰時，才會將辨識文字送至 Anthropic。本機失敗後的截圖回退需要獨立的畫面傳送同意與金鑰。結果會顯示後端及錯誤，也能撤回同意。 |
| **Pet chat** | 你的訊息會送到 Anthropic 的 API | 同一把金鑰、同一條規則;預設關閉。 |
| **Weather**(文字來源) | 座標會送到 Open-Meteo | 不需要金鑰、不需要帳號、沒有任何可識別身分的資料;只有你當成地點輸入的那些內容。 |
| **Phone remote** | HTTPS | 手機操控：Settings → Remote control 只提供 HTTPS，權杖每次啟動都會更換，可執行動作採固定清單。手機不會自動信任本機自簽憑證。請先匯出公開憑證，比對顯示的 SHA-256 指紋，再依手機或瀏覽器設定匯入或信任。私鑰留在使用者資料目錄。IP 變更、到期或重新產生憑證時，可能需信任新憑證。TLS 啟動失敗不會退回 HTTP。 |

音訊功能只讀取一個輸出**音量計**——單一個數字——只有頻譜例外,它需要真正的
取樣來計算頻率,因此會擷取系統輸出串流。那些取樣是在記憶體裡分析的,絕不
寫到磁碟或送到任何地方,而且你一停止頻譜,擷取就立刻停止。

外掛：啟用載入不代表授權外掛。plugin.json 或單檔 sidecar 宣告版本、身分、入口與能力；Python import 前檢查同意，授權綁定內容摘要。程式或宣告改變就需重新同意；舊外掛需明確完全信任。Settings → Revoke plugin grants 可撤銷保存的授權；已在執行的程式需重新啟動才能卸載。Python 外掛仍具有完整應用程式權限，宣告與同意不是作業系統沙箱。

### 螢幕分享隱私

你的覆蓋層是給你自己看的,不是給你正在分享的對象看的。從
**Settings → Screen-sharing privacy**,FrontEngine 可以在會議應用程式開著時
把它們排除在擷取之外:

- **它們會留在你自己的螢幕上。** 只有被擷取的那份副本是空白的——這用的是
  Windows 的 `WDA_EXCLUDEFROMCAPTURE`,一個作業系統層級的旗標,會議與錄影
  應用程式都會遵守它。
- **遮罩是例外。** 一個干擾遮罩的存在就是為了蓋住某樣東西,所以它會刻意
  在擷取中保持可見。
- **觸發依據是你的清單。** Windows 沒有可靠的「我是不是正在被擷取」API,
  所以它會盯著你指名的視窗標題——這也能抓到在瀏覽器分頁裡開的會議,那種
  情況下執行檔就只是瀏覽器而已。

控制中心裡也有一個手動的 *Hide from capture* 按鈕。

> 這是隱私,不是資安:它擊敗的是一般的擷取路徑,而且它從不對坐在桌前的
> 那個人隱藏任何東西。

## 執行環境、隱私與互通

錄製：框選範圍後，先選擇輸出 GIF 或 AVI 才開始擷取；取消不會啟動錄製。影格由背景執行緒逐張寫入，佇列上限為三張與 64 MiB，單張超限會拒絕。佇列已滿時略過擷取，並保留實際經過的播放時間。仍保留幀率、時長、影格數上限與攝影機子母畫面。停止後非同步完成寫檔，只有成功時才原子替換目標；取消與寫入失敗會清除暫存檔，保留既有目標檔。

手機操控：Settings → Remote control 只提供 HTTPS，權杖每次啟動都會更換，可執行動作採固定清單。手機不會自動信任本機自簽憑證。請先匯出公開憑證，比對顯示的 SHA-256 指紋，再依手機或瀏覽器設定匯入或信任。私鑰留在使用者資料目錄。IP 變更、到期或重新產生憑證時，可能需信任新憑證。TLS 啟動失敗不會退回 HTTP。

畫面文字：Tools → Read text 優先使用本機 OCR：Windows 的 Windows.Media.Ocr、macOS 的 Vision，或已安裝且具有語言資料的 Tesseract 執行檔。本機擷取文字不需雲端同意或 ANTHROPIC_API_KEY；成功但沒有文字時不會上傳截圖。翻譯與提問只有在另行同意傳送文字且提供金鑰時，才會將辨識文字送至 Anthropic。本機失敗後的截圖回退需要獨立的畫面傳送同意與金鑰。結果會顯示後端及錯誤，也能撤回同意。

Puppet 寵物：安裝選用的 puppet extra 與可用的 Imervue runtime，再於寵物頁選擇或拖入原始 Imervue .puppet v1 檔案。既有圖片與 sprite 寵物包仍可使用。Puppet 寵物使用 Imervue 畫布、動作與表情，可複製或關閉，並支援 FrontEngine 覆蓋層控制與預設集。可另選 .petscript.json 使用 Imervue 原有腳本引擎；FrontEngine pet.json 寵物包不是 puppet 檔。未知版本、不安全的封存路徑與無效資源會在載入 runtime 前拒絕。

Puppet 寵物也會自己散步：休息幾秒後，沿目前的高度向左或向右走一小段，並播放走路動作，不會走出螢幕的工作區，接著再休息。拖曳、撫摸、「過來」與玩具、打字時安分，以及不允許自行行動的模式都會讓散步停下。

「行為」選單的預設值「循環所有動作（隨機）」會讓寵物從整套動作中隨機挑選接下來要做什麼；「沿底部行走」則只走路和發呆。精靈圖寵物會在走路、發呆、坐下、玩耍、理毛、走到較近的牆邊爬牆、揮手、睡覺、慶祝和展示服裝之間挑選；Puppet 寵物則在散步，以及原地坐下、玩耍、理毛、揮手或慶祝之間挑選。叫出來的寵物會馬上開始走動。姿勢動作會停在原地，沒有該姿勢圖片的寵物會顯示待機圖片。

場景：場景頁支援舊 entry mapping JSON、有版本的 frontengine.scene envelope，以及可攜式 .fescene 套件。PUPPET 項目可設定位置、大小、不透明度、有限數值參數，以及選用動作、表情與腳本。JSON 路徑相對於場景檔解析。.fescene 包含引用媒體、原始 .puppet 與選用 .petscript.json，可移到其他電腦。匯入會檢查路徑、符號連結、版本與解壓上限。FrontEngine 場景維持場景套件；.puppet 維持單一 Imervue 角色。

macOS：選用 macos extra 以 macOS 13+ 與公開 PyObjC framework 為基準。後端提供 ScreenCaptureKit 螢幕／視窗擷取與系統音訊、麥克風擷取、Quartz 視窗幾何、Accessibility 視窗版面與移動、CoreMIDI、媒體鍵及 F12 退出。螢幕錄製、輔助使用與麥克風權限分別檢查；請到系統設定 → 隱私權與安全性，依提示重新啟動。其他程式視窗的透明度／強制置頂、Space 指定，以及讓其他程式擷取時排除覆蓋層仍不可用。本 Windows 開發環境尚未驗證 macOS 原生授權、硬體與效能。 Settings → macOS 權限與能力會逐項列出可用、不可用或不支援，並顯示權限或安裝原因。

外掛：啟用載入不代表授權外掛。plugin.json 或單檔 sidecar 宣告版本、身分、入口與能力；Python import 前檢查同意，授權綁定內容摘要。程式或宣告改變就需重新同意；舊外掛需明確完全信任。Settings → Revoke plugin grants 可撤銷保存的授權；已在執行的程式需重新啟動才能卸載。Python 外掛仍具有完整應用程式權限，宣告與同意不是作業系統沙箱。

算圖：Settings → Overlay rendering 可選 Auto、GPU 或 Software，並查看實際後端。GPU 合成器以 OpenGL texture、shader 與 framebuffer 處理圖層順序、變換、不透明度與裁切；初始化失敗時回退軟體並顯示原因。既有 QPainter 內容仍可能先由 CPU 轉成點陣圖再上傳；web／video／原生 widget 可能使用獨立視窗。擷取與錄製可能將 GPU 畫面讀回 CPU，這不代表零拷貝擷取或已測得效能提升。 覆蓋層重繪會將合成器更新排到父視窗繪製完成後執行，切換後端或螢幕時也遵循此順序。

Windows OCR 的 WinRT 投影套件包含於 FrontEngine 的一般 Windows 安裝；請安裝需要的 Windows 辨識語言。Tesseract 的執行檔與訓練語言資料需另行安裝。選用 puppet extra 會安裝 Imervue>=1.0.90；macos extra 安裝 macOS 13+ 的公開 PyObjC framework。請使用下列指令。docs/formats/ 提供 puppet、pet.json、petscript 與場景範例。

  一起更新,而測試會強制這一點。

## 持續整合與發佈

工作流程是 `feature → dev → main`,而且只有最後一步會發佈:

```
feat/xyz  ──PR──►  dev  ──PR──►  main
                    │              │
              CI, no release   CI + release
```

| 工作流程 | 觸發 | 用途 |
| --- | --- | --- |
| `CI`(`ci.yml`) | 推送／PR 到 `main` 或 `dev`、手動派發,或由 `Nightly` 呼叫 | 編譯、跑單元測試,接著從*那次 checkout* 建置一個 wheel、安裝它並啟動應用程式——在 Python 3.11 / 3.12、Windows 上 |
| `Nightly`(`nightly.yml`) | 每日 cron、手動派發 | 呼叫 `CI`。排程刻意放在這裡:GitHub 會在含有 cron 的工作流程閒置約 60 天後停用它,否則那會連帶把 PR 檢查一起弄掉 |
| `Release`(`release.yml`) | 一個**來自 `dev`**的 pull request 被併入 `main`,或手動派發 | 提升版本號、帶著 `[skip ci]` 把它 commit 回去、把 `stable.toml` → `pyproject.toml` 對調、建置 sdist + wheel、以 `frontengine` 之名上傳到 PyPI、建立一個標記為 `v<version>` 的 GitHub release,並快轉 `dev` |

發佈**只在 `dev` 併入 `main` 時**發生。功能落在 `dev` 上而不鑄造版本號,
而一次發佈是一個刻意為之的 `dev → main` pull request。一個誤把目標指向
`main` 的功能 PR 仍會被併入,但不會發佈——失敗的方向是漏了一次發佈,
而不是多了一次不想要的發佈。

修訂號(patch)區段會自動提升;至於次版本或主版本發佈,執行
*Actions → Release → Run workflow* 並挑選區段。那條路徑也能在不需要新的
併入之下,重跑一次失敗的發佈。

版本號存在兩個檔案裡:`pyproject.toml` 是開發套件(`frontengine_dev`),
`stable.toml` 是已發佈的那一個(`frontengine`)。

需要一個 repository secret:`PYPI_API_TOKEN`,一個範圍限定在 `frontengine`
專案的 PyPI 權杖。工作流程用 `__token__` 當作 twine 使用者名稱,所以只需要
存權杖本身。

完整符合目前介面語言的名稱會排在收藏與最近使用之前。修改搜尋文字會選取最佳結果；未修改查詢而更新收藏或切換介面語言時，保留選取的命令及參數。

設定以卡片分區：常用動作直接顯示，次要操作收進「更多操作」。進階工具與訊息可按「展開設定」開啟。場景編輯器將畫布放在「屬性／預覽／動畫」面板旁。窄視窗會自動換行，底部動作保持可見。功能搜尋會顯示收藏狀態與鍵盤提示；執行失敗時保留輸入供重試，切換功能時清除上一個功能的參數。

預設集 → 預設集版本會跨工作階段保留每個預設集最多 50 個不同設定快照。儲存時記錄原配置與新配置，相同內容不重複保存。選取版本可比較與目前分頁設定的欄位差異；預覽會將該配置套用至分頁控制項，取消預覽、Escape 或關閉視窗會回復原設定。「回復版本」會套用並存檔，若套用或儲存失敗則還原分頁設定。快照只保留媒體路徑，不複製媒體；預覽不開啟覆蓋層。既有 JSON／ZIP 預設集保持相容。歷史位於 presets/.versions；刪除預設集後歷史仍保留，同名重建時可查看。

寵物 → 寵物身分與存檔會為每隻 sprite 或 Puppet 寵物保存獨立 UUID、名字、心情、飽足及好感度。重開後於生成前選取已保存身分即可接續狀態；「新寵物」建立新狀態。第一個身分只遷移一次原共用數值。複製會將目前數值複製到新身分，餵食不會改到其他寵物。可重新命名、整理、匯出或匯入單隻 JSON 存檔，匯入一定建立新身分。同一個身分同時只能啟用一次。存檔不含圖片、腳本或對話紀錄，可攜預設集不寫入本機身分 ID。使用者設定最多保存 256 個身分；sprite 數值變更稍後合併存檔，關閉時也會保存。Puppet 餵食只更新存檔數值，不改變 Imervue 動作及尺寸。

匯出寵物存檔時請另取檔名。匯出會拒絕設定、家園、備份、暫存與鎖定檔的保留名稱，以及連結形式的目的檔案。

圖片 → 比較圖片可在同一個縮放／平移視窗檢視兩張參考圖，切換並排、透明疊圖、滑動分隔線與 RGB 絕對差。可不縮放而對齊左上角或中心，或保持比例將 B 放入 A。滾輪同步縮放；滑桿調整 B 透明度或分隔線位置。透明像素與留白以白底比較，差異黑色表示 RGB 相同；動態圖片只用第一影格。解碼、對齊及差異計算在背景執行，每次只處理一個請求並套用最新選擇；透明度／分隔線重繪沿用圖片快取。每檔限 64 MiB、單邊最多 8,192 像素，每圖及對齊畫布最多 16,777,216 像素。新選擇失敗會保留原比較內容，關閉會釋放圖片並忽略遲到結果。

設定 → 規則新增優先數字（-1000…1000）、冷卻時間（0…86400 整數秒）、條件預覽及本工作階段執行紀錄。觸發規則由小到大執行，相同數字依表格順序，較高優先數字最後執行。冷卻依單調時鐘計算，期間觸發會消耗並略過，期滿時若條件仍成立也不執行。預覽可檢查未存檔的列，不執行動作或消耗觸發。最近 200 筆紀錄保留規則條件、當時環境與派送／執行／失敗／冷卻結果，只存在記憶體。已命名但無效的列會阻止存檔。最多 200 條規則，同名規則也有獨立身分；編輯時保留表格未列出的既有條件。動作回報失敗時會記錄失敗，不阻斷後續規則。

說明 → 平台能力唯讀顯示必要條件與最近原生失敗，不啟動擷取或監聽。Linux 音訊需要發行版 pulseaudio-utils（parec）與 PulseAudio／PipeWire Pulse 相容服務，頻譜／音訊反應使用預設輸出 monitor、對嘴使用預設麥克風。與 Windows 只讀峰值不同，Linux 電表／反應會讀實際音訊取樣；首次啟用取樣才建立自己的工作執行緒與子行程，只在記憶體保留 2048 個清理後 float 取樣、丟棄過期資料，不存檔或傳送。停止、關閉及退出只收回自己的擷取子行程，不在 GUI join，裝置、服務及權限失敗明確顯示。Linux 視窗幾何／配置／置頂／螢幕移動使用 Linux 安裝的 python-xlib、EWMH 與實體 XRandR 工作区，透明度另需合成管理器。X11 pynput 需 DISPLAY／伺服器權限；原生 Wayland 任意視窗定位及桌面全域 pynput 輸入不可用，即使有 Xwayland，介面顯示原因並拒絕螢幕恢復操作，不宣稱可監聽其他 Wayland 程式。Linux 協定驗收使用隔離 X11／Wayland 伺服器與虛擬 Pulse 裝置；Linux 實體音效／多螢幕及 macOS 實機驗收仍保留。

音訊反應停止取樣後，電表會在 1.25 秒內停止自己的擷取；重新啟用取樣可再次啟動。

Windows 封裝共用 Python CLI 的 --preset 與 --debug。原生封裝驗收前，於建置環境安裝選用 frontengine[puppet] 執行期（包含 Pillow 動態解碼外掛及已安裝 Imervue 的套件資料）。用 `py tests/integration/scene_build_fixtures.py FIXTURES --puppet SAMPLE.puppet` 產生本機合成素材（產生影片另需 PyAV）。在原生桌面執行 `FrontEngine.exe --verify-scene-build FIXTURES REPORT`，REPORT 必須是新目錄。固定驗收以暫存目錄隔離設定、保持預覽靜音，只建立自己的場景／編輯器視窗，驗證七種類型、舊／版本化 JSON、匯出再載入、GIF 動畫、網頁互動、復原重做、暫停恢復與清理，寫入 result.json 及預覽 PNG 後退出；不執行傳入的 Python 測試腳本。請檢查報告及退出碼，缺少執行期或原生渲染會明確失敗。

在寵物分頁選擇身分後開啟「自訂寵物」，或從該寵物選單開啟。每個身分可獨立設定大小（16–512）、速度（1–20）、地面／漫遊／追逐行為、爬牆、坐在視窗上、對話泡泡、音量（0–100）、打字時安靜、自動休息、拋擲與社交偏好。「使用分頁預設值」會繼承分頁的顯示與行為設定；複製及匯入保留個別設定。「套用」先以不可分割的寫入儲存，再更新正在運作的寵物。「取消」不更動設定；「重設預設值」須再按「套用」才生效。儲存失敗或編輯衝突時保留草稿。Puppet 會停用不支援的控制項，顯示與行為設定中僅套用大小、對話泡泡及打字時安靜。原生換裝控制與分層美術仍未完成。

寵物身分 → 衣櫃可預覽已安裝的分層角色。安裝素材資料夾會驗證 layered-pet.json 並複製到本機設定旁的 pet-assets。可選頭、頸、身體、背部配件，預覽動作與朝向，每個體最多收藏 20 套搭配。穿上配件會替換佔用相同槽位的配件並列出被替換的項目，取消即可還原。只列出符合目前體型的配件，缺少動作的配件會顯示為停用。試穿會播放短暫的換裝展示，「固定以便比較」可把目前造型並排顯示在草稿旁。寵物正被拖曳或正在互動時，會等結束後才換上新衣服。使用整張圖片 Sprite 的寵物會提示先選擇分層角色。套用會保存並更新正在顯示的 Sprite；取消捨棄上次套用後的編輯。缺少素材仍保留引用，修復後按重新整理。Puppet 不使用 Sprite 分層衣服。加入內建角色會在背景繪製六個 INKSIDE 角色之一（MOCHI、MOSS、PIP、BOLT、INK、GILL），連同依其體型適配、來自十四套搭配的三十件衣物，並走相同的驗證流程安裝；關閉衣櫃即取消。每個角色可選眼睛、嘴巴與三組身體部件，也能替指定區域換色，每件衣物都會跟著所有動作。部件與衣物名稱會跟隨介面語言。沒穿衣服、維持預設部件與顏色的內建角色有專屬的手繪姿勢：躺在床上睡、坐在扶手椅、吃飯、玩耍、在書桌寫字、替花槽澆水、在工作台敲打（坐、睡、吃、玩在桌面上也看得到）。穿上衣服或換了顏色時，則維持分層動畫，在工作位置坐著。仍穿著舊版內建角色的寵物會自動換到目前版本，衣服與顏色都保留。 內建衣櫃現在有 19 套、43 件，包括冬日散步、廚房、派對、上學日、海灘日；每一件都適合所有內建體型。替穿著內建角色的寵物打開衣櫃時，新版 FrontEngine 帶來的衣服會自動加進來。

沒有穿衣服、部件與配色都是預設值的內建角色，走路和爬牆會改用手繪的全身步伐畫格；穿上衣服或換過部件時則使用分層動畫，讓每件衣物都保持貼合。

桌面寵物不論「覆蓋層繪製」設定為何，一律使用一般的 Qt 繪製：寵物每一刻都在移動視窗，而走 GPU 路徑時，移動中的動畫畫格會停住不換。

寵物會進入合適的姿勢：工作模式坐下，進入休息先播放入睡片段，離開休息播放醒來片段。玩耍、丟球、撿回與鬼抓人會消耗少量能量；能量低於 20 時，即使關閉自動休息，閒置的寵物也會坐下，但仍聽從所有指令。拖放或拋出後落地、接住丟出的球、遇到其他寵物時，會短暫播放落地、接球與揮手反應，不中斷移動、玩具或你的操作。沒有這些片段的 Sprite 動作包會退回閒置或睡覺圖片。整理結束時會伸個懶腰；一再相遇的寵物每分鐘最多互相揮手一次。

關係會隨好感分成四個階段：初次見面、熟悉（20）、親近（100）、默契（250），狀態中會顯示目前階段。各階段有不同的招呼台詞，親近時揮手、默契時開心跳起，達到新階段會播放一次慶祝；不會鎖住或失去任何東西。重新召喚已保存的寵物會說歡迎回來，從寵物自己的選單關閉時會先揮手道別再關閉視窗。Puppet 現在也和 Sprite 一樣區分點擊與拖曳：放開時點擊會打招呼，只有移動超過系統拖曳距離才會移動視窗，且不給獎勵。

「自訂寵物」還能分別設定主動說話（關閉、偶爾、一般、經常）與動畫幅度（沉穩、一般、活潑），前者控制寵物自己開口的頻率，後者控制聲音脈動與落地、接球等短反應，與對話泡泡及音量互不影響。關閉主動說話後，對你操作的回應仍會顯示。Puppet 的主動說話設定套用於腳本排程台詞。先前保存的設定照常可用，兩者皆視為一般。

寵物管理頁的互動清單也會列出所選寵物自己的選單指令：拍照、狀態、提醒、對話（接上對話服務時）、複製與關閉，以及 Puppet 模型的每個動作與表情，因此右鍵選單中的所有操作都能用鍵盤完成。

寵物頁的「使用內建角色」會在背景安裝所選的 INKSIDE 角色與它的衣櫃，並把它設為來源。接著按「開始」會叫出一般的精靈圖寵物並穿上這個角色：牠會用手繪的步伐畫格走路和爬牆、可以在衣櫃換裝，而且已經是這個角色的寵物會保留原本的穿搭。旁邊的「使用內建 Puppet 模型」仍會產生 Imervue Puppet 版本。

寵物頁的「使用內建 Puppet 模型」會在背景把選定的 INKSIDE 角色繪製成 Imervue .puppet 模型：頭、手臂、尾巴與身體都已綁定，附十個動作、三個表情，以及把陪伴互動對應到它們的寵物腳本。模型存放在 pet-assets/puppets，並連同腳本設為來源，按開始即以 Puppet 寵物出現。

在多台不同縮放的螢幕上，把寵物拖到或找回到另一台螢幕時，牠會維持原本大小、留在該螢幕的工作區內並在那裡走動。縮放螢幕上的視窗上緣也改用與寵物相同的座標計算，因此會準確站在視窗頂端。

衣櫃會列出角色或服裝素材宣告的配色部位。選取部位後可改色或恢復素材原色；只改指定遮罩圖層，輪廓與未標記細節保持不變。配色先預覽，按套用才保存，並隨個體、收藏搭配及存檔匯出／匯入保留。未宣告部位的素材不開放配色控制。

關閉時若寵物存檔失敗，會保留寵物、目前狀態與重試計時器。「全部關閉」保留未能關閉的寵物；退出程式前會先確認寵物存檔成功。好感度到達存檔上限後不再增加，避免後續獎勵造成存檔失效。

互相打招呼與鬼抓人要求雙方都可見、處於玩耍模式且沒有正在互動、允許社交，也未被拖曳或因打字而安靜。不符合條件的寵物會退出追逐目標與角色。合適成員不足兩隻時暫停，恢復後再開始。關閉對話泡泡只隱藏招呼文字，不取消社交獎勵。

開始寵物專注計時會讓目前可見且沒有正在互動的寵物進入工作模式，休息階段改為休息模式。停止時恢復原模式，但不覆蓋手動更改的模式。每輪完成時，符合條件且可見的陪伴寵物只獲得一次 3 點好感與 5 點心情；提早停止或隱藏寵物不發完成獎勵。工作／休息模式不主動閒聊，預設計時採單調經過時間，不受系統時鐘調整影響。

專注開始時，空間足夠的寵物會排列在所屬螢幕工作區右下角。停止時只恢復未被手動移動或改變模式的寵物原位置。

分層角色可宣告五官與身體部件選項；衣櫃按個體預覽，套用後保存，搭配收藏同時保留角色及部件。每個選項必須涵蓋所有動畫幀。六角色正式部件美術仍未完成。

Sprite 寵物選單提供「寵物拍照」：凍結目前外觀，或選擇分層素材已有的姿勢，再保存透明 PNG。只輸出寵物，不含桌面像素與對話泡泡。Puppet 也可透過已就緒且相容的 Imervue 渲染器拍攝透明定格照片，不讀取桌面像素。原生 GL 拍照驗收仍待完成。

Sprite 寵物選「摸摸」後，在牠身上來回移動游標；三段明確行程才開始一次撫摸反應，細微抖動不算。期間暫停拖曳與社交；移開、隱藏、改變模式或選結束互動會取消未完成撫摸，獎勵仍須完成且遵守冷卻。

Sprite 寵物選單可投出或收起玩具球；拖動球再放開可重投，右鍵球可收起。寵物追球並帶回起點附近，完成往返加 1 好感，冷卻為 30 秒活躍時間。工作／休息、其他互動、隱藏、打字安靜或逾時會取消且不發獎勵。Puppet 也能撿球（見下方）。

地板模式寵物會離開窗沿下到地板追球；玩球期間暫停視窗停靠，結束後恢復。帶回位置在原起點水平位置附近的地板。

「光點逗逗牠」在寵物附近放置可拖動的小光點，活動距離有限；地板寵物沿地面追逐。放開光點並讓寵物追到後開始短暫玩耍，完成才依既有玩耍冷卻給獎勵。右鍵光點或選「收起玩具」可停止。同一隻寵物一次只能使用球或光點其中一個。

複製會使用被複製寵物本身的圖片／模型、外觀、偏好及資產庫，即使設定頁已改選其他素材也不影響。複製品使用新身分，之後換裝或換部件不會改到原寵物。Puppet 也保留來源腳本、參數值及已選表情。

符合條件的專注完成會短暫播放 celebrate，再回休息；套用變更的衣櫃會短暫播放 outfit_show。反應持續兩秒活躍時間，不另給獎勵、不寫入存檔，手動互動或換模式可中斷。素材缺少對應動畫時沿用 idle 回退；正式反應美術與 Puppet 動畫對應仍待完成。

選擇已啟用的個體後按「找回寵物」，可帶回目標螢幕工作區。隱藏寵物會重新顯示，未完成互動與玩具會停止，Sprite 移動邊界同步更新；外觀與養成數值不變。未啟用者須先啟動，尺寸超過工作區者須先縮小。

Puppet 腳本可用 frontengine_actions 將共同互動狀態對應到模型已有動作與表情，啟動前驗證名稱；未設定時不猜動畫。完成後釋放互動持有的效果，保留手動選擇。格式見 docs/formats/puppet-companion-actions.md，原生視覺驗收仍待完成。

Puppet 選擇撫摸後，需來回移動游標才開始互動；移開、Esc、隱藏、切換模式或安靜狀態會取消未完成撫摸。撫摸期間不拖曳視窗。原生手勢驗收仍待完成。

衣櫃提供六個風格色票，可快速調整選取的素材配色部位。先預覽再套用；取消保留已存外觀。仍可自由選色及恢復部位原色。

Sprite 與 Puppet 選單可直接選四種虛構點心，不必拖放檔案；沿用餵食完成、飽足上限與冷卻規則。餵食前結束撫摸，未完成撫摸不給獎勵，Sprite 同時收起玩具。

每隻寵物可在自訂中保存喜歡與不喜歡的不同點心。只在餵食完成後調整心情，飽足、好感與冷卻不變；進食中改設定從下一餐生效。舊存檔預設無偏好。素材或 Puppet 可提供 food_like、food_dislike 短反應，正式動畫仍待製作。

Sprite 寵物可用「過來這裡」顯示可拖動的附近落點標記。地板模式沿地面前往，自由漫遊／追游標模式可沿兩軸移動；抵達後短招呼，沿用招呼冷卻。標記右鍵或結束互動可取消；工作／休息、隱藏、餵食或換玩具也會取消。

寵物身分區新增互動清單與執行按鈕，可用鍵盤對選定的運作中寵物招呼、短撫摸、梳理、餵點心、切換玩耍／工作／休息或取消。管理頁撫摸沿用計時照護規則，不需滑鼠手勢；隱藏或未啟動時只顯示提示，不自行召喚。
