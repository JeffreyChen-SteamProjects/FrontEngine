# 寵物透明照片

Sprite 寵物右鍵選單新增「寵物拍照」。開啟時凍結當前寵物的畫面，包含服裝、部件與朝向；寵物繼續活動不會改動照片。分層素材可選擇已有動作及動作時間，使用開啟時的外觀與朝向產生姿勢圖。原始拍攝使用目前顯示尺寸，分層姿勢圖使用素材畫布尺寸。

照片只繪製寵物內容到透明 QImage，不讀取桌面像素，不包含對話泡泡或選單。PNG 透過 QSaveFile 提交，寫入失敗保留預覽並可另選位置重試。拍照不改變模式、好感或衣櫃存檔，也不建立動畫計時器。

驗證：照片、部件、衣櫃與文件共 41 項測試通過；像素檢查涵蓋透明度、左右朝向、部件及動作幀；保存檢查涵蓋失敗重試及拒絕空圖覆寫。變更 Python 模組 pyflakes 通過。測試全程使用 Qt offscreen。
