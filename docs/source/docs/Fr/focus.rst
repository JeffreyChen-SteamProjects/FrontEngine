Page Concentration
------------------

* Assombrir les fenêtres d'arrière-plan - atténuer tout sauf la fenêtre en
  cours, avec une intensité réglable.
* Masquer une distraction - cacher une partie de l'écran : la bande inférieure
  où se trouve la barre des tâches, le coin inférieur droit, la bande
  supérieure, l'un des bords latéraux, ou tout l'écran.
* Écran cible - quel écran utiliser, ou demander à chaque fois.

Les deux laissent passer les clics : ce qu'ils recouvrent fonctionne toujours,
cela cesse simplement de réclamer votre attention. Un cache reste par ailleurs
visible dans un partage d'écran, puisque recouvrir est sa seule raison d'être.
