Центр управления
----------------

.. image:: ../image/control_center/control_center.png

Одна страница, дотягивающаяся до каждого слоя, включая открытые другими
страницами.

Закрытие

* Закрыть все видео / изображения / GIF / страницы / звуки / тексты - только
  этот вид.
* Закрыть всё - каждый слой на экране, какой бы вкладкой он ни был открыт.
* Очистить журнал - опустошить область сообщений справа.

Всё сразу

* Скрыть всё / Показать всё - ненадолго убрать и вернуть.
* Выключить весь звук.
* Заблокировать / разблокировать слои - разблокированные можно перетаскивать
  мышью, и они запоминают, где их оставили; заблокированные пропускают щелчки.
* Хромакей - залить фон одним цветом для кеинга в OBS и подобном.
* Сбросить положение слоёв - вернуть всё на исходные места.
* Энергосбережение - снизить частоту обновления и разрешение, когда важна батарея.
* Качество - высокое, сбалансированное или экономное: то же самое, но тоньше.
* Скрыть от захвата - слои остаются на вашем экране, но не попадают в то, что
  записывает демонстрация экрана. Только в Windows. Заслонка со страницы
  «Фокус» остаётся видимой - закрывать что-то и есть её назначение.
* Закрепить за этим столом - слои остаются на том виртуальном рабочем столе,
  где были открыты. На другом столе они убираются, при возврате появляются
  снова. Открепление возвращает всё, что было убрано. Только в Windows.

Центр управления → Следовать за окном выбирает зарегистрированное верхнее наложение и видимую Windows-цель. Исходный пропорциональный сдвиг следует движению/масштабу; логический размер, физическая позиция без активации/размера, ограничена монитором, проверка 250 мс. Сворачивание скрывает, возврат уважает ручное/общее скрытие; закрытие/скрытие/потеря идентичности отвязывает. Уникальное обратимое свойство + PID/поток предотвращает повторный HWND; UIPI/повышенная цель может отказать. Отвязать перед новым сдвигом. 64 временных связи без восстановления сеанса; закрытие/всё/выход снимает cookie/таймер. Только проверенный Windows-адаптер, другие системы показывают причину. Собственные окна на одном 125%-экране проверены; смешанные DPI нескольких мониторов требуют второго.

Центр управления → Профили мониторов сохраняет/восстанавливает сочетания оборудования (20 профилей/200 окон/512 KiB, локальный monitor-profiles.json). Относительные позиции адаптируются к разрешению/главному/DPI, логические размеры сохраняются; новое сочетание возвращает окна на главный экран. Автоматика отдельно включается, события Qt/новые окна объединяются 500 мс, настройки ОС не меняются. Неоднозначное оборудование даёт ошибку; одинаковые тип/имя не сохраняются, но возвращаются на экран. Полноэкранные/сцены/привязанные окна исключены; без создания окон или угадывания handle. Только логические координаты Qt. Нативно проверен один Windows экран 125%; подключение, главный и смешанные DPI требуют оборудования.

Статичная программная композиция кеширует один кадр ≤16 MP; содержимое/DPR, преобразования, непрозрачность, порядок, clip, размер/DPI обновляют кеш. Без изменений нет перерисовки; анимация/видео обновляются, GPU readback прежний. Выход/Закрыть всё используют общий реестр: каждое окно закрывается один раз до очистки, сброс обоев и cleanup перед ресурсами. Неблокирующий таймер сохраняет Qt до окончания отменённых локальных файловых/растровых работ. Manifest API v1; examples/plugins/clock показывает QWidget с overlay_widgets, optional release_overlay_resources/shutdown, get_state/set_state. Состояния загруженных плагинов под plugin:<имя страницы>, транзакционный откат, без загрузки кода из preset. Копировать в plugins/, включить и одобрить digest; без OS sandbox. Benchmark: py -m benchmarks.scene_composition --output build/scene-benchmark.json, доверенный --baseline-file сравнивает пиксели; данные/процедура docs/benchmarks/README.md.
