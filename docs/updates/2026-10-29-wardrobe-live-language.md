# 衣櫃即時語言切換

衣櫃原先只更新標籤與按鈕，動態建立的「無」、「缺少素材」及部件「重設預設」選項沒有登記語言更新。修正前測試重現切換繁體中文後仍顯示 `None` 與 `Missing: absent-cat`。

衣櫃現在透過既有弱參考翻譯回呼更新素材選項與重設文字。更新不重建預覽、不切換動作，也不重新載入存檔。作者提供的素材、部件與選項名稱保留原文。

測試連續切換七種語言三輪，確認未套用配色、選定色區、部件、穿搭、輸入中的名稱、鏡像與預覽影格保持不變，最後套用仍保存相同外觀。缺少素材時保留原識別碼；視窗銷毀後再次翻譯亦通過。

連同換裝、部件、配色、翻譯及文件共 78 項測試通過，pyflakes 通過。測試使用 Qt offscreen，不代替原生焦點與正式美術驗收。
