Page Web
--------

.. image:: ../image/web/web.png

* Ouvrir une page par son adresse - afficher l'adresse saisie.
* Ouvrir un fichier local - lire le champ comme un chemin vers un html local.
* Autoriser la saisie - laisser la page recevoir clics et frappes.
* Opacité - à quel point la page est translucide.
* Zoom - de 50% à 200%.
* Actualisation automatique - recharger toutes les 30 secondes à 15 minutes.
* URL du tableau de bord - une adresse par ligne ; les lignes commençant par #
  sont ignorées.

    * Démarrer le tableau de bord - faire défiler ces adresses.
    * Page suivante - passer à la suivante tout de suite.

* Tous les écrans / Sous toutes les fenêtres / Écran cible - comme ailleurs.
