場景頁面
--------

.. image:: ../image/scene/scene.png

一個場景可以同時放好幾種覆蓋層，並存成檔案。

* 加入網頁到場景 - 位址與不透明度。
* 加入影片到場景 - 檔案、不透明度、播放速度、音量。
* 加入圖片到場景 - 檔案與不透明度。
* 加入 GIF 到場景 - 檔案、不透明度、速度。
* 加入音效到場景 - 檔案與音量。
* 加入文字到場景 - 文字、不透明度、字體大小、對齊。
* 開始場景 - 顯示所有加進去的東西。
* 輸出場景檔 - 把組好的內容存起來。
* 載入場景檔 - 把存過的場景叫回來。
* 清除所有腳本 - 重新開始。
* 顯示在所有螢幕 - 每個螢幕各一份。
