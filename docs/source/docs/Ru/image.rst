Изображение
-----------

.. image:: ../image/image_page/image_page.png

* Выбрать изображение - какую картинку показать.
* Показать изображение.
* Непрозрачность - насколько картинка просвечивает.
* Полный экран - растянуть на весь экран.
* Показывать на всех экранах - по копии на монитор.
* Показывать под всеми окнами - разместить ниже прочих окон.
* Слайд-шоу - показывать все картинки из папки по очереди.

    * Выбрать папку - где лежат картинки.
    * Интервал - сколько секунд на картинку.
    * В случайном порядке.
    * Включая вложенные папки.

* Целевой экран - какой экран использовать или спрашивать каждый раз.
* Недавние - ранее показанные картинки.
* Открыть доску референсов… - выбрать сразу несколько изображений и разложить их
  на одном холсте поверх рабочего стола. Перетаскивайте каждое, чтобы расставить,
  фон - чтобы сдвинуть вид, колесо - масштаб, Delete убирает выбранное, Escape
  закрывает доску. Центр управления тоже до них дотягивается.

Изображение → Сравнить изображения показывает два образца в едином масштабируемом и перемещаемом виде: рядом, с прозрачным наложением, подвижным разделителем или абсолютной разницей RGB. Выравнивайте слева сверху или по центру без масштаба, либо пропорционально вписывайте B в A. Колесо масштабирует оба; ползунок меняет прозрачность B или разделитель. Прозрачность и поля сравниваются на белом; черный означает одинаковые RGB. Используется только первый кадр анимации. Декодирование, выравнивание и расчет идут в фоне: один запрос за раз и только последний выбор; прозрачность/разделитель используют готовые изображения. Пределы: 64 MiB на файл, 8 192 пикселя на сторону и 16 777 216 пикселей на изображение/холст. Ошибка сохраняет предыдущую пару; закрытие освобождает изображения и игнорирует поздние результаты.
