# 寵物點心選單

Sprite 與 Puppet 的右鍵選單新增四種虛構點心，保留既有快速餵食。香脆小點、滿滿大餐、旋律餅乾、書頁薄餅分別使用既有 snack、feast、music、book 效果；不需要真實檔案，不讀取檔案內容。

選單共用 `companion_menu.add_food_actions`，送出食物種類而非 QAction 的 checked 布林值。仍由 CompanionState 管理兩秒餵食完成、飽足上限及所有點心共用的三十秒冷卻；切換點心不會繞過冷卻。這次沒有新增個體口味偏好或專屬食物動畫。

同時修正 Sprite 餵食交接。修改前撫摸中選餵食仍保留 `pet` 動作，回歸測試顯示預期 feed、實際 pet。現在餵食先結束撫摸並收起玩具，未完成撫摸不給獎勵，再請求餵食。Puppet 使用同樣的撫摸交接，並接受食物種類參數。

已驗證四種點心完成時的狀態差異、完成前不變、跨點心冷卻、吃飽拒絕、收玩具與取消未完成撫摸。功能、翻譯與文件初輪共 77 項測試通過，修改模組 pyflakes 通過。七種介面翻譯及十份 README、七份 pet.rst 已更新。

補上 Puppet 實際 contextMenuEvent 入口測試後，同組共 78 項通過。
