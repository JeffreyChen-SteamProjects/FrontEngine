工具頁面
--------

* 量測 - 點擊開始量測，右鍵清除。量到的結果會直接複製到剪貼簿。

    * 取色器 - 游標底下的顏色，可複製成 #rrggbb、rgb(...)、hsl(...)
      或 CSS 自訂屬性。
    * 像素尺 - 兩點之間的距離。
    * 量角器 - 三點構成的角度。

* 區域截圖 - 框出一塊範圍，結果會進剪貼簿；「複製上一張」可以再放一次。

  釘選上一張會把剛才擷取的內容釘在所有視窗之上，變成一個可以拖曳、滾輪縮放、
  雙擊或按 Escape 關閉的小視窗——把規格、配色參考或錯誤訊息擺在正在做的東西旁邊。
* 畫面文字：Tools → Read text 優先使用本機 OCR：Windows 的 Windows.Media.Ocr、macOS 的 Vision，或已安裝且具有語言資料的 Tesseract 執行檔。本機擷取文字不需雲端同意或 ANTHROPIC_API_KEY；成功但沒有文字時不會上傳截圖。翻譯與提問只有在另行同意傳送文字且提供金鑰時，才會將辨識文字送至 Anthropic。本機失敗後的截圖回退需要獨立的畫面傳送同意與金鑰。結果會顯示後端及錯誤，也能撤回同意。
* 錄製：框選範圍後，先選擇輸出 GIF 或 AVI 才開始擷取；取消不會啟動錄製。影格由背景執行緒逐張寫入，佇列上限為三張與 64 MiB，單張超限會拒絕。佇列已滿時略過擷取，並保留實際經過的播放時間。仍保留幀率、時長、影格數上限與攝影機子母畫面。停止後非同步完成寫檔，只有成功時才原子替換目標；取消與寫入失敗會清除暫存檔，保留既有目標檔。
* 虛擬攝影機 - 把一塊畫面連同覆蓋層一起當成網路攝影機送出，
  Zoom、Teams 或 Discord 都能選它當視訊來源。需要選用套件 pyvirtualcam
  與虛擬攝影機驅動；缺其中之一時按鈕會直接說明。
* 攝影機 - 顯示任何視訊輸入（含擷取卡），可選圓形、圓角或矩形，
  並加上邊框或鏡像。只在本機顯示，不會錄下任何東西。
* 釘選視窗… - 讓其他程式的視窗保持在最上層，並調整它的透明度。Windows 或 Linux X11（EWMH；透明度需要合成管理器）。
* 視窗複本… - 另外開一個小視窗顯示選定視窗的即時畫面，原視窗留在原地不動。
  適合一邊工作一邊盯著影片或編譯進度。拖曳可以搬動它，連點兩下關閉。
  Windows 與 macOS（macos extra 與權限；此處未驗證 macOS 實機）。

  複本可以只顯示視窗的一部分（上半、下半、左右半邊或中央），所以聊天欄或進度條
  可以單獨釘出來。框的範圍是以比例記住的，原視窗調整大小之後看到的還是同一塊。
* 視窗版面 - 記住視窗現在的位置，之後再擺回來。

:doc:`runtime_interoperability`

工具 → 色票管理可在勾選「收集色票」後，透過取色器連續點選收集顏色。可命名、分組、編輯精確色碼、搜尋、複製及移除，近期取樣可重用。本機保存最多 512 張色票及 50 個不同近期顏色，重開後保留。每組名稱不分大小寫且不可重複，重複時明確拒絕。CSS／JSON 匯出保留 RGB 色值；CSS 變數名稱碰撞會加數字尾碼。匯出採完整寫入後取代檔案。功能搜尋也可開啟色票管理。

工具 → 區域錄影可選 GIF 或無聲 AVI（Motion JPEG），支援 1–20 fps、暫停／繼續及取消。狀態顯示有效秒數、已接受影格與丟幀數；暫停時間不計入播放及時長限制，暫停中也可停止。AVI 最多一小時、72,000 影格，輸出上限 2 GiB；GIF 保留 120 秒／600 影格限制。兩者共用三張／64 MiB 的背景佇列與原子輸出。AVI 只保留一張 JPEG，索引寫入磁碟，略過擷取的時段重複上一張畫面以維持時間。編碼、容量或磁碟失敗，以及取消，都保留既有目標檔。不錄製音訊。

工具 → 編輯上次截圖以獨立副本提供裁切、箭頭、編號、文字框與不透明黑色遮蓋。在縮放預覽上拖曳，座標及輸出仍使用圖片實體像素。可復原、重設並檢視唯讀原圖。複製、儲存 PNG 與釘選編輯結果均使用同一份合成結果，即使正在顯示原圖。遮蓋最後繪製，PNG 不包含原圖或隱藏圖層；上次原始截圖仍另存於記憶體。PNG 採原子存檔。上限為 1600 萬像素、1000 個標記、文字框 2000 字、20 個復原狀態。關閉或替換面板會釋放文件。

工具 → 持續更新 OCR 浮窗將固定選定區域的文字釘在旁邊，初始採手動、本機辨識。可明確開啟 5–60 秒自動刷新，複製目前或歷史文字，並在記憶體保留 20 筆不重複成功結果；相同或空文字不重複記錄。最多四個浮窗、每窗一個辨識作業、截圖上限 1600 萬像素／編碼 8 MiB、文字 20000 字；慢速辨識略過重複請求。本機模式即使已有全域同意也不呼叫雲端；明確選擇雲端備援才沿用 ScreenTextService 截圖同意與憑證，另提供「檢視雲端權限」，不自動彈同意窗、不翻譯或上傳文字。啟用備援後每次刷新可能上傳選定區域。浮窗重疊區域時拒絕刷新以避免回饋。Windows/X11 使用螢幕相對 Qt 座標，Mac 非同步原生擷取單張後停止串流。隱藏停止擷取與計時；關閉／Escape 釋放來源、歷史並忽略延後結果，不等待背景作業；已送出的外部 API 請求可能仍完成。浮窗納入覆蓋層批次清理，不自動重開擷取。
