控制中心頁面
------------

.. image:: ../image/control_center/control_center.png

這一頁碰得到所有覆蓋層，包含其他頁面開出來的那些。

關閉

* 關閉所有影片／圖片／GIF／網頁／音效／文字 - 只關那一類。
* 關閉所有 - 關掉畫面上每一個覆蓋層，不管是哪一頁開的。
* 清除日誌 - 清空右側的訊息區。

整批操作

* 全部隱藏 / 全部顯示 - 暫時收起來，再叫回來。
* 全部靜音 - 讓所有會出聲的東西安靜。
* 鎖定 / 解除鎖定覆蓋層 - 解除鎖定後可以用滑鼠把覆蓋層拖到想要的位置，
  放開時位置會被記住；鎖定時則讓點擊穿透。
* 去背色 - 把背景塗成單一顏色，方便在 OBS 之類的軟體裡去背。
* 重設覆蓋層位置 - 全部擺回一開始的地方。
* 省電模式 - 在意電池時降低更新率與算圖解析度。
* 畫質 - 高、平衡、省電，是上面那件事更細的版本。
* 從畫面擷取中隱藏 - 覆蓋層留在你自己的螢幕上，但不會出現在螢幕分享的結果裡。
  僅 Windows 有效。專注頁的遮蔽層會保持可見——遮住東西正是它唯一的用途。
* 綁在這個虛擬桌面 - 覆蓋層只留在開啟它的那個虛擬桌面上。切到別的桌面就
  自己收起來，切回來再出現。取消綁定時，被收起來的都會放回來。僅 Windows 有效。

控制中心 → 跟隨指定視窗選擇已登錄的頂層覆蓋層與可見 Windows 目標。綁定保持初始比例偏移，隨目標移動／縮放；覆蓋層維持邏輯尺寸，原生位置全用實體座標，不要求啟用或調整尺寸，限制在目標螢幕工作區，每 250 ms 檢查。目標最小化時隱藏，還原尊重使用者及全部隱藏；關閉／隱藏或識別失效解除綁定。唯一可回復視窗屬性與 PID／執行緒檢查避免 handle 重用，UIPI／較高權限目標可能明確拒絕。要拖曳到新偏移請先解除。最多 64 組暫時綁定，不跨工作階段恢復；覆蓋層關閉、全部關閉及退出清除屬性並停止閒置計時器。目前只有已驗證 Windows 介面，其他平台顯示原因。原生驗收用自己的視窗與一台 125% 螢幕，跨螢幕混合 DPI 仍待第二台設備。
