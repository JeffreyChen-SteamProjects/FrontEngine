宠物页面
--------

一只住在桌面上的伙伴。

* 选择宠物图片 - 单张图片。
* 选择宠物包… - 一个文件夹，里面有 walk / idle / sleep / climb / fall / drag
  这些动作的图，宠物就会有动画。
* 选择音效（可不选） - 它会播放的声音。
* 召唤宠物 - 放到画面上。再按一次会多一只。
* 大小、速度 - 多大、多快。
* 行为 - 在地面走动、自由漫游，或追着光标跑。
* 爬墙 - 让它沿着窗口边缘爬。
* 坐在窗口上 - 让它停在其他窗口的上沿。
* 对话气泡 - 按时段、喂食等情况说几句短话。
* 打字时安分 - 你在打字时宠物会停下来，停手一两秒后再继续走，这样它就不会
  跑过你正在看的那一行。
* 把话说出来 - 用语音把那些话念出来。
* 玩捉迷藏 - 两只以上的宠物会互相追逐。
* 跟着声音反应 - 宠物会随声音起伏动作。可以跟着**扬声器**或**麦克风**；
  两者都只读取音量电平（一个数字），不会捕获说话内容。仅 Windows 有效。
* AI 聊天（需要 API 密钥） - 和它对话。会读取 ANTHROPIC_API_KEY 环境变量，
  密钥不会被保存。
* 专注计时（分） - 宠物帮你看着的工作计时器，中间会安排休息。

把文件拖到宠物身上就是喂它；拖图片或宠物包则是换造型。
