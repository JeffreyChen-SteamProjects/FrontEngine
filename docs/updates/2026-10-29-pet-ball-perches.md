# 玩球與視窗停靠整合

整合測試發現，坐在窗沿上的地板模式寵物仍受平台範圍限制，無法追到地板上的球。新增回歸案例重現後，玩球入口改為先解除平台或牆面附著，沿既有重力落到地板；遊戲期間清空視窗平台並暫停重新偵測，收球後恢復正常偵測。帶回位置為起點水平位置附近的地板，不瞬移回高處窗沿。

驗證：修改前全部 275 項 test_pet 測試通過，但不涵蓋窗沿追球。新增的窗沿案例在修正前失敗、修正後通過。玩球與移動邏輯合計 38 項通過，另補地板、漫遊、追游標三種完整往返，以及收球後恢復平台偵測的案例。Qt 使用 offscreen，平台來源在測試中替換，沒有讀取或操作使用者桌面視窗。

原生視窗、混合 DPI 與效能驗收仍待進行。這次修正不代表全部桌面寵物需求完成。
