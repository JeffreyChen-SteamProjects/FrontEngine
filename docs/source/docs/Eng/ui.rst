How to use
----------

.. image:: ../image/main/FrontEngine.png

FrontEngine puts things on top of your screen - a video, an image, a web page,
some text, a desktop pet - and keeps them there while you carry on working.
Each of those is called an overlay. You can run as many as you like at once,
from different tabs, on different monitors.

Your first overlay
==================

1. Pick the tab for the kind of thing you want: Video, Image, Web, Text and so on.
2. Choose the file or type the address.
3. Press the start button on that page.

It appears above everything else and stays there until you close it. Nothing
else you do puts it away by accident.

Settings every page shares
==========================

Most pages carry the same handful of controls, and they mean the same thing
everywhere:

* **Opacity** - how much of the desktop shows through. Overlays default to
  fairly translucent so they sit over your work rather than hide it.
* **Target monitor** - which screen to use. Set it to *Ask* and you are asked
  each time instead.
* **Show on all screen** - put a copy on every monitor rather than one.
* **Show on all window bottom** - drop the overlay beneath your windows, so it
  behaves like a backdrop instead of something in front.
* **Recent** - files you used before, to save finding them again.

Overlays do not get in the way
==============================

Clicks pass straight through an overlay to whatever is underneath, so the
window below keeps working normally. Two things need the mouse and so are
exceptions: the pet, and the drawing layer on the Presenting page while drawing
is switched on.

Managing several at once
========================

The **Control Center** tab reaches every overlay, whichever page opened it. It
can hide them all for a moment, mute them, lock them, reset where they sit, or
drop the quality when the battery matters. Unlock them first if you want to
drag one somewhere else - it remembers where you dropped it.

Clearing the screen
===================

*Close all* in the Control Center closes everything at once, and a global
shortcut can be bound to it under Settings, Hotkeys. If anything ever stops
responding, pressing **F12** shuts FrontEngine down immediately.

The menu bar
============

* **Language** - seven languages: English, 繁體中文, 简体中文, Deutsch,
  Русский, Français, Italiano. The interface changes immediately; no restart,
  and whatever you have open stays open.
* **UI Style** - the colour theme, optionally on a day/night schedule.
* **Presets** - save how every page is set up under a name and bring it back
  later. See :doc:`menus`.
* **Settings** - hotkeys, autostart, smart pause, app profiles, reminders,
  signage mode, phone remote, screen-sharing privacy, screen time and clipboard
  history. Also :doc:`menus`.
* **Help** - *How to use...* opens a short guide inside the application, the
  same ground this page covers. It also holds the issue tracker and a reminder
  of the F12 shortcut.
* **Doc** - opens this documentation in a browser.

The tabs
========

Putting something on screen

* :doc:`video`, :doc:`image`, :doc:`web`, :doc:`gif_and_webp`, :doc:`sound`,
  :doc:`text` - one kind of thing each.
* :doc:`scene` - several of them together, saved as a file.
* :doc:`particle` - a particle effect over the desktop.
* :doc:`pet` - a companion that walks, climbs and reacts to you.

Working more comfortably

* :doc:`screen_care` - screen filter, reading ruler, break reminders,
  colour-vision simulation.
* :doc:`focus` - dim the background or cover something distracting.
* :doc:`wallpaper` - an animated wallpaper below every window.

Showing your screen to other people

* :doc:`presentation` - annotation, cursor emphasis, keystroke display,
  magnifier, whiteboard.
* :doc:`tools` - measure, capture, read text, record, virtual camera, camera,
  window pinning.
* :doc:`widgets` - audio spectrum, system monitor, now playing, sticky notes.

And :doc:`control_center` to command all of them at once.
