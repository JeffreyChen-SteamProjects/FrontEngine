# Puppet 原生 GL 呼叫移動驗證

`tests/integration/puppet_call_native.py` 使用 Windows Qt、實際 OpenGL canvas、原生視窗移動與真正的 33ms 移動計時器。測試以獨立合成模型與記憶體存檔執行，視窗及目標全程放在實體螢幕外。僅替換工作區來源為螢幕外合成範圍，沒有注入桌面鍵盤或滑鼠輸入。

本次結果保存於 `.audit/pet-implementation/native-call-2026-10-29/result.json`，status 為 passed，程序已結束。Puppet 從 `(5663, 200)` 移至 `(5823, 260)`，中心抵達指定目標後開始招呼。招呼完成只增加一次好感，移動計時器已停止。

測試模型將 walk 綁定到半透明 expression。移動中的原生 PNG 中心 alpha 為 64；抵達時釋放該反應，影像逐像素恢復原 alpha 128 的基準。另一輪呼叫在切換工作模式時取消，事先手動選擇的 expression 保留，清除後又恢復基準影像。外觀存檔、喜好、識別碼與名稱均未因移動改寫。

64 次唯讀觀測記錄到 20 個不同視窗位置，前景視窗全程相同，沒有任何測試視窗取得前景。游標位置有 55 次相異變化，因此不宣稱游標靜止；工具只呼叫 GetCursorPos 觀測，沒有操作游標。

此結果證明合成模型的原生 GL 移動、反應還原、完成與取消流程。輔助程式明確設定不接受焦點與顯示時不啟用，不能據此宣稱產品所有開窗入口皆已完成焦點驗收。正式模型動畫、真實螢幕邊界及混合 DPI 仍待驗收。
