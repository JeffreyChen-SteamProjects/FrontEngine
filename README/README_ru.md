**Разместите что угодно поверх экрана — или под ним.**

FrontEngine — это настольное приложение-оверлей. Видео, изображения, GIF,
веб-страницы, текст, частицы, звук и анимированный питомец могут быть размещены
поверх любого другого окна (со сквозным кликом, так что находящееся снизу
продолжает работать) или позади них в качестве живых обоев. Вокруг этого
собран набор инструментов для самого экрана: фильтры для комфорта глаз,
аннотирование презентаций, измерение и захват, маски для концентрации и
настольные виджеты.

## Установка

Python **3.10+**. Windows 10/11 является основной целевой платформой; macOS и
Linux запускают приложение с различиями между платформами, перечисленными в
разделе [Поддержка платформ](#поддержка-платформ).

```bash
pip install frontengine

frontengine                    # or: python -m frontengine
frontengine --preset "Work"    # apply a saved preset on launch
```

Готовые бинарные файлы для Windows находятся на
[странице релизов](https://github.com/JeffreyChen-SteamProjects/FrontEngine/releases),
а сборка Steam поставляет то же самое приложение с поддержкой Workshop.

> **Как выйти.** Оверлеи могут закрывать весь экран, включая собственное окно
> FrontEngine, поэтому есть два запасных выхода, которым не нужна мышь:
> `Ctrl+Shift+F12` закрывает все оверлеи, а **F12 полностью завершает
> приложение** откуда угодно (только Windows — см. *Help → How to force close*).

## Что оно выводит на экран

Боковая панель группирует страницы по их назначению. Этот раздел следует ей.

### На экране

Медиа-оверлеи. Каждый выбирает свой монитор (или охватывает их все), помнит,
куда вы его перетащили, и имеет собственную непрозрачность.

- **Видео** — с громкостью, скоростью воспроизведения и зацикливанием.
- **Изображение** — одна картинка, папка в виде слайд-шоу или **справочная
  доска**: несколько изображений на одном холсте, каждое перетаскиваемое, вся
  доска масштабируется и панорамируется.
- **Веб** — URL или локальный HTML-файл, при желании интерактивный. **Режим
  дашборда** прокручивает список URL-адресов, так что настенный дисплей может
  циклически переключать страницы по горячей клавише или таймеру.
- **GIF / WebP** — анимации с регулируемой скоростью.
- **Текст** — шрифт, цвет, контур, выравнивание и бегущая строка, показывающая
  либо фиксированную строку, либо **живой источник**: часы, дату, обратный
  отсчёт, секундомер, нагрузку системы или погоду. Живые источники принимают
  шаблон `{field}`, и страница перечисляет поля, которые предлагает каждый из
  них.
- **Звук** — воспроизведение музыки и WAV-эффекты с низкой задержкой.
- **Сцена** — объедините несколько из вышеперечисленного в одну композицию,
  описываемую JSON-документом, который вы можете сохранить и поделиться им.
- **Частицы** — эффект частиц на OpenGL.

### Рабочий стол

**Настольный питомец** — анимированный спрайт, живущий на вашем рабочем столе.

- **Спрайты** — один GIF/WebP/PNG или папка *пакета питомца*, имена файлов в
  которой сопоставляются с состояниями: `walk`, `idle`, `sleep`, `climb`,
  `fall`, `drag` (отсутствующее состояние откатывается к `walk`).
  Необязательный `pet.json` задаёт размер, скорость и то, может ли питомец
  карабкаться, разговаривать или сидеть на окнах.
- **Поведение** — ходить по полу с гравитацией (бросьте его, и он отскочит),
  свободно бродить или гнаться за курсором. Питомцы на полу карабкаются по
  краям экрана и стоят на верхней кромке других окон.
- **Жизнь** — настроение, сытость и уровень привязанности, которые сохраняются
  между запусками. Он растёт по мере повышения уровня, разговаривает в речевых
  пузырях, дремлет, пока вас нет, и предупреждает о низком заряде батареи.
- **Взаимодействие** — перетащите его, щёлкните правой кнопкой, чтобы
  клонировать / покормить / поставить напоминание, и **бросьте на него файл**:
  изображение или пакет питомца становится его новым обликом, всё остальное
  съедается. Важно, что именно он ест — архив это пир, музыка радует его больше,
  чем насыщает, документ это скромная трапеза, бинарник слишком трудно
  разжевать.
- **Салки** — с двумя или более питомцами на экране отметьте *Play tag with
  each other*, и один становится «водящим»: он идёт к ближайшему соседу, пока
  остальные убегают в другую сторону, а поймав кого-то, передаёт салку дальше.
- **Реагирует на звук** — питомец пульсирует в такт выводу ваших динамиков или
  вашего **микрофона**, так что он двигается, пока вы говорите. Оба читают
  только *измеритель* вывода — число, а не аудио. Пики сглаживаются окном RMS и
  огибающей с быстрой атакой/медленным спадом, так что пульс дышит, а не
  мерцает. При нескольких мониторах каждый питомец следует за аудио-конечной
  точкой, соответствующей его собственному экрану.
- **Таймер концентрации** — помодоро на той же странице, о котором объявляет
  питомец: он сообщает вам, когда концентрация заканчивается и когда перерыв
  окончен.
- **Чат** — питомец может отвечать вам через Claude, когда установлен
  `ANTHROPIC_API_KEY`. Выключено, пока вы не включите его; см.
  [Что покидает машину](#что-покидает-машину).

**Обои** — воспроизведение папки с изображениями и анимациями *под* каждым
окном. Каждый монитор указывает на свою папку со своим таймером,
перетасованную или прочитанную рекурсивно, и может пульсировать в такт уровню
динамиков. Вторая папка может взять управление в тихие часы.

**Виджеты** — четыре вещи, которые располагаются на рабочем столе:

- **Аудио-спектр** — полосы или кольцо, логарифмически распределённые полосы,
  сглаженные следящей функцией с быстрой атакой/медленным спадом, и маркеры
  пиков, которые медленно опускаются.
- **Сейчас играет** — текущий трек из медиа-элементов управления Windows, когда
  установлены необязательные привязки `winsdk`; иначе имя приложения, которое
  действительно издаёт звук.
- **Системный монитор** — процессор, память, диск, батарея и пропускная
  способность сети в виде маленьких спарклайнов; отметьте нужные линии.
  Среднее скрывает подвисание; линия — нет. Скрытая линия продолжает запись, так
  что при её повторном включении видно, что происходило тем временем.
- **Стикеры** — редактируемые карточки поверх каждого окна, сохраняющие свой
  текст, цвет и положение между сессиями.

### Работа

**Концентрация** — два оверлея на случай, когда экран соперничает с вашей
работой. *Затемнить фоновые окна* затеняет всё, кроме окна, в котором вы
работаете, с регулируемой силой. *Закрыть отвлечение* маскирует полосу экрана:
панель задач, угол с уведомлениями, край или всё сразу. Оба пропускают клики
насквозь, так что закрытое ими продолжает работать — просто перестаёт
притягивать взгляд.

**Забота об экране** — для долгих сессий за экраном:

- **Цветовой фильтр** — семь оттенков от тёплого через янтарный и розовый до
  серого, с регулируемой силой.
- **Линейка для чтения** — затемняет страницу и оставляет яркую полосу, которая
  следует за курсором.
- **Напоминание о перерыве** — правило 20-20-20, с оверлеем отдыха, когда
  интервал истёк.
- **Симуляция цветовосприятия** — протанопия, дейтеранопия, тританопия и
  ахроматопсия с регулируемой степенью, с использованием модели Machado et al.
  (2009). В отличие от других оверлеев этот непрозрачен, потому что показать то,
  что видит кто-то другой, означает перерисовать экран, а не тонировать его.

**Презентация** — для демонстраций, уроков и записей:

- **Аннотация** — рисуйте по экрану пером, маркером или ластиком, с отменой и
  очисткой.
- **Эффекты курсора** — кольцо вокруг указателя, рябь при клике и прожектор,
  затемняющий всё остальное.
- **Отображение нажатий клавиш** — показывает, что вы только что нажали и какую
  кнопку мыши щёлкнули, чтобы зрители могли следить; исчезает через пару секунд.
  Выберите, где располагается панель и насколько крупный текст, и отключите
  клики мыши отдельно.
- **Лупа** — увеличенный вид области вокруг курсора.
- **Доска** — бесконечный холст: тяните для панорамирования, прокручивайте для
  масштабирования, сохраняйте нарисованное. Штрихи живут в координатах холста,
  так что панорамирование и масштабирование оставляют их там, где им место.
- **Заморозка** — закрепите текущий кадр монитора, чтобы продолжать работать за
  неподвижным изображением. `Ctrl+Shift+F7` освобождает его, что важно, потому
  что замороженное изображение закрывает кнопку, которая бы это сделала.

**Инструменты** — измерение, захват и работа с окнами:

- **Пипетка / пиксельная линейка / транспортир** — щёлкните, чтобы взять пробу
  или измерить; результат сразу попадает в буфер обмена как `#rrggbb`,
  `rgb(...)`, `hsl(...)` или пользовательское CSS-свойство.
- **Захват области** — растяните область; она попадает в буфер обмена, может
  быть сохранена в файл или **закреплена** сверху как плавающая, масштабируемая
  копия.
- **Запись области** — запишите область в анимированный GIF, с камерой,
  скомпонованной в углу, для вида реакционного видео. Ограничена как
  длительностью, так и количеством кадров, потому что каждый кадр удерживается в
  памяти.
- **Камера** — ваша веб-камера в круге, скруглённом прямоугольнике или
  прямоугольнике, показываемая локально и никогда не записываемая. Работает
  любой видеовход, включая карты захвата, и список устройств обновляется без
  перезапуска, поскольку карты обычно подключают, когда приложение уже запущено.
- **Виртуальная камера** — отправьте область, вместе со всеми оверлеями, как
  веб-камеру, которую Zoom, Teams или Discord могут выбрать в качестве
  видеоисточника. Нужен необязательный пакет `pyvirtualcam` и драйвер
  виртуальной камеры (OBS устанавливает один); без чего-либо из этого кнопка
  сообщает об этом, а не тихо отказывает.
- **Прочитать текст** — растяните область, чтобы скопировать текст в ней,
  перевести его или задать о нём вопрос. Это отправляет выделение за пределы
  машины; см. [Что покидает машину](#что-покидает-машину).
- **Закрепить окно** — держите окно другой программы сверху или притушите его,
  пока работаете рядом с ним. Затрагиваются только порядок наложения и
  непрозрачность, никогда содержимое окна.
- **Реплика окна** — маленькая живая копия другого окна, всегда поверх всех, так
  что вы можете следить за рендером или чатом, пока он погребён.
- **Раскладки окон** — сохраните, где располагается каждое окно, и верните их
  позже. Окна сопоставляются по заголовку; то, которого нет на экране,
  пропускается, а не угадывается.

## Управление всем сразу

Страница **Центр управления** достигает каждого оверлея на каждой странице,
какая бы вкладка его ни открыла: скрыть, показать, закрыть, приглушить,
заблокировать, сбросить позиции, изменить непрозрачность шагами и применить
**уровень качества** (высокое / сбалансированное / экономное), который
ограничивает частоту обновления каждого оверлея и снижает разрешение его
рендеринга. Она также несёт фон цветности для OBS, переключатель *Скрыть от
захвата*, панель журнала и **Закрепить на этом рабочем столе** — оверлеи
отходят в сторону, когда вы переключаете виртуальный рабочий стол, и
возвращаются, когда вы возвращаетесь. Открепление возвращает всё, что оно
убрало.

Глобальные горячие клавиши по умолчанию, все переназначаемые из **Settings →
Hotkeys**:

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+F12` | Close every overlay |
| `Ctrl+Shift+F11` / `F10` | Hide / show every overlay |
| `Ctrl+Shift+F9` | Mute everything |
| `Ctrl+Shift+↑` / `↓` | Opacity up / down |
| `Ctrl+Shift+L` | Lock or unlock (click-through vs draggable) |
| `Ctrl+Shift+→` | Next dashboard page |
| `Ctrl+Shift+F8` | Show the shortcut sheet on screen |
| `Ctrl+Shift+F7` | Freeze / unfreeze the screen |
| `Ctrl+Shift+F6` / `F5` / `F4` | Media play/pause, next and previous track |
| `Ctrl+Shift+F3` | Move the foreground window to the next monitor |
| `F12` | Quit immediately (Windows) |

Транспорт медиа посылает системные медиа-клавиши, так что он достигает любого
проигрывателя, который их слушает. Перемещение окна сохраняет его пропорции, а
не перекидывает его целиком, что делает собственное `Win+Shift+Arrow` Windows.

Те же действия — и ничего сверх них — это то, чем управляют удалённые пульты:

- **Ваш телефон** (Settings → Remote control) — FrontEngine обслуживает
  небольшую страницу в вашей локальной сети; откройте ссылку на телефоне, и
  кнопки управляют этими действиями.
- **MIDI-контроллер** — нажмите *Learn*, поверните ручку или нажмите пэд, и
  привяжите его. Он использует встроенный winmm Windows, так что не нужен
  дополнительный пакет. Ручка срабатывает, как только достигает верха, а не
  многократно по пути, и отпускание пэда не считается вторым нажатием.

## Пресеты и автоматизация

**Пресеты** захватывают настройки каждой страницы сразу. Сохраняйте,
загружайте, удаляйте, экспортируйте и импортируйте их из меню **Presets**,
применяйте один при запуске или автоматически восстанавливайте предыдущую
сессию. Пресет можно экспортировать как **пакет** — zip, несущий медиа, на
которое он ссылается — так что он открывается на машине, где этих файлов нет.

Вещи, которые затем решают за себя сами, все из меню **Settings**. Умная пауза
единственная, которая начинает работу включённой; всё остальное выключено, пока
вы это не включите.

| | |
| --- | --- |
| **Правила** | *«Когда выполняются эти условия, делай это.»* Скомбинируйте день недели, временное окно и то, какое приложение в фокусе, затем примените пресет, скройте/покажите/закройте оверлеи или установите качество. Пустое условие означает «любое», и правило срабатывает **один раз**, когда его условия начинают выполняться, а не многократно, пока они выполняются. Это единственное место, где условия комбинируются; каждая из строк ниже знает единственный вид. |
| **Умная пауза** | Отставить оверлеи, пока работает полноэкранное приложение, пока машина на батарее или пока названное приложение в фокусе. *(Включена по умолчанию, для полноэкранного правила.)* |
| **Профили приложений** | Применить пресет, когда вы переключаетесь на заданное приложение. |
| **Расписание пресетов** | Применить пресет в выбранные дни недели в заданное время. |
| **Расписание темы** | Переключаться между дневной и ночной темой по часам. |
| **Режим вывесок** | Прокручивать список пресетов по таймеру с убранным главным окном, для машины, оставленной работать как дисплей. |
| **Заставка** | После порога бездействия вывести выбранные вами видео / изображение / GIF / частицы / веб-страницу и убрать их, когда вы вернётесь. |
| **Напоминания** | Каждые N минут или раз в день в заданное время, показываемые как всплывающее уведомление, которое закрывается само. |
| **Не давать уснуть** | Не давать дисплею засыпать, пока оверлеи подняты. |
| **Запуск с системой** | Запуск при входе в систему. |
| **Экранное время** | Какие приложения были в фокусе и как долго, с суточной разбивкой и семидневной сводкой. Оно приостанавливается, пока вы вдали от клавиатуры, хранит не более 60 дней, а очистка удаляет сам файл. |
| **История буфера обмена** | Ищите то, что вы скопировали, и закрепляйте фразы, которые повторно используете. Буферы обмена регулярно хранят пароли, поэтому это держится **только в памяти**, если вы отдельно не отметите «хранить между сессиями». |

## Заметки о конфиденциальности и платформах

### Что покидает машину

Всё в FrontEngine локально, если только это не в этом списке. Есть четыре
исключения, все с явным согласием:

| Feature | Where it goes | Guard |
| --- | --- | --- |
| **Read text** (Tools) | Выбранная область отправляется в API Anthropic | Спрашивает один раз перед первой отправкой и запоминает ответ; согласие можно отозвать из окна результата. Использует ваш собственный `ANTHROPIC_API_KEY`, считываемый из окружения и никогда не записываемый в файл настроек. Ничего не отправляется без обоих. |
| **Pet chat** | Ваше сообщение идёт в API Anthropic | Тот же ключ, то же правило; выключено по умолчанию. |
| **Weather** (text source) | Координаты идут в Open-Meteo | Без ключа, без учётной записи, без идентифицирующих данных; только то, что вы ввели как местоположение. |
| **Phone remote** | Обслуживает страницу в вашей локальной сети | Выключено по умолчанию. Ссылка несёт токен, перегенерируемый при каждом старте, так что старая ссылка перестаёт работать, а страница может запрашивать только фиксированный список действий. Это простой HTTP: кто-то другой в той же сети мог бы прочитать токен и нажать те же кнопки — скорее неудобство, чем брешь, учитывая то, что делают эти кнопки, но оставьте его выключенным в сетях, которым вы не доверяете. |

Аудиофункции читают только *измеритель* вывода — одно число — за исключением
спектра, которому нужны реальные сэмплы для вычисления частот, и потому он
захватывает поток вывода системы. Эти сэмплы анализируются в памяти, никогда не
записываются на диск и никуда не отправляются, а захват прекращается в тот
момент, когда вы останавливаете спектр.

**Плагины** — это Python и работают с теми же привилегиями, что и FrontEngine —
их нельзя изолировать в песочнице. Загрузка выключена по умолчанию (Settings →
Load plugins), каждая загрузка записывается в журнал, а один сломанный плагин
пропускается, а не останавливает приложение. Устанавливайте только плагины,
которым доверяете.

### Конфиденциальность при демонстрации экрана

Ваши оверлеи для вас, а не для людей, которым вы демонстрируете. Из **Settings →
Screen-sharing privacy** FrontEngine может убрать их из захвата, пока открыто
приложение для встреч:

- **Они остаются на вашем собственном экране.** Пустой только захваченный экземпляр —
  это использует `WDA_EXCLUDEFROMCAPTURE` Windows, флаг уровня ОС, который
  соблюдают приложения для конференций и рекордеры.
- **Маски — исключение.** Маска отвлечения существует, чтобы что-то закрыть,
  поэтому она намеренно остаётся видимой в захвате.
- **Триггер — ваш список.** У Windows нет надёжного API «захватывают ли меня»,
  поэтому оно следит за названиями окон, которые вы указываете — что также
  ловит встречу, проводимую во вкладке браузера, где исполняемый файл — это
  просто браузер.

В центре управления тоже есть ручная кнопка *Hide from capture*.

> Это конфиденциальность, а не безопасность: она побеждает обычный путь
> захвата и никогда ничего не скрывает от человека, сидящего за столом.

## Расширение

- **Steam Workshop** — подписанные элементы подхватываются из собственной папки
  Steam `steamapps/workshop/content`: пресеты импортируются, а пакеты питомцев
  перечисляются со своими путями, из **Presets → Import Workshop content**.
  Публикация в Workshop требует Steamworks SDK и не встроена.
- **Плагины** — папка `plugins/` может добавлять собственные вкладки, либо через
  сопоставление `FRONTENGINE_TABS = {"name": WidgetClass}`, либо через хук
  `register(registry)`. Сначала прочитайте примечание о доверии выше.

## Разработка

```bash
pip install -r dev_requirements.txt
pip install -e .

python -m pytest tests/ -q          # the whole suite, headless (Qt offscreen)
```

Статическая проверка использует pyflakes (в `dev_requirements.txt`), а чистое
дерево не печатает вообще ничего:

```bash
python -m pyflakes frontengine/ exe/ tests/
```

Набор тестов выполняется полностью вне экрана и не нуждается в дисплее, звуковой
карте или камере; всё, что касается внешнего мира, принимает внедряемый
источник, так что его можно тестировать с фальшивым.

- **Архитектура** — [`architecture_explore.md`](../architecture_explore.md)
  отображает каждый модуль, слои, контракт оверлеев и точки расширения.
  Прочитайте её перед добавлением страницы или оверлея: несколько вещей (реестр
  центра управления, семь языковых словарей, семь деревьев документации) должны
  обновляться вместе, и тесты это обеспечивают.
- **Участие** — см. [`CONTRIBUTING.md`](../CONTRIBUTING.md). Одна функция на
  pull request, все проверки CI зелёные.
- **Сборка исполняемого файла Windows** — `python exe/build_exe.py`
  (Nuitka; добавьте `--onefile` для одного файла).
- **Документация** — исходники Sphinx в `docs/`, опубликованные на
  [Read the Docs](https://frontengine.readthedocs.io/en/latest/) на всех семи
  языках.

## Непрерывная интеграция и релизы

Работа течёт `feature → dev → main`, и только последний шаг публикует:

```
feat/xyz  ──PR──►  dev  ──PR──►  main
                    │              │
              CI, no release   CI + release
```

| Workflow | Trigger | Purpose |
| --- | --- | --- |
| `CI` (`ci.yml`) | Push / PR to `main` or `dev`, manual dispatch, or called by `Nightly` | Compile, run the unit tests, then build a wheel from *that checkout*, install it and start the app — on Python 3.10 / 3.11 / 3.12, Windows |
| `Nightly` (`nightly.yml`) | Daily cron, manual dispatch | Calls `CI`. The schedule lives here on purpose: GitHub disables workflows containing a cron after ~60 days of inactivity, and that would otherwise take the PR checks down with it |
| `Release` (`release.yml`) | A pull request **from `dev`** is merged into `main`, or manual dispatch | Bumps the version, commits it back with `[skip ci]`, swaps `stable.toml` → `pyproject.toml`, builds sdist + wheel, uploads to PyPI as `frontengine`, creates a GitHub release tagged `v<version>`, and fast-forwards `dev` |

Публикация происходит **только когда `dev` сливается в `main`**. Функции
приземляются на `dev`, не чеканя версию, а релиз — это намеренный pull request
`dev → main`. Функциональный PR, по ошибке нацеленный на `main`, всё равно
сливается, но не публикует — направление отказа это отсутствующий релиз, а не
нежелательный.

Сегмент патча повышается автоматически; для минорного или мажорного релиза
запустите *Actions → Release → Run workflow* и выберите сегмент. Этот путь также
перезапускает неудавшуюся публикацию без необходимости в новом слиянии.

Версии живут в двух файлах: `pyproject.toml` — это dev-пакет
(`frontengine_dev`), а `stable.toml` — опубликованный (`frontengine`).

Требуется один секрет репозитория: `PYPI_API_TOKEN`, токен PyPI с областью
действия для проекта `frontengine`. Workflow использует `__token__` как имя
пользователя twine, так что нужно хранить только сам токен.
