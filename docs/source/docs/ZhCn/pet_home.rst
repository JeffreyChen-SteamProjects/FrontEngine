宠物家园页面
------------

**宠物家园** — 第一页。已保存的宠物可以搬进一个小家园，在那里自己生活，并靠工作赚取家园币。

* *创建家园* 会给一张床、一张餐桌、一张书桌和 10 枚家园币。按下之前什么都不会创建或启动，其他功能不需要家园也能使用。建立家园之前，所有已存的宠物都会列在 *和你一起搬进来的宠物* 下面并默认勾选，不想搬的取消勾选即可。勾选的宠物以原本的身份搬进来——同样的标识、名字、亲密度、心情、饱足、精力、造型与衣柜——不会复制或重置；没搬的宠物之后可以从居民标签页再搬进来，初始物资也不会重发。家园的一年有四季，每季七个游戏日——春、夏、秋、冬——会显示在状态栏，总览的天空也会出现花瓣、落叶或雪花（开启 *减少动态* 时静止不动）；冬天的雨会变成雪。每一季都有一个当季目标（种花、玩耍、收成香草、放松），只会发一次奖励；错过的季节明年还会再来。 还没有任何宠物时，「建立家园」会顺便带来第一只宠物并选中它。
* *搬进家园* 一只已保存的宠物，或用 *新宠物* 创建一只。同一只宠物不会同时住在家园和桌面上；它的精力、饱足、心情与亲密度会带进来，搬离时写回它的角色记录。
* *布置* 把收纳中的家具放到地板上。红色预览会说明为什么不能放（超出家园范围、那里已经有东西、挡住出入口），按 Esc 结束布置。*收纳* 会把家具收回，正在那里进行的工作会暂停并保留进度。布置时可以直接拖动家具，或选中后按 ← ／ → 一次移一格；*撤销* 与 *重做*\ （Ctrl+Z ／ Ctrl+Y）涵盖所有配置变更。*复制配置* 会把配置码放到剪贴板（只有家具与位置，不含宠物、金币或任何个人资料），*粘贴配置* 再读回来；四种现成配置（*新手家园*、*温馨角落*、*工坊*、*园艺工作室*）在 *应用配置* 购买并摆好之前，会先显示还缺什么与价格，原来的配置按一次 *撤销* 就回来。*在地板上画区域* 可以把一段地板标成 *居住*、*工作*、*休闲* 或 *用餐*\ （或清除标签）；宠物会优先使用标签符合当下活动的家具，但不会被禁止使用其他家具。接上第二台屏幕时，*在那个屏幕新增区域* 会在那里多一个有自己桌面长条的区域，*把这个区域移过去* 可以搬移区域；宠物只有通过 *移到那个区域* 才会换区。屏幕被拔掉时，那个区域的宠物会等待、家具留在原处，不会复制任何东西，屏幕回来后就继续生活。*猫爬架* 与 *攀爬墙* 在高处：活泼的宠物会自己跳上去，其他宠物需要旁边有 *宠物阶梯*；两者都没有时，红色预览会显示「没有宠物上得去」。工作台一律放在地面。*入口通往* 可以把两个区域的入口连成交通点：宠物空闲时偶尔会走过去串门，睡觉时间再走回自己的床，不会走进未连接的屏幕。*分享蓝图…* 会把整个家园的房间与家具存成 JSON 文件——不含宠物、名字、金币、目标、屏幕名称或任何个人资料；*拜访蓝图…* 以只读方式打开这种文件：可以逛各个房间，但不会运作、不会购买、不会存档，也完全不联网。不是蓝图的文件会被拒绝；这个 FrontEngine 没有的家具会列出名称，而不显示出来。
* *工作* 不需要设置：宠物在工作时段会按家里的工作台自己接工作，先做自己擅长的行业，只用背包里已有的材料；标签页会列出每只正在做什么，附上产出物的图，任何工作都能取消。每个完成的单位只付一次钱，取消的不付钱。起始家具会自己摆好，*摆放* 会把收纳中的家具放到第一个空位（或用 *布置* 点地板指定位置），在 *商店* 买的家具直接进家里，完成的 *新手目标* 奖励与物品足够的委托会自动结算。商店、背包与收纳都以图片显示每件家具和物品。格子内的名称与价格分行显示，格子大小随字体调整，较长的完整名称仍可在工具提示中查看。*设置* 标签页只保留在桌面显示家园与减少动态。工作台可以从右键菜单或家具标签页 *升级* 两次（价格依家具与等级而定，自由布置时免费）；同一种工作台共用等级，所以收起或重新布置都不会失去，每升一级工作快四分之一。空闲的宠物可能会走过去帮正在工作的宠物——最多两位帮手，每位让速度再加四分之一——也会学到一点那项职业。仓库里某样成品已有二十个时，自动工作就不再做它。家具会显示正在发生的事：有人使用时有一个圆点，有宠物在工作时显示该职业的工具（✎ ❀ ⚒），完成一份工作后显示 ✓ 几秒钟。勾选 *专注时宠物陪我一起工作* 后，开始宠物页的专注计时会替每只有空的宠物排一个工作请求——不会打断它正在做的事、工作照一般奖励计算，也不读取你打的字、不在意你暂停——休息或停止计时时，只收回家园自己排的请求。每项职业都有一份进阶工作，需要技能等级 4 的宠物，以及等级 4 的家园：*写一部长篇小说*\ （120 金币）、*扎一束花*\ （三朵花扎成价值 30 的花束）与 *做一个音乐盒*\ （三份木材加一个玩具，做成价值 80 的音乐盒）。
* *商店* 出售更多家具；卖回最多拿回半价，基本的床、餐桌与书桌不能买卖。家园共有 45 件家具，每件都有自己的用途或风格（从宠物软垫到双层床的床铺、餐桌、每种职业各有工作台、沙发、懒人沙发、球池、钢琴、地毯、鱼缸等）；部分要家园等级更高才会开放，商店会标示所需等级，短篇故事、花与木凳也一样。*收藏* 标签页有家具图鉴（每件家具与获取方式）、宠物的作品与相册。因为作息已自动安排，新手目标“选择作息”改为“摆一件装饰”；旧存档的状态会保留。家具包可以在商店与收藏里加入家具：每个家具包是 ``pet-home-packs`` 里的一个文件夹（设置标签页的 *打开家具包文件夹*），里面有 ``pack.json``——格式 ``frontengine.home-pack`` 第 1 版、与文件夹同名的稳定 ID、名称、来源与授权，以及最多 64 件家具（ID、名称、类别、宽度、是否实心、互动点、用途、需要的姿势、价格与舒适度）——每件家具都要有 ``furniture/warm_home/<art>.png`` 图片（其他主题可省略），另附 ``thumbnail.png``。只要有未知字段、指向家具包外的路径或链接、不是 PNG 或超过 2 MB 的图片、重复的 ID，或任何可执行的文件，整个家具包都会被拒绝，原因会显示在设置标签页；家具包里的东西一律不会被执行。家具的 ID 会变成 ``<pack>__<id>``，移除家具包后，存档里的这些家具会先保留着，等家具包装回来。 第二批家具新增落地灯、吊挂盆栽、衣橱、和式床垫、暖桌、电视、壁炉、摇摇马、望远镜与淋浴间。
* 内容包也可以带主题：名称、沿用哪套内置主题的家具图，以及地板、白天天空与夜晚天空的颜色；主题会加入家具分页的主题列表，只有主题的包也可以。使用的主题所属的包被移除时，家园会保留该主题，在包回来之前以温暖小屋的样子呈现。家具包、主题与蓝图在 Steam 创意工坊上也是各自独立的类别：订阅的包与主题会在下次启动 FrontEngine 时出现在家园，订阅的蓝图则以只读参观打开。蓝图会写明需要哪些内容包，创意工坊列表和参观画面都会标出还没安装的包。
* 页面排得像游戏画面：家园在最上方，同一行显示日子、时间、天气、金币与 *开始* ／ *暂停*；*居民*、*工作*、*家具*、*商店*、*背包*、*目标*、*待阅*、*收藏* 与 *设置* 是下方的标签页，使用时家园一直看得到。还没有家园时，上方会显示新家园附带的床、餐桌与书桌，旁边是 *创建家园*。总览下方有 *回到桌面*、*背包*、*目标* 与缩放（− ／ + 或 Ctrl+滚轮），以及 *等你处理* 列表，列出家园无法自己解决的事（还没有宠物、待阅新消息、收纳里的家具、等材料的工作、可以举办的庆典、愿望），点一行就打开对应标签页。布置时桌面长条会显示 *布置完成*，因为长条不接收键盘。较新版本 FrontEngine 的存档会提供 *获取最新版 FrontEngine*。*自由布置* 会切换到另一个独立的家园（``pet-home-sandbox.json``），所有家具都能用、不花钱也没有金币；在那里做的事不会影响经营中的家园、它的金币与目标，也不会改到宠物本身的数值。来回切换时会先保存，并取消宠物正在做的事、不发奖励。
* 只有家园在进行中（*开始*／*暂停*）时时间才会前进；FrontEngine 关闭或电脑睡眠的时间不会补算。家园保存在设置文件旁的 ``pet-home.json``，上一份正常的存档保留为 ``pet-home.json.bak``。读不了的存档或较新版本的存档永远不会被覆盖：页面会提供还原备份，或保留旧文件后创建新家园。
* 穿上分层角色（内置的 INKSIDE 角色或衣柜里的角色）的宠物，会以它本来的样子出现在家园里：在路上时走路、在书桌或扶手椅上坐着、在床上睡觉、在餐桌吃饭、在玩具箱玩、互相打招呼，并朝着走路的方向。居民的 *衣柜…* 会打开原本的衣柜，换好的造型会立刻出现在家园。角色在后台加载；加载完成前会先用彩色标记代替。曾在桌面上出现过的图片宠物（GIF、图片或精灵包）与 Puppet 宠物，在家园里也会以自己的样子出现：精灵包用自己的走路、待机与睡觉动画，GIF 用自己的帧，Puppet 则用从自己画布拍下的静态图；只有一张静态图的宠物走路时会弹跳、玩耍时会跳起、睡觉时会缩成一团。没有可用外观的宠物（新宠物，或图片后来被移走）会以固定的一位内置角色出现；它本身的外观与桌面宠物都不会改变。没穿衣服、保持默认部件与颜色的内置角色有专属的手绘姿势：躺在床上睡、坐在扶手椅、吃饭、玩耍、在书桌写字、给花槽浇水、在工作台敲打（坐、睡、吃、玩在桌面上也看得到）。穿上衣服或换了颜色时，则保持分层动画，在工作位置坐着。仍穿着旧版内置角色的宠物会自动换到当前版本，衣服与颜色都保留。
* 家园有四种 *模式*：*一般*；*专注*，桌面长条保持安静（没有气泡与卡片）；*会议*，隐藏家园并暂停，状态会明说；*省电*，长条每秒只画 15 帧，宠物的生活速度不变。共享屏幕期间会自动切到会议模式。*待阅* 会收集工作完成、需求、生活点滴与问题，重复的事件合成一行，从不弹窗或抢焦点；宠物自己去吃饭睡觉不会列出来。
* 家园有白天、夜晚和天气：总览的天空会随游戏时钟从黎明变到夜晚，晴天、多云或雨天每六个游戏小时变换一次，由家园本身决定，所以每次都一样。天气只是氛围，不会弄坏东西，也不会让你干等。三套主题（*温暖居家*、*绿意工作室*、*夜间创作室*）只改颜色，不改布局。家具是用 Blender 建模的描边卡通图，颜色会配合各套主题；选中家具或布置时才会显示名称。听雨的日子、星光夜晚、交到好朋友、手艺精进、绿意之家、热闹之家、第一篇短篇故事和丰收也加入生活点滴，一共十二种。*减少动态* 会让宠物不在步伐之间滑动、雨也保持静止；所有事件也都会写在卡片与点滴列表里，家园本身没有声音。
* 环境音在 *设置* 分页开启前都是关闭的，并有独立的音量：白天鸟鸣、夜晚虫鸣，下雨或下雪时是雨声或轻柔的冬风。家园暂停、会议中或电脑锁定时不会发声。桌面长条在傍晚与夜里会让家具和宠物稍微变暗；长条的空白处仍保持透明，点击照样穿透到后面的窗口。 下雨或下雪时，桌面长条上也会落下雨滴或雪花，画在一层完全不接收鼠标与焦点的独立图层上；专注与会议模式会暂停，*减少动态* 时则静止不动。
* *目标* 会随着家园成长：家园等级靠生活里程碑提升（三种工作都做过、更多居民、更多家具、深厚的友谊），十个 *新手目标* 附小额奖励、完成后自动领取（随时可以跳过，之后仍可回看），每天三笔 *委托* 用家园币收购商品、没有连续登录奖励也没有错过惩罚，每只宠物一个说明达成方式、永不倒计时的小愿望，生日、第一件手作、好友聚餐等生活点滴，以及两只以上宠物同住且三种工作都做过之后的一次性家园庆典。*拍一张合照* 会把家园画面保存到设置文件旁的 ``pet-album``，不会截取你的桌面。背包会显示家具图鉴的收集度。
* 宠物也需要舒适与陪伴。床、扶手椅和装饰让家更舒适，舒适度太低会让心情变差。宠物会互相打招呼、一起吃饭玩耍而变得更亲近，偶尔也会为了最后一个空位闹别扭。每只宠物都有固定的性格（勤快、爱玩、安静、爱社交，或喜欢园艺、写作、手作），会影响它的选择，做喜欢的工作也稍微快一点；没有哪种性格会让宠物不适合做任何事。卡片会显示性格、最要好的朋友，以及当前动作还剩几分钟；桌面上的小气泡会说出宠物刚开始做什么、跟谁打了招呼、赚了多少。旧的家园存档读取时会补上新需求；这个版本保存的家园不会被旧版 FrontEngine 覆盖。
* 宠物也喜欢保持干净：清洁度会慢慢下降（玩耍时降得更快），觉得脏的宠物会就地整理毛发，或去浴缸泡澡（更快）；梳毛也有帮助，家里没有浴缸却有脏兮兮的宠物时，家园下方的清单会建议买一个。
* 三种工作：在书桌写作、在 *花盆* 园艺（香草让用餐更开心，花可以卖）、用商店买的木材在 *工作台* 手作（玩具可以卖，木凳做好直接进收纳）。工作分成看得到的阶段（播种、浇水、采收…），材料不够时会等待而不是硬做。*背包* 列出家园拥有的所有东西、保留给工作的数量，并能卖出商品。买价一定高于卖价，任何工作链都不能把东西变回自己。
* 家园也会出现在桌面上：沿着屏幕底部、站在任务栏边缘的一条透明长条。只有宠物、家具和小小的 ⌂ 按钮会接收鼠标，其他像素都会穿透到后面的窗口，长条也不会抢走焦点。点宠物看它的卡片，右键下指令，拖拽可以移动它；家具按右键可以收纳。*在桌面显示家园* 可以关掉它，*桌面图层* 决定放在窗口上层或下层（默认上层）；全部隐藏时家园会暂停，重新显示才继续；控制中心的画质设置决定每秒 60、30 或 15 帧，不影响家园生活的速度。⌂ 旁边的箭头会展开工具栏，有 *布置*、*居民*、*工作*，以及金币、最后点选的宠物与进行中的工作；⌂ 菜单可以把工具栏移到长条另一端，展开与否和位置都会记住。宠物的右键菜单最前面是 *喂食*、*摸摸*、*聊天*——稍微提升饱足、心情或陪伴，每种每半分钟最多一次，正在别处休息的宠物不能用——接着是 *请它去*\ （各种指令）、*衣柜…*、*安排这只宠物的工作…* 与 *在总览中跟随*\ （总览放大时让它保持在画面内）。家具的右键菜单会说明用途与目前谁在使用，并提供 *移动*\ （直接在桌面上布置）与 *收起*。锁定电脑时家园也会同样暂停，状态栏会显示原因，直到解锁为止。把文件拖到家园里的宠物身上就等于喂食（同样每半分钟一次）；文件不会被打开、修改或删除，也不会变成材料或金币。宠物菜单还有 *理毛* 与 *玩玩具*\ （工作、吃饭或睡觉时不行）、*过来这里*\ （走到你按右键的位置并在那里待一下）、*玩捉人游戏*\ （找最近的空闲宠物一起玩，正在忙的不会被拉进来，两只都会开心）与 *拍张照*\ （从总览拍下这只宠物，存进相册）。
* 长条可以缩小或放大（75–200 %，家具、宠物与高度一起变）：在宠物或家具上按住 Ctrl 滚动鼠标滚轮、⌂ → *大小*，或在设置分页选择，选择会被记住。放大后比屏幕宽的家园仍留在屏幕内，并平滑跟随最后点选的宠物（或所有宠物）保持在画面中。在长条上双击宠物就能摸摸它。

家园设置中的模式菜单在手动选择会议模式而隐藏桌面长条后仍可使用。撤销与重做按房间分别记录；若家具不可用或放不下，会保留当前布局与记录，以便稍后重试。Esc 可取消布置与区域绘制。连续拍照会分别保存文件。一次性生活事件离开近期记录后仍会保留触发状态，暂时移除家具包也会保留已付费的工作站升级。旧存档只能恢复其中仍保留的事件记录。
