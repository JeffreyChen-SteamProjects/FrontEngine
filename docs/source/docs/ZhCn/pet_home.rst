宠物家园页面
------------

**宠物家园** — 第一页。已保存的宠物可以搬进一个小家园，在那里自己生活，并靠工作赚取家园币。

* *创建家园* 会给一张床、一张餐桌、一张书桌和 10 枚家园币。按下之前什么都不会创建或启动，其他功能不需要家园也能使用。
* *搬进家园* 一只已保存的宠物，或用 *新宠物* 创建一只。同一只宠物不会同时住在家园和桌面上；它的精力、饱足、心情与亲密度会带进来，搬离时写回它的角色记录。
* *布置* 把收纳中的家具放到地板上。红色预览会说明为什么不能放（超出家园范围、那里已经有东西、挡住出入口），按 Esc 结束布置。*收纳* 会把家具收回，正在那里进行的工作会暂停并保留进度。
* *工作* 把工作交给选中的居民，例如在书桌写信（每封 2 分钟、12 家园币）。宠物会自己走到书桌、工作、累了去睡、饿了去吃，然后回来继续；每完成一份只入账一次，取消的那份没有报酬。
* *商店* 出售更多家具；卖回最多拿回半价，基本的床、餐桌与书桌不能买卖。
* 只有家园在进行中（*开始*／*暂停*）时时间才会前进；FrontEngine 关闭或电脑睡眠的时间不会补算。家园保存在设置文件旁的 ``pet-home.json``，上一份正常的存档保留为 ``pet-home.json.bak``。读不了的存档或较新版本的存档永远不会被覆盖：页面会提供还原备份，或保留旧文件后创建新家园。
* 家园也会出现在桌面上：沿着屏幕底部、站在任务栏边缘的一条透明长条。只有宠物、家具和小小的 ⌂ 按钮会接收鼠标，其他像素都会穿透到后面的窗口，长条也不会抢走焦点。点宠物看它的卡片，右键下指令，拖拽可以移动它；家具按右键可以收纳。*在桌面显示家园* 可以关掉它，*桌面图层* 决定放在窗口上层或下层（默认上层）；全部隐藏时家园会暂停，重新显示才继续；控制中心的画质设置决定每秒 60、30 或 15 帧，不影响家园生活的速度。
