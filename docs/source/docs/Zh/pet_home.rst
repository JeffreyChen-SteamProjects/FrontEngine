寵物家園頁面
------------

家園操作訊息會隨語言切換更新，並保留數量、檔案路徑與原始錯誤內容。存檔成功會清除對應的失敗提示，不會清除較新的操作訊息。

選取家具的名稱與提示會在窄面板換行，家具分頁不會因此撐寬其他家園分頁。 家園標題及背包、收藏中的家具統計也會隨窄面板換行。

**寵物家園** — 第一頁。已儲存的寵物可以搬進一個小家園，在那裡自己生活，並靠工作賺取家園幣。

* *建立家園* 會給一張床、一張餐桌、一張書桌和 10 枚家園幣。按下之前什麼都不會建立或啟動，其他功能不需要家園也能使用。建立家園之前，所有已存的寵物都會列在 *和你一起搬進來的寵物* 底下並預設勾選，不想搬的取消勾選即可。勾選的寵物以原本的身分搬進來——同樣的識別碼、名字、親密度、心情、飽足、精力、造型與衣櫃——不會複製或重設；沒搬的寵物之後可以從居民分頁再搬進來，初始物資也不會重發。家園的一年有四季，每季七個遊戲日——春、夏、秋、冬——會顯示在狀態列，總覽的天空也會出現花瓣、落葉或雪花（開啟 *減少動態* 時靜止不動）；冬天的雨會變成雪。每一季都有一個當季目標（種花、玩耍、收成香草、放鬆），只會發一次獎勵；錯過的季節明年還會再來。 還沒有任何寵物時，「建立家園」會順便帶來第一隻寵物並選取牠。
* *搬進家園* 一隻已儲存的寵物，或用 *新寵物* 建立一隻。同一隻寵物不會同時住在家園和桌面上；牠的精力、飽足、心情與親密度會帶進來，搬離時寫回牠的角色紀錄。
* *布置* 把收納中的家具放到地板上。紅色預覽會說明為什麼不能放（超出家園範圍、那裡已經有東西、擋住出入口），按 Esc 結束布置。*收納* 會把家具收回，正在那裡進行的工作會暫停並保留進度。布置時可以直接拖曳家具，或選取後按 ← ／ → 一次移一格；*復原* 與 *重做*\ （Ctrl+Z ／ Ctrl+Y）涵蓋所有配置變更。*複製配置* 會把配置碼放到剪貼簿（只有家具與位置，不含寵物、金幣或任何個人資料），*貼上配置* 再讀回來；四種現成配置（*新手家園*、*溫馨角落*、*工坊*、*園藝工作室*）在 *套用配置* 購買並擺好之前，會先顯示還缺什麼與價格，原本的配置按一次 *復原* 就回來。*在地板上畫區域* 可以把一段地板標成 *居住*、*工作*、*休閒* 或 *用餐*\ （或清除標籤）；寵物會優先使用標籤符合當下活動的家具，但不會被禁止使用其他家具。接上第二台螢幕時，*在那個螢幕新增區域* 會在那裡多一個有自己桌面長條的區域，*把這個區域移過去* 可以搬移區域；寵物只有透過 *移到那個區域* 才會換區。螢幕被拔掉時，那個區域的寵物會等待、家具留在原處，不會複製任何東西，螢幕回來後就繼續生活。*貓跳台* 與 *攀爬牆* 在高處：活潑的寵物會自己跳上去，其他寵物需要旁邊有 *寵物階梯*；兩者都沒有時，紅色預覽會顯示「沒有寵物上得去」。工作台一律放在地面。*入口通往* 可以把兩個區域的入口連成交通點：寵物空閒時偶爾會走過去串門子，睡覺時間再走回自己的床，不會走進未連接的螢幕。*分享藍圖…* 會把整個家園的房間與家具存成 JSON 檔——不含寵物、名字、金幣、目標、螢幕名稱或任何個人資料；*拜訪藍圖…* 以唯讀方式開啟這種檔案：可以逛各個房間，但不會運作、不會購買、不會存檔，也完全不連網。不是藍圖的檔案會被拒絕；這個 FrontEngine 沒有的家具會列出名稱，而不顯示出來。
* *工作* 不需要設定：寵物在工作時段會依家裡的工作台自己接工作，先做自己擅長的行業，只用背包裡已有的材料；分頁會列出每隻正在做什麼，附上產出物的圖，任何工作都能取消。每個完成的單位只付一次錢，取消的不付錢。起始家具會自己擺好，*擺放* 會把收納中的家具放到第一個空位（或用 *布置* 點地板指定位置），在 *商店* 買的家具直接進家裡，完成的 *新手目標* 獎勵與物品足夠的委託會自動結算。商店、背包與收納都以圖片顯示每件家具和物品。格子內的名稱與價格分行顯示，格子大小隨字型調整，較長的完整名稱仍可在工具提示中查看。*設定* 分頁只保留在桌面顯示家園與減少動態。工作台可以從右鍵選單或家具分頁 *升級* 兩次（價格依家具與等級而定，自由布置時免費）；同一種工作台共用等級，所以收起或重新布置都不會失去，每升一級工作快四分之一。空閒的寵物可能會走過去幫正在工作的寵物——最多兩位幫手，每位讓速度再加四分之一——也會學到一點那項職業。倉庫裡某樣成品已有二十個時，自動工作就不再做它。家具會顯示正在發生的事：有人使用時有一個圓點，有寵物在工作時顯示該職業的工具（✎ ❀ ⚒），完成一份工作後顯示 ✓ 幾秒鐘。勾選 *專注時寵物陪我一起工作* 後，開始寵物頁的專注計時會替每隻有空的寵物排一個工作請求——不會打斷牠正在做的事、工作照一般獎勵計算，也不讀取你打的字、不在意你暫停——休息或停止計時時，只收回家園自己排的請求。每項職業都有一份進階工作，需要技能等級 4 的寵物，以及等級 4 的家園：*寫一部長篇小說*\ （120 金幣）、*紮一束花*\ （三朵花紮成價值 30 的花束）與 *做一個音樂盒*\ （三份木材加一個玩具，做成價值 80 的音樂盒）。
* *商店* 販售更多家具；賣回最多拿回半價，基本的床、餐桌與書桌不能買賣。家園共有 45 件家具，每件都有自己的用途或風格（從寵物軟墊到雙層床的床鋪、餐桌、每種職業各有工作台、沙發、懶骨頭、球池、鋼琴、地毯、魚缸等）；部分要家園等級更高才會開放，商店會標示所需等級，短篇故事、花與木凳也一樣。*收藏* 分頁有家具圖鑑（每件家具與取得方式）、寵物的作品與相簿。因為作息已自動安排，新手目標「選擇作息」改為「擺一件裝飾」；舊存檔的狀態會保留。家具包可以在商店與收藏裡加入家具：每個家具包是 ``pet-home-packs`` 裡的一個資料夾（設定分頁的 *開啟家具包資料夾*），裡面有 ``pack.json``——格式 ``frontengine.home-pack`` 第 1 版、與資料夾同名的穩定 ID、名稱、來源與授權，以及最多 64 件家具（ID、名稱、類別、寬度、是否實心、互動點、用途、需要的姿勢、價格與舒適度）——每件家具都要有 ``furniture/warm_home/<art>.png`` 圖片（其他主題可省略），另附 ``thumbnail.png``。只要有未知欄位、指向家具包外的路徑或連結、不是 PNG 或超過 2 MB 的圖片、重複的 ID，或任何可執行的檔案，整個家具包都會被拒絕，原因會顯示在設定分頁；家具包裡的東西一律不會被執行。家具的 ID 會變成 ``<pack>__<id>``，移除家具包後，存檔裡的這些家具會先保留著，等家具包裝回來。 第二批家具新增落地燈、吊掛盆栽、衣櫥、和式床墊、暖桌、電視、壁爐、搖搖馬、望遠鏡與淋浴間。
* 內容包也可以帶主題：名稱、沿用哪套內建主題的家具圖，以及地板、白天天空與夜晚天空的顏色；主題會加入家具分頁的主題清單，只有主題的包也可以。使用中的主題所屬的包被移除時，家園會保留該主題，在包回來之前以溫暖小屋的樣子呈現。家具包、主題與藍圖在 Steam 創意工坊上也是各自獨立的類別：訂閱的包與主題會在下次啟動 FrontEngine 時出現在家園，訂閱的藍圖則以唯讀參觀開啟。藍圖會寫明需要哪些內容包，創意工坊清單和參觀畫面都會標出還沒安裝的包。
* 頁面排得像遊戲畫面：家園在最上方，同一行顯示日子、時間、天氣、金幣與 *開始* ／ *暫停*；*居民*、*工作*、*家具*、*商店*、*背包*、*目標*、*待閱*、*收藏* 與 *設定* 是下方的分頁，使用時家園一直看得到。還沒有家園時，上方會顯示新家園附帶的床、餐桌與書桌，旁邊是 *建立家園*。總覽下方有 *回到桌面*、*背包*、*目標* 與縮放（− ／ + 或 Ctrl+滾輪），以及 *等你處理* 清單，列出家園無法自己解決的事（還沒有寵物、待閱新訊息、收納裡的家具、等材料的工作、可以舉辦的慶典、願望），點一行就打開對應分頁。布置時桌面長條會顯示 *布置完成*，因為長條不接收鍵盤。較新版本 FrontEngine 的存檔會提供 *取得最新版 FrontEngine*。*自由布置* 會切換到另一個獨立的家園（``pet-home-sandbox.json``），所有家具都能用、不花錢也沒有金幣；在那裡做的事不會影響經營中的家園、它的金幣與目標，也不會改到寵物本身的數值。來回切換時會先存檔，並取消寵物正在做的事、不發獎勵。
* 只有家園在進行中（*開始*／*暫停*）時時間才會前進；FrontEngine 關閉或電腦睡眠的時間不會補算。家園存在設定檔旁的 ``pet-home.json``，上一份正常的存檔保留為 ``pet-home.json.bak``。讀不了的存檔或較新版本的存檔永遠不會被覆寫：頁面會提供還原備份，或保留舊檔後建立新家園。 存檔失敗後若重試成功，該次存檔的即時錯誤提示會清除，待閱仍保留錯誤紀錄。 關閉時若無法儲存設定、寵物或家園狀態、筆記、上次工作階段或使用紀錄，FrontEngine 會保持開啟，讓你排除問題後重試。先前成功的寫入與已取消的活動不會回復原狀。

每個程序只有一個 FrontEngine 控制視窗。設定資料夾會持續保留給該視窗，直到所屬背景作業與視窗完成關閉；其他程序無法開啟同一資料夾。JEditor 與 PyBreeze 會重用嵌入視窗，並在存檔失敗或關閉尚未完成時保留宿主視窗。

窄視窗中的家園狀態文字位於操作按鈕上方，按鈕可自動換行。GIF 覆蓋層完成關閉後，來源檔案即可移動或刪除。

寵物生成、預覽、桌面寵物與家園居民的預設衣櫃與家園圖片使用設定頁已持有的資料目錄，不隨主機工作目錄切換。明確指定的寵物素材庫仍會保留。 家園照片、相簿與本機內容包資料夾也使用同一個已持有的資料目錄。 照片保存成功後立即出現在相簿中，家園暫停時也一樣。

準備關閉及關閉期間會拒絕家園面板操作，藍圖選檔結果也會在使用前重新檢查。取消關閉後可執行新操作，不會重播先前被拒絕的操作。

建立家園後，快捷列及較長的按鈕、勾選說明會在窄視窗換行。家園控制項可隨面板縮放，家園畫布仍保有自己的水平捲動。

遊戲內換日時，每日委託會同步更新到畫面，不必等待其他生活或獎勵事件。

收件匣中的既有事件會隨語言切換重新顯示，並保留重複次數、當時的寵物名稱與獎勵數值。家園暫停時，新通知與全部已讀操作也會立即同步到待處理清單。

獨立嵌入設定頁時，宿主必須透過 lifetime= 傳入明確的 DefaultSettingsLifetime。關閉該生命週期前，先儲存並停止頁面；宿主須觀察 finished 訊號後才結束。 :download:`Runtime lifetime API <../../../formats/runtime-lifetime.md>`
* 穿上分層角色（內建的 INKSIDE 角色或衣櫃裡的角色）的寵物，會以牠本來的樣子出現在家園裡：在路上時走路、在書桌或扶手椅上坐著、在床上睡覺、在餐桌吃飯、在玩具箱玩、互相打招呼，並朝著走路的方向。居民的 *衣櫃…* 會打開原本的衣櫃，換好的造型會立刻出現在家園。角色在背景載入；載入完成前會先用彩色標記代替。曾在桌面上出現過的圖片寵物（GIF、圖片或精靈包）與 Puppet 寵物，在家園裡也會以自己的樣子出現：精靈包用自己的走路、待機與睡覺動畫，GIF 用自己的影格，Puppet 則用從自己畫布拍下的靜態圖；只有一張靜態圖的寵物走路時會彈跳、玩耍時會跳起、睡覺時會縮成一團。沒有可用外觀的寵物（新寵物，或圖片後來被移走）會以固定的一位內建角色出現；牠本身的外觀與桌面寵物都不會改變。沒穿衣服、維持預設部件與顏色的內建角色有專屬的手繪姿勢：躺在床上睡、坐在扶手椅、吃飯、玩耍、在書桌寫字、替花槽澆水、在工作台敲打（坐、睡、吃、玩在桌面上也看得到）。穿上衣服或換了顏色時，則維持分層動畫，在工作位置坐著。仍穿著舊版內建角色的寵物會自動換到目前版本，衣服與顏色都保留。
* 家園有四種 *模式*：*一般*；*專注*，桌面長條保持安靜（沒有泡泡與卡片）；*會議*，隱藏家園並暫停，狀態會明說；*省電*，長條每秒只畫 15 格，寵物的生活速度不變。分享螢幕期間會自動切到會議模式。*待閱* 會收集工作完成、需求、生活點滴與問題，重複的事件合成一行，從不跳窗或搶焦點；寵物自己去吃飯睡覺不會列出來。
* 家園有白天、夜晚和天氣：總覽的天空會隨遊戲時鐘從黎明變到夜晚，晴天、多雲或雨天每六個遊戲小時變換一次，由家園本身決定，所以每次都一樣。天氣只是氣氛，不會弄壞東西，也不會讓你乾等。三套主題（*溫暖居家*、*綠意工作室*、*夜間創作室*）只改顏色，不改布局。家具是用 Blender 建模的描邊卡通圖，顏色會配合各套主題；選取家具或布置時才會顯示名稱。聽雨的日子、星光夜晚、交到好朋友、手藝精進、綠意之家、熱鬧之家、第一篇短篇故事和豐收也加入生活點滴，一共十二種。*減少動態* 會讓寵物不在步伐之間滑動、雨也保持靜止；所有事件也都會寫在卡片與點滴清單裡，家園本身沒有聲音。
* 環境音在 *設定* 分頁開啟前都是關閉的，並有獨立的音量：白天鳥鳴、夜晚蟲鳴，下雨或下雪時是雨聲或輕柔的冬風。家園暫停、會議中或電腦鎖定時不會發聲。桌面長條在傍晚與夜裡會讓家具和寵物稍微變暗；長條的空白處仍保持透明，點擊照樣穿透到後面的視窗。 下雨或下雪時，桌面長條上也會落下雨滴或雪花，畫在一層完全不接收滑鼠與焦點的獨立圖層上；專注與會議模式會暫停，*減少動態* 時則靜止不動。
* *目標* 會隨著家園成長：家園等級靠生活里程碑提升（三種工作都做過、更多居民、更多家具、深厚的友誼），十個 *新手目標* 附小額獎勵、完成後自動領取（隨時可以略過，之後仍可回看），每天三筆 *委託* 用家園幣收購商品、沒有連續登入獎勵也沒有錯過懲罰，每隻寵物一個說明達成方式、永不倒數的小願望，生日、第一件手作、好友聚餐等生活點滴，以及兩隻以上寵物同住且三種工作都做過之後的一次性家園慶典。*拍一張合照* 會把家園畫面存到設定檔旁的 ``pet-album``，不會擷取你的桌面。背包會顯示家具圖鑑的收集度。
* 寵物也需要舒適與陪伴。床、扶手椅和裝飾讓家更舒適，舒適度太低會讓心情變差。寵物會互相打招呼、一起吃飯玩耍而變得更親近，偶爾也會為了最後一個空位鬧彆扭。每隻寵物都有固定的個性（勤快、愛玩、安靜、愛社交，或喜歡園藝、寫作、手作），會影響牠的選擇，做喜歡的工作也稍微快一點；沒有哪種個性會讓寵物不適合做任何事。卡片會顯示個性、最要好的朋友，以及目前動作還剩幾分鐘；桌面上的小泡泡會說出寵物剛開始做什麼、跟誰打了招呼、賺了多少。舊的家園存檔讀取時會補上新需求；這個版本存的家園不會被舊版 FrontEngine 覆寫。
* 寵物也喜歡保持乾淨：清潔度會慢慢下降（玩耍時降得更快），覺得髒的寵物會就地整理毛髮，或去浴缸泡澡（更快）；梳毛也有幫助，家裡沒有浴缸卻有髒兮兮的寵物時，家園下方的清單會建議買一個。
* 三種工作：在書桌寫作、在 *花盆* 園藝（香草讓用餐更開心，花可以賣）、用商店買的木材在 *工作台* 手作（玩具可以賣，木凳做好直接進收納）。工作分成看得到的階段（播種、澆水、採收…），材料不夠時會等待而不是硬做。*背包* 列出家園擁有的所有東西、保留給工作的數量，並能賣出商品。買價一定高於賣價，任何工作串都不能把東西變回自己。
* 家園也會出現在桌面上：沿著螢幕底部、站在工作列邊緣的一條透明長條。只有寵物、家具和小小的 ⌂ 按鈕會接收滑鼠，其他像素都會穿透到後面的視窗，長條也不會搶走焦點。點寵物看牠的卡片，右鍵下指令，拖曳可以移動牠；家具按右鍵可以收納。*在桌面顯示家園* 可以關掉它，*桌面圖層* 決定放在視窗上層或下層（預設上層）；全部隱藏時家園會暫停，重新顯示才繼續；控制中心的畫質設定決定每秒 60、30 或 15 格，不影響家園生活的速度。⌂ 旁邊的箭頭會展開工具列，有 *布置*、*居民*、*工作*，以及金幣、最後點選的寵物與進行中的工作；⌂ 選單可以把工具列移到長條另一端，展開與否和位置都會記住。寵物的右鍵選單最前面是 *餵食*、*摸摸*、*聊天*——稍微提升飽足、心情或陪伴，每種每半分鐘最多一次，正在別處休息的寵物不能用——接著是 *請牠去*\ （各種指令）、*衣櫃…*、*安排這隻寵物的工作…* 與 *在總覽中跟隨*\ （總覽放大時讓牠保持在畫面內）。家具的右鍵選單會說明用途與目前誰在使用，並提供 *移動*\ （直接在桌面上布置）與 *收起*。鎖定電腦時家園也會同樣暫停，狀態列會顯示原因，直到解鎖為止。把檔案拖到家園裡的寵物身上就等於餵食（同樣每半分鐘一次）；檔案不會被開啟、修改或刪除，也不會變成材料或金幣。寵物選單還有 *理毛* 與 *玩玩具*\ （工作、吃飯或睡覺時不行）、*過來這裡*\ （走到你按右鍵的位置並在那裡待一下）、*玩鬼抓人*\ （找最近的空閒寵物一起玩，正在忙的不會被拉進來，兩隻都會開心）與 *拍張照*\ （從總覽拍下這隻寵物，存進相簿）。
* 長條可以縮小或放大（75–200 %，家具、寵物與高度一起變）：在寵物或家具上按住 Ctrl 滾動滑鼠滾輪、⌂ → *大小*，或在設定分頁選擇，選擇會被記住。放大後比螢幕寬的家園仍留在螢幕內，並平滑跟隨最後點選的寵物（或所有寵物）保持在畫面中。在長條上雙擊寵物就能摸摸牠。

家園設定中的模式選單在手動選擇會議模式而隱藏桌面長條後仍可使用。復原與重做依房間分開記錄；若家具無法取得或放不下，會保留目前配置與紀錄，讓你稍後重試。Esc 可取消布置與區域繪製。連續拍照會分別保存檔案。一次性生活事件離開近期紀錄後仍會保留觸發狀態，暫時移除家具包也會保留已付費的工作站升級。舊存檔只能還原其中仍保有的事件紀錄。

工作清單為空時，請檢查居民作息、工作站與背包材料。選取尚未完成的工作後，才能按「取消工作」。

所有教學目標都已領獎或跳過後，跳過按鈕會隱藏；目標清單仍可回顧。

工作清單取得鍵盤焦點時會顯示強調色邊框，即使尚未選取工作也能辨認焦點。

工作清單的無障礙名稱會隨介面語言更新。

自主工作因缺材料、缺工作站或工作站被占用而無法開始時，居民卡會在改做休閒活動期間保留原因；重新開始工作後，舊原因會清除。

已排入佇列的指令若因條件改變而在執行時被拒絕，居民卡會在替代活動期間保留原因；下一項接受的活動會清除該原因。

手動工作指令排入佇列後，嘗試開始時若缺材料、缺工作站或工作站被占用，也會在居民卡顯示原因；排除問題後可重新交代工作。

等待事項清單高度改變時，家園場景與工具列仍各自排列，不會重疊。
