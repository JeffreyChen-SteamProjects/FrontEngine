# 衣櫃背景安裝生命週期驗收

補上 `test_pet_wardrobe_dialog.py` 的真實 QRunnable 安裝測試。測試在素材已複製、圖片已驗證，但尚未 rename 發布的時點用 threading Event 暫停工作執行緒，關閉衣櫃後再繼續。沒有用假的成功訊號替代檔案安裝。

兩種生命週期都通過：關閉但暫時保留 QObject，以及完成 QObject 延後刪除後才讓工作執行緒結束。取消旗標生效，素材庫沒有發布項目或 `.install-` 殘留，正式個體存檔未改變，預覽計時器停止且 renderer 已釋放。已刪除的衣櫃不接收遲到回呼。

另驗證損壞 PNG 的背景安裝失敗會顯示訊息、重新啟用安裝按鈕並清除暫存資料。修復同一來源後，在同一衣櫃重試可安裝相同版本，目錄只新增一個完整資產，角色選單更新且存檔維持原值。

衣櫃對話框與資產庫兩模組共 12 項測試通過。初版測試曾錯誤假設預設關閉後 QObject 仍存在，後改為明確區分保留與刪除情境；沒有因此修改產品生命週期或放寬取消後無殘留的要求。

這次沒有產品程式變更，也不代表原生 UI、完整動畫或六角色素材已驗收。

擴展至全部 33 個寵物測試模組後，340 項同程序測試通過；pyflakes 通過。
