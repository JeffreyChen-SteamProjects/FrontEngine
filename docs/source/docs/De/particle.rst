Partikel-Seite
--------------

* Bild wählen - woraus jedes Partikel gezeichnet wird.
* Partikel starten.
* Richtung - nach unten, oben, links oder rechts.
* Partikelgröße, -anzahl, -geschwindigkeit - wie aufwendig der Effekt ist.
  Weniger und langsamer kostet weniger; die Qualitätsstufe im Kontrollzentrum
  senkt zusätzlich alle Overlays auf einmal.
* Deckkraft - wie durchsichtig die Partikel sind.
* Auf allen Bildschirmen zeigen - eine Kopie je Monitor.
* Zielbildschirm - welcher Bildschirm, oder jedes Mal nachfragen.
