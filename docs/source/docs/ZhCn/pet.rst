宠物页面
--------

一只住在桌面上的伙伴。

* 选择宠物图片 - 单张图片。
* 选择宠物包… - 一个文件夹，里面有 walk / idle / sleep / climb / fall / drag
  这些动作的图，宠物就会有动画。
* 选择音效（可不选） - 它会播放的声音。
* 召唤宠物 - 放到画面上。再按一次会多一只。
* 大小、速度 - 多大、多快。
* 行为 - 在地面走动、自由漫游，或追着光标跑。
* 爬墙 - 让它沿着窗口边缘爬。
* 坐在窗口上 - 让它停在其他窗口的上沿。
* 对话气泡 - 按时段、喂食等情况说几句短话。
* 打字时安分 - 你在打字时宠物会停下来，停手一两秒后再继续走，这样它就不会
  跑过你正在看的那一行。
* 把话说出来 - 用语音把那些话念出来。
* 玩捉迷藏 - 两只以上的宠物会互相追逐。
* 跟着声音反应 - 宠物会随声音起伏动作。可以跟着**扬声器**或**麦克风**；
  两者都只读取音量电平（一个数字），不会捕获说话内容。Windows 与 macOS（macos extra 与权限；此处未验证 macOS 实机）。
* AI 聊天（需要 API 密钥） - 和它对话。会读取 ANTHROPIC_API_KEY 环境变量，
  密钥不会被保存。
* 专注计时（分） - 宠物帮你看着的工作计时器，中间会安排休息。

把文件拖到宠物身上就是喂它；拖图片或宠物包则是换造型。

Puppet 宠物：安装可选的 puppet extra 与可用的 Imervue runtime，再于宠物页选择或拖入原始 Imervue .puppet v1 文件。已有图片与 sprite 宠物包仍可使用。Puppet 宠物使用 Imervue 画布、动作与表情，可复制或关闭，并支持 FrontEngine 覆盖层控制与预设集。可另选 .petscript.json 使用 Imervue 原有脚本引擎；FrontEngine pet.json 宠物包不是 puppet 文件。未知版本、不安全的归档路径与无效资源会在加载 runtime 前拒绝。

:doc:`runtime_interoperability`

宠物 → 宠物身份与存档为每只 sprite 或 Puppet 宠物保存独立 UUID、名字、心情、饱足及好感度。重启后在生成前选择已保存身份即可继续状态；“新宠物”建立新状态。第一个身份只迁移一次原共享数值。复制将当前数值复制到新身份，喂食不会改变其他宠物。可重命名、刷新、导出或导入单只 JSON 存档，导入一定建立新身份。同一身份同时只能启用一次。存档不含图片、脚本或对话记录，可移植预设集不写入本地身份 ID。用户设置最多保存 256 个身份；sprite 数值更改稍后合并保存，关闭时也会保存。Puppet 喂食只更新存档数值，不改变 Imervue 动作及尺寸。

宠物 → Sprite 宠物包制作可对应行走／闲置／睡眠／攀爬／落下／拖动图片、预览尺寸与行走速度，导出含 pet.json 的便携文件夹。至少需要一个动作；缺失动作列出提示并使用现有加载器备用。支持 PNG/JPEG/GIF/WebP，每文件上限 64 MiB、1600 万像素，总计 256 MiB。导入／导出在后台执行，可取消且不覆盖现有文件夹。导出后可移动、在宠物页选用或作为 Workshop 宠物包分享。导入只保留选定图片、名称、尺寸与速度，不复制音效、脚本或对话；Imervue .puppet 使用独立制作格式。关闭或 Escape 会释放预览动画并取消文件操作。

陪伴互动与存档
~~~~~~~~~~~~~~

第 2 版宠物存档保留第 1 版的 UUID 与数值，新增精力、所选模式、偏好与经过验证的外观引用。

精灵宠物菜单提供打招呼、轻轻抚摸、梳理毛发，以及持续的一起玩耍、一起工作和休息模式。“结束互动”可取消当前动作。计时动作完成后才发放收益，取消不给奖励。吃饱时拒绝喂食，重复动作需等待冷却，拖曳或变更外观不给奖励。本版尚无玩具界面。

照护按活动时间推进，不依赖对话气泡。隐藏与离线期间不积累待补算的照护或奖励。精灵宠物通过共用互动会话处理菜单动作与模式控制。Puppet 宠物共用会话及喂食规则，实际原生视觉反应取决于运行时与模型能力。

在宠物页面选择身份后打开“自定义宠物”，或从该宠物菜单打开。每个身份可独立设置大小（16–512）、速度（1–20）、地面／漫游／追逐行为、爬墙、坐在窗口上、对话气泡、音量（0–100）、打字时安静、自动休息、抛掷和社交偏好。“使用页面默认值”会继承页面的显示与行为设置；克隆及导入保留各自的设置。“应用”先以原子写入保存，再更新正在运行的宠物。“取消”不更改设置；“恢复默认值”须再按“应用”才生效。保存失败或编辑冲突时保留草稿。Puppet 会禁用不支持的控件，显示与行为设置中仅应用大小、对话气泡及打字时安静。原生换装控件与分层美术仍未完成。

宠物身份 → 衣柜可预览已安装的分层角色。安装素材文件夹会验证 layered-pet.json 并复制到本地设置旁的 pet-assets。可选头、颈、身体、背部配件，预览动作与朝向，每个体最多收藏 20 套搭配。穿上配件会替换占用相同槽位的配件并列出被替换的项目，取消即可还原。只列出符合当前体型的配件，缺少动作的配件会显示为停用。试穿会播放短暂的换装展示，“固定以便比较”可把当前造型并排显示在草稿旁。宠物正被拖动或正在互动时，会等结束后才换上新衣服。使用整张图片 Sprite 的宠物会提示先选择分层角色。应用会保存并更新正在显示的 Sprite；取消放弃上次应用后的编辑。缺少素材仍保留引用，修复后按刷新。Puppet 不使用 Sprite 分层衣服。添加内置角色会在后台绘制六个 INKSIDE 角色之一（MOCHI、MOSS、PIP、BOLT、INK、GILL），连同按其体型适配、来自十四套搭配的三十件衣物，并走相同的验证流程安装；关闭衣柜即取消。每个角色可选眼睛、嘴巴与三组身体部件，也能为指定区域换色，每件衣物都会跟随所有动作。部件与衣物名称会跟随界面语言。

没有穿衣服、部件与配色都是默认值的内置角色，走路和爬墙会改用手绘的全身步伐画格；穿上衣服或换过部件时则使用分层动画，让每件衣物都保持贴合。

桌面宠物不论“覆盖层绘制”设置为何，一律使用一般的 Qt 绘制：宠物每一刻都在移动窗口，而走 GPU 路径时，移动中的动画画格会停住不换。

宠物会进入合适的姿势：工作模式坐下，进入休息先播放入睡片段，离开休息播放醒来片段。玩耍、扔球、捡回与鬼抓人会消耗少量能量；能量低于 20 时，即使关闭自动休息，空闲的宠物也会坐下，但仍听从所有指令。拖放或抛出后落地、接住扔出的球、遇到其他宠物时，会短暂播放落地、接球与挥手反应，不中断移动、玩具或你的操作。没有这些片段的 Sprite 动作包会退回空闲或睡觉图片。整理结束时会伸个懒腰；一再相遇的宠物每分钟最多互相挥手一次。

关系会随好感分为四个阶段：初次见面、熟悉（20）、亲近（100）、默契（250），状态中会显示当前阶段。各阶段有不同的招呼台词，亲近时挥手、默契时开心跳起，达到新阶段会播放一次庆祝；不会锁住或失去任何东西。重新召唤已保存的宠物会说欢迎回来，从宠物自己的菜单关闭时会先挥手道别再关闭窗口。Puppet 现在也和 Sprite 一样区分点击与拖动：松开时点击会打招呼，只有移动超过系统拖动距离才会移动窗口，且不给奖励。

“自定义宠物”还能分别设置主动说话（关闭、偶尔、一般、经常）与动画幅度（沉稳、一般、活泼），前者控制宠物自己开口的频率，后者控制声音脉动与落地、接球等短反应，与对话气泡及音量互不影响。关闭主动说话后，对你操作的回应仍会显示。Puppet 的主动说话设置用于脚本排程台词。先前保存的设置照常可用，两者均视为一般。

宠物管理页的互动列表也会列出所选宠物自己的菜单指令：拍照、状态、提醒、对话（接入对话服务时）、复制与关闭，以及 Puppet 模型的每个动作与表情，因此右键菜单中的所有操作都能用键盘完成。

宠物页的“使用内置 Puppet 模型”会在后台把选定的 INKSIDE 角色绘制成 Imervue .puppet 模型：头、手臂、尾巴与身体都已绑定，附十个动作、三个表情，以及把陪伴互动对应到它们的宠物脚本。模型存放在 pet-assets/puppets，并连同脚本设为来源，按开始即以 Puppet 宠物出现。

在多台不同缩放的屏幕上，把宠物拖到或找回到另一台屏幕时，它会保持原本大小、留在该屏幕的工作区内并在那里走动。缩放屏幕上的窗口上缘也改用与宠物相同的坐标计算，因此会准确站在窗口顶端。

衣柜会列出角色或服装素材声明的配色部位。选择部位后可改色或恢复素材原色；只改指定遮罩图层，轮廓与未标记细节保持不变。配色先预览，点击应用才保存，并随个体、收藏搭配及存档导出／导入保留。未声明部位的素材不开放配色控制。

关闭时若宠物存档失败，会保留宠物、当前状态与重试计时器。“全部关闭”保留未能关闭的宠物；退出程序前会先确认宠物存档成功。好感度达到存档上限后不再增加，避免后续奖励造成存档失效。

互相打招呼与追逐游戏要求双方都可见、处于玩耍模式且没有正在互动、允许社交，也未被拖动或因打字而安静。不符合条件的宠物会退出追逐目标与角色。合适成员不足两只时暂停，恢复后再开始。关闭对话泡泡只隐藏招呼文字，不取消社交奖励。

开始宠物专注计时会让当前可见且没有正在互动的宠物进入工作模式，休息阶段改为休息模式。停止时恢复原模式，但不覆盖手动更改的模式。每轮完成时，符合条件且可见的陪伴宠物只获得一次 3 点好感与 5 点心情；提前停止或隐藏宠物不发完成奖励。工作／休息模式不主动闲聊，默认计时采用单调经过时间，不受系统时钟调整影响。

专注开始时，空间足够的宠物会排列在所属屏幕工作区右下角。停止时只恢复未被手动移动或改变模式的宠物原位置。

分层角色可声明五官与身体部件选项；衣柜按个体预览，应用后保存，搭配收藏同时保留角色及部件。每个选项必须涵盖所有动画帧。六角色正式部件美术仍未完成。

Sprite 宠物菜单提供“宠物拍照”：冻结当前外观，或选择分层素材已有的姿势，再保存透明 PNG。只输出宠物，不含桌面像素与对话气泡。Puppet 也可通过已就绪且兼容的 Imervue 渲染器拍摄透明定格照片，不读取桌面像素。原生 GL 拍照验收仍待完成。

Sprite 宠物选“摸摸”后，在它身上来回移动光标；三段明确行程才开始一次抚摸反应，细微抖动不算。期间暂停拖动与社交；移开、隐藏、改变模式或选结束互动会取消未完成抚摸，奖励仍须完成且遵守冷却。

Sprite 宠物菜单可投出或收起玩具球；拖动球再放开可重投，右键球可收起。宠物追球并带回起点附近，完成往返加 1 好感，冷却为 30 秒活跃时间。工作／休息、其他互动、隐藏、打字安静或超时会取消且不发奖励。Puppet 也能捡球（见下方）。

地板模式宠物会离开窗沿下到地板追球；玩球期间暂停窗口停靠，结束后恢复。带回位置在原起点水平位置附近的地板。

“光点逗逗它”在宠物附近放置可拖动的小光点，活动距离有限；地板宠物沿地面追逐。放开光点并让宠物追到后开始短暂玩耍，完成才按既有玩耍冷却给奖励。右键光点或选“收起玩具”可停止。同一只宠物一次只能使用球或光点其中一个。

复制会使用被复制宠物本身的图片／模型、外观、偏好及资产库，即使设置页已改选其他素材也不影响。复制品使用新身份，之后换装或换部件不会改到原宠物。Puppet 也保留来源脚本、参数值及已选表情。

符合条件的专注完成会短暂播放 celebrate，再回休息；应用更改的衣柜会短暂播放 outfit_show。反应持续两秒活跃时间，不另给奖励、不写入存档，手动互动或换模式可中断。素材缺少对应动画时沿用 idle 回退；正式反应美术与 Puppet 动画映射仍待完成。

选择已启用的个体后按“找回宠物”，可带回目标屏幕工作区。隐藏宠物会重新显示，未完成互动与玩具会停止，Sprite 移动边界同步更新；外观与养成数值不变。未启用者须先启动，尺寸超过工作区者须先缩小。

Puppet 脚本可用 frontengine_actions 将共同互动状态映射到模型已有动作与表情，启动前验证名称；未设置时不猜动画。完成后释放互动持有的效果，保留手动选择。格式见 docs/formats/puppet-companion-actions.md，原生视觉验收仍待完成。

Puppet 选择抚摸后，需来回移动光标才开始互动；移开、Esc、隐藏、切换模式或安静状态会取消未完成抚摸。抚摸期间不拖动窗口。原生手势验收仍待完成。

衣柜提供六个风格色板，可快速调整选中的素材配色部位。先预览再应用；取消保留已存外观。仍可自由选色及恢复部位原色。

Sprite 与 Puppet 菜单可直接选四种虚构点心，不必拖放文件；沿用喂食完成、饱足上限与冷却规则。喂食前结束抚摸，未完成抚摸不给奖励，Sprite 同时收起玩具。

每只宠物可在自定义中保存喜欢与不喜欢的不同点心。只在喂食完成后调整心情，饱足、好感与冷却不变；进食中改设置从下一餐生效。旧存档默认无偏好。素材或 Puppet 可提供 food_like、food_dislike 短反应，正式动画仍待制作。

Sprite 宠物可用「过来这里」显示可拖动的附近落点标记。地板模式沿地面前往，自由漫游／追光标模式可沿两轴移动；抵达后短招呼，沿用招呼冷却。标记右键或结束互动可取消；工作／休息、隐藏、喂食或换玩具也会取消。

宠物身份区新增互动列表与执行按钮，可用键盘对选中的运行中宠物招呼、短抚摸、梳理、喂点心、切换玩耍／工作／休息或取消。管理页抚摸沿用计时照护规则，不需鼠标手势；隐藏或未启动时只显示提示，不自行召唤。

衣柜打开时切换界面语言，会更新“无”、“缺少素材”和“重设默认”选项，保留未应用的配色、部件、穿搭名称和预览进度。素材作者提供的名称保持原文。

键盘指定落点：在宠物管理页选择“过来这里”，输入水平／垂直位移，单位为逻辑像素，负值表示左／上。落点受附近工作区限制，地板模式忽略垂直位移。执行互动开始呼叫，结束互动取消；忙碌或不支持移动的宠物会保留当前互动。

Puppet 也可从菜单或管理页键盘位移使用“过来这里”。移动外层窗口，将整只宠物和标记限制在工作区内；以宠物中心到达判定，停留半秒后开始共用招呼。手动拖动宠物、照护、模式切换、隐藏、尺寸或工作区变化、手动模型指令会取消呼叫。声明了 walk 反应的模型播放对应动作，其余保持原生外观。移动计时器仅在呼叫期间运行。原生 GL／焦点验收仍待完成。

Puppet 菜单可开始追逐可拖动的光点；Sprite 和 Puppet 都能在管理页用键盘位移放置光点。光点在宠物附近松开半秒后，开始共用的三秒玩耍，完成才增加好感并沿用冷却。呼叫与光点共用单一目标；收起玩具、结束互动、照护、手动拖动、模式切换或隐藏可取消。

Puppet 菜单也提供投出玩具球，Sprite 和 Puppet 的管理页都能替选中的身份投球。球的物理、拖动重投、右键收起、完成加 1 好感与 30 秒冷却都与 Sprite 共用；Puppet 窗口会追球、捡起并带回原来的中心位置，全程限制在工作区内。每次重投都重新计时。球、光点与呼叫共用单一目标，开始其中一个会取代另一个。照护、手动拖动、模式切换或隐藏会取消且不发奖励。正式捡球动画仍待完成。
