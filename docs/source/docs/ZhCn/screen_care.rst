护眼页面
--------

* 屏幕滤镜 - 在画面上盖一层暖色、琥珀、玫瑰、黄、绿、蓝或灰，强度可调。
* 阅读尺 - 一条跟着光标移动的横带，长篇文字不容易看丢行。
* 护眼休息（分／秒） - 每隔几分钟把画面调暗几秒，然后还给你。
* 色觉 - 模拟红色盲、绿色盲、蓝色盲或全色盲，用来检查设计出来的东西还读不读得懂。
* 显示在所有屏幕 / 目标屏幕 - 和其他页面相同。

这些覆盖层都让点击穿透，底下的东西照常可以操作。

色觉模拟不再闪烁，颜色也不会越跑越偏。Windows 上这一层不会被屏幕截取拍到，由后台线程跟着画面更新，只重画有变动的部分；因此截图与屏幕共享看不到它。做不到的系统改成静止画面，在开始与改设置时拍一张。
